# `max` 家族：双参数、initializer_list、max_element、ranges::max

`std::max` 只有两种签名——双参数和 `initializer_list`，**没有容器重载**。给 `vector` 求最大值要用 `std::max_element`（C++98）或 `std::ranges::max`（C++20），三者的返回值类型和空输入行为各不相同。

**场景示例：**

```cpp
#include <algorithm>
#include <vector>

std::max(1, 2);                    // 双参数版，返回 const int&
std::max({1, 2, 3});               // 列表版（C++11），返回值

std::vector<int> v = {3, 1, 4, 1, 5};
// std::max(v);                    // ❌ 编译错误：没有容器重载
*std::max_element(v.begin(), v.end());  // 迭代器版，返回指向 5 的迭代器
std::ranges::max(v);                    // ranges 版（C++20），返回值 5
```

**原理解析 + 常见误区**

- ❌ `std::max(v)` 能求 vector 最大值 — 错误。`std::max` 只接受两个值或一个 `initializer_list`，容器要走 `max_element` / `ranges::max`。
- ❌ `ranges::max` 是 `max_element` 的语法糖，行为完全一样 — 错误。返回值不同（值 vs 迭代器），**空输入行为**更关键：`max_element` 空容器返回 `end()` 可检查；`ranges::max` 空 range 是 **UB**（要返回元素值，空 range 没有值可返回）。
- ❌ `max({})` 空列表返回 0 — 错误。同样是 UB。
- ✅ 双参数版返回 `const T&`，列表版和 ranges 版返回**值**。对重对象频繁比较时，列表版会多一次拷贝。

**选型建议**：

| 场景 | 写法 | 空输入 |
|------|------|--------|
| 两三个值 | `max(a, b)` / `max({a, b, c})` | 空列表 UB |
| 容器，可能为空 | `max_element` + 判 `!= end()` | 返回 `end()`，安全 |
| 容器，确定非空 | `ranges::max(v)` | UB，别用在空容器上 |

**延伸点**：`ranges::max` 还支持自定义比较器和投影（`ranges::max(v, {}, &T::member)`），比手写 lambda 传给 `max_element` 简洁；`min`/`minmax` 家族规则完全对称。
