# `vector(n)` 的默认插入语义

C++11 起，`std::vector<T> v(n)` 是**默认插入**（default-insert）n 个元素：对类类型就是调用 n 次默认构造函数，**不经过拷贝构造**。C++11 之前则等价于 `vector(n, T())`——1 次默认构造 + n 次拷贝构造。

**场景示例：**

```cpp
struct Foo {
    Foo() { std::cout << "a"; }
    Foo(const Foo&) { std::cout << "b"; }
};

std::vector<Foo> bar(5);          // C++11 起输出 aaaaa
std::vector<Foo> baz(5, Foo{});   // 显式给初值：abbbbb（1 次默认 + 5 次拷贝）
```

`[vector.cons]/4`：`constexpr explicit vector(size_type n, const Allocator& = Allocator())`，效果是以默认插入方式构造 n 个元素。默认插入使用值初始化：类类型调默认构造函数，标量类型清零。

**原理解析 + 常见误区**

- ❌ `vector<Foo>(5)` 输出 `abbbbb` — 错误。那是 C++11 之前的双参数构造函数（`vector(n, const T& value = T())`）的行为；C++11 起单参数版本独立出来，直接默认插入。
- ❌ `reserve(5)` 也会调 5 次构造函数 — 错误。`reserve` 只分配原始内存，不构造任何元素。
- ✅ `resize(n)` 扩容部分同样默认插入，语义与 `vector(n)` 一致。
- ✅ 显式给初值 `vector(n, value)` 才是拷贝语义：`value` 构造一次，再拷贝 n 份。

**延伸点**：默认插入要求 `T` 是 DefaultInsertable（可默认构造）。没有默认构造函数的类不能用 `vector(n)`，只能 `vector(n, value)` 或 `emplace_back` 逐个构造。
