# operator void()：合法但永远不会被调用

`operator void()` 语法上**合法**，能通过编译（编译器一般给 `-Wclass-conversion` 警告），但任何类型转换语境都不会调用它——标准把"转换到 void"定义为不执行任何转换操作。

| 转换目标 | 合法性 | 转换语境会调用吗 |
|----------|--------|------------------|
| `operator int()` | ✅ | ✅ |
| `operator int&()` | ✅ | ✅ |
| `operator void()` | ✅（有警告） | ❌ 永不 |
| `operator void*()` | ✅ | ✅ |

```cpp
struct S {
    operator void() {}   // 编译通过，-Wclass-conversion 警告
};

int main() {
    S s;
    static_cast<void>(s);   // 不调用：到 void 的转换定义为无操作
    s.operator void()();    // 唯一的触发方式：成员访问语法显式调用
}
```

**常见误区**

- ❌ `operator void()` 是非法语法 — 错误。合法，只是永远不会被转换语境调用。
- ❌ `static_cast<void>(s)` 会调用它 — 错误。到 void 的转换是无操作。
- ❌ 它能用来"丢弃对象" — 错误。`void` 表示无类型，转过去也没有语义价值。

**延伸点**：C++11 之前的 safe bool 惯用法用的是 `operator void*()`（或成员指针），不是 `operator void()`——`void*` 是合法转换目标，能参与 `if (obj)` 语境；C++11 起这套做法被 `explicit operator bool()` 取代，见 [explicit 转换函数](./blog.html?post=cpp/ch01/39.md)。
