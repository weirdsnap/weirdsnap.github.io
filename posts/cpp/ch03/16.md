# `delete[]` 的数组析构顺序

`delete[]` 销毁数组元素时，按**构造完成的逆序**逐个析构——即按地址**递减**的顺序（标准条款 `[expr.delete]/6`）。先构造的元素后析构，和栈上局部对象的销毁规则一致。

**场景示例：**

```cpp
#include <iostream>

class show_id {
public:
    ~show_id() { std::cout << id; }
    int id;
};

int main() {
    delete[] new show_id[3]{ {0}, {1}, {2} };
}
```

输出 `210`：元素按 `0 → 1 → 2` 构造，析构时逆序执行 `2 → 1 → 0`。

**原理解析 + 常见误区**

- ❌ 数组元素按构造顺序析构（输出 `012`）— 错误。析构永远是构造的严格逆序，数组也不例外。
- ❌ 数组析构顺序是未指定的 — 错误。标准明确规定按地址递减析构，行为良定义。
- ✅ 该规则与对象内部的析构规则自洽：成员按声明逆序、基类最后析构，数组元素按构造逆序——"后构造的先析构"是 C++ 的通用原则。

**延伸点**：正因如此，用 `delete` 配 `new[]` 时只析构第一个元素（下标 0），其余元素析构函数全部跳过——对持有资源的类对象是静默泄漏。
