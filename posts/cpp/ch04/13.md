# 特化 vs 重载的优先级

两条独立的规则，容易混在一起：

- 非模板函数 vs 函数模板：不是"非模板无条件优先"，而是**转换序列平票时非模板赢**（决胜规则）。模板匹配得更好时，模板照样胜出。
- 函数模板的全特化：**不参与重载决议**。它只挂在主模板上，等重载决议选中主模板之后，才由特化匹配机制决定用主模板还是特化版本。

```cpp
#include <iostream>

template<typename T> void f(T) { std::cout << "template f\n"; }
template<> void f<int>(int)  { std::cout << "full spec f\n"; }
void f(int)                  { std::cout << "non-template f\n"; }

void g(short)                  { std::cout << "non-template g(short)\n"; }
template<typename T> void g(T) { std::cout << "template g\n"; }

int main() {
    f(1);     // non-template f：非模板和模板都是精确匹配，平票，非模板赢
    f(1.5);   // template f：非模板要 double→int 窄化转换，模板精确匹配
    f<>(1);   // full spec f：<> 强制只考虑模板，决议后全特化接手
    g(42);    // template g：模板 T=int 精确匹配，非模板要 int→short 转换
}
```

两个方向都要记住：

- `f(1)` 说明平票时非模板优先；`g(42)` 说明这不是"严格优先"，模板匹配更好就是模板赢。
- `f<>(1)` 说明全特化的位置：重载决议选中了主模板 `f<int>`，然后编译器发现存在全特化 `f<int>`，于是调特化版本。如果改成声明顺序不同或特化在调用点之后才出现，还会踩"特化未声明就用主模板"的坑（见下）。
