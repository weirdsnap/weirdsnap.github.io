# 只含一种字母的子串计数（1180. Count Substrings with Only One Distinct Letter）

## 题意

给定字符串 `s`，统计只含一种字符的非空子串个数。比如 `"aa"` 有 `"a"`、`"a"`、`"aa"` 共 3 个。

```
输入: s = "aaaba"
输出: 8
解释: "aa" 段贡献 3 个（a, a, aa），"b" 贡献 1 个，"a" 贡献 1 个，"aa" 段贡献 3 个

输入: s = "aaaaaaaaaa"
输出: 55
```

- `1 <= s.length <= 1000`
- `s[i]` 只含小写英文字母

## 思路

只含一种字符的子串，必然完全落在某一段"连续相同字符"里；反过来，一段长度为 `k` 的连续相同字符，里面任意连续子段都合法，共 `k*(k+1)/2` 个。

所以扫描一遍，按字符变化把字符串切成若干段，每段长度 `k` 累加 `k*(k+1)/2` 即可。

## 解法：分段计数

```cpp
class Solution {
public:
    int countLetters(string s) {
        int cnt = 1;
        int result = 0;
        char last = s[0];
        for (int i = 1; i < s.size(); i++) {
            if (s[i] == last) {
                cnt++;
            } else {
                result += cnt * (cnt + 1) / 2; // 连续 k 个相同字母贡献 k*(k+1)/2 个子串
                cnt = 1;
                last = s[i];
            }
        }
        result += cnt * (cnt + 1) / 2; // 最后一段单独累加，避免遗漏
        return result;
    }
};
```

## 核心理解

### 1. `k*(k+1)/2` 的组合意义

长度 `k` 的段里，合法子串就是"选起点和终点"：以第 1 个字符开头的有 `k` 个，以第 2 个开头的有 `k-1` 个，…… 合计 `k + (k-1) + ... + 1 = k*(k+1)/2`。等差数列求和，不用真的枚举。

### 2. 尾段结算的两种写法

循环里只在"字符变化"时结算，最后一段没有变化点，所以循环结束后要补一句累加。这是分段扫描的标准收尾。

另一种写法是哨兵结算：循环多跑一轮（`i <= s.size()`），把越界位置当作强制结算点，所有段都在循环内统一处理，不用在循环外补写。之前 [寻找排列（484）](./blog.html?post=leetcode/stack/ch90.md) 里给 `s` 末端强加一个 `'I'` 触发最后一次 reverse，就是这个思路。两种都对，看哪个顺手。

### 3. 免公式的等价形式

如果不想记公式，可以换个视角：扫描时维护"以当前字符结尾的合法子串数" `cnt`，字符不变则 `cnt++`，变化则重置为 1，每一位都把 `cnt` 加进答案。`ans += cnt` 逐位累加的结果和分段求公式完全一样，相当于把求和摊到了每一位上。

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 一次扫描 |
| 空间 | O(1) | 只存当前段长度 |

## 踩坑点

### ❌ 循环结束后忘记结算最后一段

分段扫描最容易犯的错：只在 `else` 分支里累加，循环一结束就直接 `return result`，尾段的贡献丢了。`"aaa"` 会返回 3 而不是 6。写完这种循环，先用"整串全相同"的用例过一遍脑子。

### ⚠️ 这题 int 够用，但公式本身要留意溢出

`n <= 1000`，单段最多贡献 `1000*1001/2 = 500500`，int 绰绰有余。但如果同样的模式搬到 `n <= 1e5` 的题里（比如 1513、1862 这类同模式计数题），`k*(k+1)/2` 会到 50 亿，得用 `long long`。公式记住，数据范围看题。
