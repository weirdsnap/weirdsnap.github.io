# 给字符串加粗标签（616. Add Bold Tag in String）

## 题意

给定字符串 `s` 和词表 `words`。`s` 中所有**出现在词表里**的子串都要用 `<b>...</b>` 包起来；重叠或相邻的加粗段要**合并**成一对标签。

```
输入: s = "abcxyz123", words = ["abc","123"]
输出: "<b>abc</b>xyz<b>123</b>"

输入: s = "aaabbb", words = ["aa","b"]
输出: "<b>aaabbb</b>"      （重叠区间合并）

输入: s = "aaabbcc", words = ["aaa","aab","bc"]
输出: "<b>aaabbc</b>c"     （"bc" 只命中下标 4 处那次的 b,c）
```

约束：`s` 长度 ≤ 1000，词表 ≤ 100 个词，只含字母和数字。

---

## 思路：匹配 → 标记 → 拼接，三段分离

1. **匹配**：把所有词插入 Trie。从每个起点 `i` 沿 Trie 下走，途中每遇到 `isEnd` 就更新最远终点 `end`：一次下走找出"以 i 开头的所有词"的最远覆盖，避免逐词匹配。
2. **标记**：`bold[n]` 布尔数组，把 `[i, end)` 整段置 true。区间合并**不需要维护区间列表**，数组天然完成。
3. **拼接**：扫一遍 `bold`，上升沿（false→true）插 `<b>`，下降沿（true→false）插 `</b>`。

## 解法：Trie + 布尔标记 + 边沿检测

```cpp
struct TrieNode {
    TrieNode* children[128];   // ASCII 直接定址
    bool isEnd;
    TrieNode() {
        memset(children, 0, sizeof(children));
        isEnd = false;
    }
};

class Trie {
public:
    TrieNode* root = new TrieNode();
    void insert(const string& word) {
        TrieNode* node = root;
        for (char c : word) {
            if (!node->children[c]) node->children[c] = new TrieNode();
            node = node->children[c];
        }
        node->isEnd = true;
    }
};

class Solution {
public:
    string addBoldTag(string s, vector<string>& words) {
        Trie trie;
        for (const string& word : words) trie.insert(word);

        int n = s.size();
        vector<bool> bold(n, false);

        // 每个起点沿 Trie 下走，end 记最远覆盖
        for (int i = 0; i < n; ++i) {
            TrieNode* node = trie.root;
            int end = 0;
            for (int j = i; j < n; ++j) {
                node = node->children[s[j]];
                if (!node) break;
                if (node->isEnd) end = j + 1;  // 命中完整词，继续找更长的
            }
            for (int k = i; k < end; ++k) bold[k] = true;
        }

        // 边沿检测拼标签
        string res;
        for (int i = 0; i < n; ++i) {
            if (bold[i] && (i == 0 || !bold[i - 1])) res += "<b>";
            res += s[i];
            if (bold[i] && (i == n - 1 || !bold[i + 1])) res += "</b>";
        }
        return res;
    }
};
```

---

## 核心理解

### 1. `end` 必须取最远命中，不能首次命中就停

词表含 `"aa"` 和 `"aaa"` 时，从 `i` 出发先在 j+1 命中 `"aa"`，若此时停手就只标记两个字符，丢掉 `"aaa"` 的覆盖。继续下走、`isEnd` 处持续刷新 `end`，最远距离天然包含所有较短命中——**区间是连续前缀，最长的一个就够了**，不用逐个记录。

### 2. 区间合并用布尔数组，别维护区间列表

"合并重叠/相邻区间"若用区间列表做，要排序、判重叠、合并，一套区间 DP 的复杂度。换成 `bool bold[n]` 后合并是**免费的**：重叠只是同一个位置被置两次 true。这是"**把区间问题转成逐点标记**"的范式，和 253 的差分扫描线是同一思想的两端（那边聚合计数，这边聚合布尔）。

### 3. 拼标签的两种等价写法

- **边沿检测**（本解）：插 `<b>` 看 `bold[i] && !bold[i-1]`，插 `</b>` 看 `bold[i] && !bold[i+1]`，边界处用 `i==0` / `i==n-1` 兜底；
- **状态机**（对拍 oracle 用）：维护 `in` 标志，进段开标签、出段收标签，结尾若 `in` 未收则补 `</b>`。

前者无状态、每个位置只看邻居；后者有状态、逻辑更直白。都会写，互相能对拍。

### 4. Trie 数组版的两个前提

`children[128]` 直接定址 + `memset` 清零，成立依赖：字符集在 ASCII 内（题面限定字母数字）且 `char` 值非负。**若字符串可能含高位字节，`char` 为负数时下标越界是 UB**，要转 `unsigned char` 或改 `unordered_map`。内存释放在 LC 环境无所谓，工程代码里 Trie 要配套析构。

## 复杂度

| | 时间 | 空间 |
|--|------|------|
| Trie + 标记 | O(n²) 最坏（每个起点下走一整段）+ Σ\|word\| | O(128·节点数 + n) |

n ≤ 1000 完全够用；更大规模应换 Aho-Corasick（多模式串一次扫描）。

验证：对拍**不用 Trie** 的独立实现（逐单词 `s.compare` 朴素查找 + 状态机拼接）。官方 3 样例（其中样例 3 纠正了"凭印象写错期望值"的测试侧错误：正确输出 `<b>aaabbc</b>c`，`bc` 命中的是下标 4 的 b,c 而非下标 3 的 b,b）+ **穷举 {a,b} 上全部长度 ≤ 8 的 s × 14 词池中 ≤3 元的全部词表组合**（239,700 组）+ 400 组字母数字随机，**240,103 条断言全过**。

## 踩坑点 / 注意点

- ❌ **`end` 首次命中即停**。见核心理解 1——词表有前缀关系的词时必漏覆盖。
- ❌ **标签位置插反**：`<b>` 在字符**前**、`</b>` 在字符**后**；边沿判断的邻居下标（i−1 看开头、i+1 看结尾）写反会把标签插进段中间。
- ❌ **`children[s[j]]` 不判空就继续下移**。Trie 下走每步都要判 `nullptr`，断了立即 break。
- ⚠️ **空词表**：Trie 为空树，第一次下走就 break，bold 全 false，输出原串——自然正确，不用特判。
- ⚠️ **测试侧教训**：凭印象写期望输出（样例 3 写成 `<b>aaabbbc</b>c`）差点冤枉了正确代码——**期望值必须按题意推导或查官方，不能靠记忆**。
