# 最小回文重排 I（3517. Smallest Palindromic Rearrangement I）

## 题意

给定一个**回文字符串** `s`（仅含小写英文字母），重新排列它的字符，返回能得到的**字典序最小的回文串**。

```
输入: s = "z"
输出: "z"

输入: s = "babab"
输出: "abbba"
解释: "babab" 的重排中，"abbba" 是字典序最小的回文串。

输入: s = "daccad"
输出: "acddca"
```

---

## 思路

### 关键观察

1. **回文的充要条件**：最多只有一个字符出现奇数次（它只能放正中间），其余字符必须成对对称分布。
2. **字典序最小 ⇒ 小的字符尽量靠前**。回文串由左半部分唯一决定（右半是左半的反转），所以只需让**左半部分字典序最小**——把每个字符的一半按从小到大排列即可。
3. 构造公式：`答案 = 左半 + 中间字符 + reverse(左半)`。

### 步骤

1. 统计每个字符的出现次数。
2. 按字符从小到大遍历：奇数次的字符减一（留一个放中间），剩下的一半追加到左半。
3. 拼接 `左半 + 中间 + 左半反转`。

## 代码

### 解法一：`map` 计数

```cpp
class Solution {
public:
    string smallestPalindrome(string s) {
        map<char, int> cnt;
        for (const auto& c : s) {
            cnt[c]++;
        }
        
        string mid = "";
        string result;
        result.reserve(s.size() / 2);  // 预分配内存，避免多次扩容
        
        for (auto& [k, v] : cnt) {
            if (v % 2 == 1) {
                mid += k;
                v--;  // 将奇数频次减为偶数
            }
            // 直接添加一半字符到 result，避免内层循环
            result.append(v / 2, k);  // O(v/2) 但内存拷贝更高效
        }
        
        // 构建回文：前半部分 + 中间字符 + 前半部分反转
        return result + mid + string(result.rbegin(), result.rend());
    }
};
```

**注意**：`map` 按键有序，遍历 `cnt` 天然就是字符从小到大，省去显式排序。

### 解法二：数组计数

字符集固定为 26 个小写字母，用定长数组替代 `map`，常数更小、缓存更友好：

```cpp
class Solution {
public:
    string smallestPalindrome(string s) {
        // 使用数组替代 map：字符范围为 'a'-'z'，固定 26 个槽位
        int cnt[26] = {0};
        for (const auto& c : s) {
            cnt[c - 'a']++;
        }
        
        string mid = "";
        string result;
        result.reserve(s.size() / 2);  // 预分配内存，避免多次扩容
        
        for (int i = 0; i < 26; i++) {
            if (cnt[i] % 2 == 1) {
                mid += ('a' + i);
                cnt[i]--;  // 将奇数频次减为偶数
            }
            // 直接添加一半字符到 result，避免内层循环
            result.append(cnt[i] / 2, 'a' + i);  // O(cnt[i]/2) 批量拷贝
        }
        
        // 构建回文：前半部分 + 中间字符 + 前半部分反转
        return result + mid + string(result.rbegin(), result.rend());
    }
};
```

**特点**：下标 `0..25` 顺序遍历等价于字符升序，和 `map` 版本逻辑完全一致，但去掉了 `map` 的平衡树开销（标准只规定 `map` 的复杂度，红黑树是 libstdc++/libc++/MSVC 的事实实现，不是语言保证）。

## 关键细节

### 1. 为什么左半决定整个回文

回文串关于中心对称，右半必然是左半的反转。要让整体字典序最小，只需让左半字典序最小；而左半的字符集合固定（每个字符取一半），字典序最小的排列就是**升序排列**。

### 2. 中间字符的唯一性

题目保证 `s` 本身是回文串，所以**最多一个**字符出现奇数次，`mid` 实际长度 ≤ 1。代码里 `mid` 用 `string` 而非 `char`，是为了兼容"无中间字符"（空串）的情况，逻辑更统一。

### 3. 两种计数方式对比

| | `map` | 数组 |
|--|-------|------|
| 有序性 | 自动有序 | 下标即顺序 |
| 时间 | O(n + 26 log 26) | **O(n + 26)** |
| 常数开销 | 红黑树，大 | **连续内存，小** |
| 适用字符集 | 任意 | 已知且较小 |
| 推荐度 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |

（渐进复杂度都是 O(n)，差距只在常数；字符集大到稀疏时 `map`/`unordered_map` 才有优势。）

| `map` 计数 | O(n) | O(1)（最多 26 个键） |

## 踩坑点 / 注意点

- ❌ **整个字符串排序后再拼**。排序后的串不是回文，必须先减半再构造。
- ❌ **用内层循环逐个追加字符**。`result.append(v / 2, k)` 一次批量拷贝，比 `for` 循环 `push_back` 高效。
- ❌ **忘记奇数次字符减一**。不减一的话该字符会被多算进左半，拼出来长度不对、也不再是重排。
- ❌ **假设一定有中间字符**。偶数长度回文没有中间字符，`mid` 必须允许为空。
