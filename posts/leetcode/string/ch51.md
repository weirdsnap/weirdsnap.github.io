# 每个字符最多出现两次的最长子字符串（3090. Maximum Length Substring With Two Occurrences）

## 题意

给定小写字母字符串 `s`，求**每个字符最多出现两次**的最长子字符串长度。

```
输入: s = "bcbbbcba"
输出: 4
解释: "bcba" 合法（b 出现 2 次，c 和 a 各 1 次）。"bbbc" 中 b 出现 3 次不合法。

输入: s = "aaaa"
输出: 2
```

约束：`1 <= s.length <= 100`，只含小写字母。

---

## 思路：滑动窗口模板

维护窗口 `[left, right]`，右指针每次扩张一格，若导致某字符超过 2 次，左指针收缩到合法为止。每一步窗口都是"以 right 结尾的最长合法子串"，全程取最大。

```cpp
class Solution {
public:
    int maximumLengthSubstring(string s) {
        int left = 0, right = 0, len = 0;
        vector<int> cnt(26, 0);

        while (right < s.size()) {
            cnt[s[right] - 'a']++;                    // 扩张
            while (cnt[s[right] - 'a'] > 2) {         // 收缩到合法
                cnt[s[left] - 'a']--;
                left++;
            }
            len = max(len, right - left + 1);         // 记录
            right++;
        }
        return len;
    }
};
```

---

## 关键细节

### 1. 为什么滑动窗口是对的

滑动窗口适用于"**窗口合法性单调**"的问题：一个子串不合法（某字符 > 2 次），则任何包含它的更长子串也不合法。所以右指针每扩张一格，左指针只需向右收缩，不用回退——每个下标最多被左右指针各访问一次，O(n)。

反例：如果约束改成"某字符恰好 2 次"，合法性不再单调，滑动窗口就不适用了。

### 2. 收缩循环只检查新加入的字符

`while (cnt[s[right]] > 2)` 只看刚加入的 `s[right]`——因为加入前窗口是合法的，唯一可能被破坏的就是这个字符。不用扫描整个 cnt 数组。

### 3. 计数用数组不用 map

字符集固定 26 个小写字母，`vector<int> cnt(26, 0)` 直接索引，比 `map`/`unordered_map` 省掉哈希开销——和 [3517 最小回文重排](./blog.html?post=leetcode/string/ch33.md) 的优化是同一招。

## 复杂度

| 指标 | 滑动窗口 | 暴力枚举子串 |
|------|---------|-------------|
| 时间 | O(n) | O(n²) |
| 空间 | O(26) = O(1) | O(1) |

对拍验证：500 组随机小字符集字符串（`n ≤ 30`，字符集 6 个字母，容易撞出超 2 次的情况）与暴力版完全一致。

---

## 踩坑点 / 注意点

- ❌ **用 `if` 收缩而不是 `while`**。一次扩张可能引入多个超限？不会——每步只加一个字符，最多超 1 次。但收缩可能要移动多步（窗口里早就有 2 个该字符），`if` 只收缩一步就停，窗口仍不合法。
- ❌ **先 `right++` 再记录长度**。顺序错了会漏掉以最后一个字符结尾的窗口。
- ❌ **字符集想当然用 map**。小写字母固定 26 个，数组直接索引更快更省。
