# 大于 target 的最小字典序回文排列（3734. Lexicographically Smallest Palindromic Permutation Greater Than Target）

## 题意

给定等长字符串 `s` 和 `target`（小写字母）。返回 `s` 的**回文**排列中**严格大于** `target` 的、字典序最小者；不存在返回 `""`。

```
输入: s = "baba", target = "abba"
输出: "baab"

输入: s = "baba", target = "bbaa"
输出: ""

输入: s = "abc", target = "abb"
输出: ""
解释: s 根本无法构成回文（三个字符都是奇数次）。

输入: s = "aac", target = "abb"
输出: "aca"
```

约束：`1 <= n == s.length == target.length <= 300`。周赛 474 Q4，Hard。

---

## 思路：回文由前半段决定，问题退化成 3720

回文串只要前半段定了，整串就定了（`前半 + 中心字符 + 前半的反转`）。所以：

1. 统计字符砍半，得到**前半段字符池** `s_cnt`；奇数次的字母当中心 `mid`，**超过一个就直接返回 `""`**
2. 在前半段上跑 3720 的"从右找分界位"流程（[ch71](./blog.html?post=leetcode/string/ch71.md)）
3. 找到后用 `makePal` 镜像拼回整串

```cpp
class Solution {
public:
    string lexPalindromicPermutation(string s, string target) {
        // === 1. 砍半得到前半段字符池，奇数字母作中心 ===
        const int n = s.size();
        vector<int> s_cnt(26, 0);
        char mid = 0;
        for (char c : s) s_cnt[c - 'a']++;
        for (int i = 0; i < 26; i++) {
            if (s_cnt[i] % 2) {
                if (mid != 0) return "";   // 超过 1 个奇数字母，无法回文
                mid = 'a' + i;
            }
            s_cnt[i] /= 2;
        }

        // === 2. 前半段"恰好等于 t"的快捷分支（见核心理解 1）===
        int m = n / 2;
        string t = target.substr(0, m);

        bool tFeasible = true;             // t 能由字符池构成吗
        vector<int> tmp = s_cnt;
        for (char c : t) {
            if (tmp[c - 'a'] == 0) { tFeasible = false; break; }
            tmp[c - 'a']--;
        }

        // 拼接回文：p + mid(如有) + reverse(p)
        auto makePal = [&](string p) {
            string ans = p;
            if (mid) ans += mid;
            string r = p;
            reverse(r.begin(), r.end());
            return ans + r;
        };

        bool canEqual = makePal(t) > target;  // 前半段 == t 时整串已严格大于吗

        if (canEqual && tFeasible) return makePal(t);

        // === 3. 3720 流程：前半段上从右往左找分界位 ===
        for (int i = 0; i < m; i++) s_cnt[t[i] - 'a']--;   // 扣掉 t，变库存差

        for (int i = m - 1; i >= 0; i--) {
            s_cnt[t[i] - 'a']++;         // 前缀缩短一位，还回 t[i]
            bool valid = true;
            for (int c : s_cnt) {
                if (c < 0) { valid = false; break; }
            }
            if (!valid) continue;
            for (int j = t[i] - 'a' + 1; j < 26; j++) {
                if (s_cnt[j] == 0) continue;
                s_cnt[j]--;
                t[i] = 'a' + j;
                t.resize(i + 1);
                for (int k = 0; k < 26; k++) t += string(s_cnt[k], 'a' + k);
                return makePal(t);
            }
        }
        return "";
    }
};
```

## 核心理解

### 1. 比 3720 多出来的唯一难点："相等的前半段"也可能是答案

3720 里答案必须**严格大于** `target`，所以前半段等于 `target` 前缀没有意义，必须从某个分界位放大。本题不一样：前半段**恰好等于** `t = target[0..m-1]` 时，镜像出来的尾巴可能已经超过 `target` 的尾巴——比如 `t = "ab"`、`target = "abba"`，拼出 `"abba"` 等于 target 不行；但若 `target = "abaa"`，`"abba" > "abaa"` 就成立了。

所以主循环之前要有 `canEqual && tFeasible` 的快捷分支：**整串**和 `target` 比（不是拿前半段比），成立且 `t` 构造得出来，直接收工。漏掉这个分支，答案会错误地往"前半段必须严格大于 t"的方向找，漏掉恰好相等的合法解。

### 2. 奇偶判定是回文排列的总开关

回文排列存在 ⟺ 奇数次字符 ≤ 1 个。砍半循环顺手做两件事：奇数字母记为 `mid`（第二个奇数立即返回 `""`），所有计数 `/= 2` 变成前半段字符池。样例 3（`s = "abc"`）走的就是这条早退路径。

### 3. 库存差数组原样复用

主循环就是 3720 单数组版（ch71 解法二）：先扣掉 `t` 的全部字符把 `s_cnt` 变成库存差，回退时 `s_cnt[t[i]]++` 还回，`>= 0` 全成立即前缀可行，放最小的大字符、右侧升序、`makePal` 镜像。3720 想通后这题的主循环是默写。

| 指标 | 值 |
|------|----|
| 时间 | O(n × 26) |
| 空间 | O(26) + 输出 |

验证：穷举 {a,b,c} 上全部长度 ≤ 7 的 (s, target) 配对（约 538 万对）+ 400 组字母表 26 的随机对，与"穷举前半段全部独特排列拼回文取最小"的暴力版逐一对拍。5,381,243 条断言全过。

## 踩坑点 / 注意点

- ❌ **漏掉 `canEqual` 快捷分支**。前半段等于 t 时整串仍可能严格大于 target（镜像尾巴的功劳），只找"严格大于 t 的前半段"会漏解。见核心理解 1。
- ❌ **`canEqual` 拿前半段和 target 前缀比**。必须拼出**整串**再比——决定大小关系的可能是镜像尾巴部分。
- ❌ **奇偶判定只记 `mid` 不早退**。两个奇数字母时任何排列都不是回文，必须返回 `""`（样例 3）。
- ❌ **砍半写成 `(cnt - 1) / 2`**。整数除法 `cnt / 2` 对奇数天然是"减一砍半"，多此一举还容易写错。
