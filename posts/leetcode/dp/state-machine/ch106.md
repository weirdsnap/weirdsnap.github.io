# K 条不重叠线段的方案数（1621. Number of Sets of K Non-Overlapping Line Segments）

## 题意

数轴上 `n` 个点 `0 ~ n-1`，要选出**恰好 k 条**线段，每条线段的端点都在这些点上，线段之间不重叠（**允许端点相触**，即一条的右端点可以是下一条的左端点）。求方案数，对 `1e9+7` 取模。

```
输入: n = 4, k = 2     输出: 5
输入: n = 3, k = 1     输出: 3
输入: n = 30, k = 7    输出: 796297179
```

- `2 <= n <= 1000`，`1 <= k <= n-1`

## 思路

三个视角，一个比一个省空间：

1. **状态机**：按点扫描，每个点只有"某条线段开着"和"没有线段开着"两种状态，转移就是开/关/延续；
2. **计数 DP + 前缀和**：`dp[i][j]` 表示前 `j+1` 个点上恰好 `i` 条线段的方案数，按"最后一条线段的右端点是不是 `j`"分类，"是 `j`"的那一项是个前缀和，边扫边维护；
3. **滚动数组**：解法二的 `i` 层只依赖 `i-1` 层，压掉第一维。

## 解法一：状态机（开 / 关）

```cpp
class Solution {
public:
    int numberOfSets(int n, int k) {
        const int MOD = 1e9 + 7;

        // dp[i][j][0]：处理到点 i，已完成 j 条线段，当前"关"
        // dp[i][j][1]：处理到点 i，已完成 j 条线段，当前"开"
        vector<vector<vector<long long>>> dp(n, vector<vector<long long>>(k + 1, vector<long long>(2, 0)));

        // 初始：第 0 个点，不开 或 开启第 1 条线段（完成 0 条）
        dp[0][0][0] = 1;
        dp[0][0][1] = 1;

        for (int i = 1; i < n; i++) {
            for (int j = 0; j <= k; j++) {
                // 先处理"关"状态，保证"先关"在"后开"之前完成

                // 0 -> 0：延续"关"
                dp[i][j][0] = (dp[i][j][0] + dp[i-1][j][0]) % MOD;

                // 1 -> 0：在点 i 关闭当前线段，完成一条
                if (j + 1 <= k) {
                    dp[i][j + 1][0] = (dp[i][j + 1][0] + dp[i-1][j][1]) % MOD;
                }

                // 再处理"开"状态，此时 dp[i][j][0] 已包含"同一点先关再开"的贡献

                // 0 -> 1：在点 i 开启一条新线段（j 不变）
                // 注意：这里的 dp[i][j][0] 已经是"关"完成之后的值，蕴含了端点重合的情况
                dp[i][j][1] = (dp[i][j][1] + dp[i][j][0]) % MOD;

                // 1 -> 1：延续"开"
                dp[i][j][1] = (dp[i][j][1] + dp[i-1][j][1]) % MOD;
            }
        }

        return dp[n - 1][k][0];
    }
};
```

## 解法二：计数 DP + 前缀和

```cpp
class Solution {
public:
    int numberOfSets(int n, int k) {
        const int MOD = 1e9 + 7;
        // dp[i][j]：在 [0, j] 这 j+1 个点上构造恰好 i 条线段的方案数
        vector<vector<long long>> dp(k + 1, vector<long long>(n, 0));

        // 边界：0 条线段时，任意点集都只有"不选"这一种方案
        for (int j = 0; j < n; j++) {
            dp[0][j] = 1;
        }

        for (int i = 1; i <= k; i++) {
            // prefix：累加 dp[i-1][p]，p 从 0 到 j-1，即 sum_{p=0}^{j-1} dp[i-1][p]
            long long prefix = 0;
            for (int j = 1; j < n; j++) {
                // 边遍历边累加上一层的 dp[i-1][j-1]，得到当前 j 所需前缀和
                prefix = (prefix + dp[i - 1][j - 1]) % MOD;
                // 情况1：最后一条线段右端点不是 j → dp[i][j-1]
                // 情况2：最后一条线段右端点是 j → prefix（即 sum_{p=0}^{j-1} dp[i-1][p]）
                dp[i][j] = (dp[i][j - 1] + prefix) % MOD;
            }
        }

        return dp[k][n - 1];
    }
};
```

## 解法三：滚动数组

```cpp
class Solution {
public:
    int numberOfSets(int n, int k) {
        const int MOD = 1e9 + 7;
        // dp[j]: 在当前处理的点集上构造恰好 (i+1) 条线段时的方案数（滚动数组）
        // prefixSums[t]: 表示 sum_{p=0}^{t-1} dp_prev[p]，用于 O(1) 计算前缀和
        vector<int> dp(n, 1);            // i=0 时：0 条线段只有"不选"一种方案，dp[j]=1
        vector<int> prefixSums(n + 1, 0);

        // 初始化第一层（i=0）的前缀和
        for (int j = 0; j < n; j++) {
            prefixSums[j + 1] = (prefixSums[j] + dp[j]) % MOD;
        }

        // 逐层增加线段数 i（从 1 到 k）
        for (int i = 1; i <= k; i++) {
            dp[0] = 0;  // 没有任何点（j=0）时无法构造 i>0 条线段
            for (int j = 0; j < n; j++) {
                // dp[j] = 右端点不是 j 的方案 + 右端点是 j 的方案
                // 右端点是 j：sum_{p=0}^{j-1} dp_prev[p] 即 prefixSums[j]
                dp[j] = (dp[j - 1] + prefixSums[j]) % MOD;
            }
            // 更新本层（线段数 i）的前缀和，供下一层使用
            for (int j = 0; j < n; j++) {
                prefixSums[j + 1] = (prefixSums[j] + dp[j]) % MOD;
            }
        }

        return dp[n - 1];
    }
};
```

## 核心理解

### 1. 状态机里"先关后开"是端点相触的关键

题目允许两条线段共享一个端点。解法一用**同一轮内的更新顺序**处理这件事：先算完"关"（`0→0` 和 `1→0`），再算"开"（`0→1`），这样 `0→1` 读到的 `dp[i][j][0]` 已经包含"在点 `i` 刚关闭一条"的方案——于是"在点 `i` 先关一条、紧接着开一条"被自然计入，且只计一次。如果把 `0→1` 的源改成 `dp[i-1][j][0]`，端点相触的方案就全丢了。注释里那句"先关在后开之前完成"是这版代码的灵魂。

### 2. 解法二的分类：右端点是不是 j

`dp[i][j]` 按"第 `i` 条线段的右端点"分两类：

- 不是 `j`：方案数就是 `dp[i][j-1]`（点 `j` 白给）；
- 是 `j`：左端点 `l` 可以落在 `0..j-1`，且前 `i-1` 条线段必须收在 `[0, l]` 内（允许 `r = l` 相触），对 `l` 求和是 `sum_{p=0}^{j-1} dp[i-1][p]`——一个前缀和，`j` 递增时滚动累加即可，不用每层重算。

### 3. 滚动数组的两个指针各管一层

解法三里 `dp[j-1]` 是**本层**刚算好的（对应"右端点不是 j"），`prefixSums[j]` 是**上一层**的（对应"右端点是 j"）。内层循环从左往右，读 `dp[j-1]` 写 `dp[j]`，层间不串；每层结束再整体重建 `prefixSums`。`dp[0] = 0` 每层都要重置：`i > 0` 条线段至少需要 `i+1` 个点，单个点上方案数为 0，而它继承自上一层的 `dp[0] = 1`，不清掉就错了。

### 4. 答案其实有封闭形式：C(n+k-1, 2k)

答案恒等于 **C(n+k-1, 2k)**。组合直觉：k 条线段共 2k 个端点，"允许相触"意味着相邻端点可以重合，相当于在端点序列里允许"空隙为 0"——把每个空隙加 1 摊平后，就变成从 `n+k-1` 个位置里选 `2k` 个的标准组合。

## 复杂度

| | 解法一 | 解法二 | 解法三 |
|--|--------|--------|--------|
| 时间 | O(nk) | O(nk) | O(nk) |
| 空间 | O(nk) | O(nk) | O(n) |

## 踩坑点

### ❌ 解法三忘记每层重置 `dp[0] = 0`

`dp` 初始化为全 1（0 条线段的边界），进入 `i = 1` 层后 `dp[0]` 还是 1，但"1 条线段、只有 1 个点"的方案数应该是 0。漏掉这行，错误会沿 `dp[j] = dp[j-1] + ...` 一路污染整层。

### ⚠️ 解法三的 `int` 是踩着线过的

`prefixSums[j] + dp[j]` 最大约 `2 × 1e9`，刚好小于 `INT_MAX`，单次加法不溢出。但这没有任何余量——模数稍大或连加两项就越界。自己写模板时一律 `long long`，别学这版省。
