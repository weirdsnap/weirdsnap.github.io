# 机器人能获得的最大金币数（3418. Maximum Amount of Money Robot Can Earn）

## 题意

`n × m` 网格，机器人从左上角走到右下角，每步只能**向右或向下**。每格有整数 `coins[i][j]`：正数是金币，负数是劫匪（会被抢走）。机器人可以**感化最多 2 格**的劫匪，经过被感化的格子不损失金币。求到达终点时能获得的**最大金币数**（可以为负）。

```
输入: coins = [[0,1,-1],[1,-2,3],[2,-3,4]]
输出: 8
解释: 路径 (0,0)→(0,1)→(0,2)→(1,2)→(2,2)，感化 (0,2) 和 (1,2) 的劫匪
     总收益 = 0+1+0+0+4 ... 实际最优为 8
```

约束：`n, m <= 500`，`-1000 <= coins[i][j] <= 1000`。

---

## 思路

在经典路径 DP（ch43 不同路径）的基础上加一个维度：**已使用的感化次数**。

### 状态定义

`dp[i][j][c]` = 到达 `(i, j)` 且已使用 `c` 次感化（`c ∈ {0,1,2}`）时的最大金币数。

### 状态转移

到达 `(i, j)` 时，对当前格只有两种决策：

1. **照付**：感化次数不变，`dp[来源][c] + coins[i][j]`
2. **感化**（仅 `c > 0`）：从 `c - 1` 的状态转移，本格取 0

来源有上方和左方两个，所以每个 `c` 最多 4 个候选：

```
dp[i][j][c] = max( dp[i-1][j][c] + coins,  // 上，照付
                   dp[i][j-1][c] + coins,  // 左，照付
                   dp[i-1][j][c-1],        // 上，本格感化
                   dp[i][j-1][c-1] )       // 左，本格感化
```

### 三维朴素版

先把状态写全，逻辑直白，不容易错：

```cpp
class Solution {
public:
    int maximumAmount(vector<vector<int>>& coins) {
        const int n = coins.size();
        const int m = coins[0].size();
        // dp[i][j][c]: 到达 (i,j) 且已使用 c 次感化时的最大金币
        int dp[500][500][3];  // 注意: 3MB 栈数组，见踩坑点
        for (int i = 0; i < n; ++i)
            for (int j = 0; j < m; ++j)
                for (int c = 0; c < 3; ++c)
                    dp[i][j][c] = INT_MIN / 2;

        // 起点：不感化用 0 次；感化为负起点则用 1 次
        dp[0][0][0] = coins[0][0];
        dp[0][0][1] = (coins[0][0] < 0) ? 0 : coins[0][0];
        dp[0][0][2] = dp[0][0][1];  // 起点最多用 1 次，2 次与 1 次等价

        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < m; ++j) {
                if (i == 0 && j == 0) continue;
                for (int c = 0; c <= 2; ++c) {
                    // 照付：同化次数不变
                    int best = INT_MIN / 2;
                    if (i > 0) best = max(best, dp[i - 1][j][c]);
                    if (j > 0) best = max(best, dp[i][j - 1][c]);
                    if (best != INT_MIN / 2)
                        dp[i][j][c] = best + coins[i][j];

                    // 感化：仅对负数格尝试，从 c-1 转移，本格取 0
                    if (c >= 1 && coins[i][j] < 0) {
                        int best_save = INT_MIN / 2;
                        if (i > 0) best_save = max(best_save, dp[i - 1][j][c - 1]);
                        if (j > 0) best_save = max(best_save, dp[i][j - 1][c - 1]);
                        if (best_save != INT_MIN / 2)
                            dp[i][j][c] = max(dp[i][j][c], best_save);
                    }
                }
            }
        }

        return max({dp[n - 1][m - 1][0], dp[n - 1][m - 1][1], dp[n - 1][m - 1][2]});
    }
};
```

这里 `INT_MIN / 2` 表示不可达：既能为负（答案本身可为负），又留出余量避免 `+ coins[i][j]` 时溢出。

### 滚动数组版：更新顺序是命门

`dp[i][j][c]` 只依赖第 `i-1` 行和本行左侧，可以把行维度滚掉。但降维后，`dp[j][c]` 同时承载"上一行的旧值"和"本行的新值"，**必须按 c 降序更新（2 → 1 → 0）**：

```cpp
class Solution {
public:
    int maximumAmount(vector<vector<int>>& coins) {
        const int n = coins.size();
        const int m = coins[0].size();
        int dp[500][3];  // dp[j][c]：当前行第 j 列，已用 c 次感化

        // 第一行：只能从左边来
        dp[0][0] = coins[0][0];
        dp[0][1] = 0;  // 感化起点，收益 0
        dp[0][2] = 0;
        for (int j = 1; j < m; j++) {
            dp[j][0] = dp[j - 1][0] + coins[0][j];
            dp[j][1] = max(dp[j - 1][0], dp[j - 1][1] + coins[0][j]);
            dp[j][2] = max(dp[j - 1][1], dp[j - 1][2] + coins[0][j]);
        }

        for (int i = 1; i < n; i++) {
            // 第一列：只能从上方来，c 降序更新
            dp[0][2] = max(dp[0][2] + coins[i][0], dp[0][1]);
            dp[0][1] = max(dp[0][1] + coins[i][0], dp[0][0]);
            dp[0][0] = dp[0][0] + coins[i][0];

            for (int j = 1; j < m; j++) {
                dp[j][2] = max({
                    dp[j - 1][2] + coins[i][j],  // 左，照付
                    dp[j - 1][1],                // 左，本格感化
                    dp[j][2] + coins[i][j],      // 上，照付（旧值）
                    dp[j][1]                     // 上，本格感化（旧值）
                });
                dp[j][1] = max({
                    dp[j - 1][1] + coins[i][j],
                    dp[j - 1][0],
                    dp[j][1] + coins[i][j],
                    dp[j][0]
                });
                dp[j][0] = max(dp[j - 1][0], dp[j][0]) + coins[i][j];
            }
        }

        return ranges::max(dp[m - 1]);
    }
};
```

## 关键细节

### 1. 为什么必须 c 降序更新？

看 `dp[j][2]` 的感化转移：它读 `dp[j][1]`，此时需要的是**上一行**（旧值）的 `dp[j][1]`。如果先更新了 `dp[j][1]`（本行新值），`dp[j][2]` 读到的是"本行同列、感化 1 次"——语义变成在同一格反复感化，状态污染。

实测证据：把顺序改成 c 升序（0 → 1 → 2），随机对拍 2000 组有 **856 组出错**；手造用例第一列全是 `-5` 时，正确答案 -2（感化两个、照付一个），错误顺序给出 3。

这和 0-1 背包倒序枚举体积是同一个道理（ch22）：**滚动数组里，读"旧值"的下标必须比当前更新的下标晚更新**。

### 2. 感化转移不需要区分正负

朴素版里感化分支写了 `coins[i][j] < 0` 的判断，但滚动版直接对所有格子尝试感化（`dp[j-1][c-1]` 取 0）——**这是安全的**：正数格感化的收益是 +0，而照付的收益是 `+coins[i][j] >= 0`，感化永远不会比照付更优，max 自然会把它淘汰。省掉符号判断，代码更对称，四种转移对正负格统一处理。

三个版本（滚动 / 三维无符号判断 / 三维有符号判断）随机对拍 300 组全部一致，证实这个化简不改变答案。

### 3. 起点初始化的含义

`dp[0][1] = dp[0][2] = 0` 表示"在起点就用掉感化机会"。若 `coins[0][0]` 是负数，这是对的（感化起点收益 0 比倒扣好）；若是正数，这个状态虽然存在但永远不会被 max 选中，无害。不需要特判。

### 4. 答案可以为负

如果路径上的劫匪超过 2 格，感化不够用，总收益可以是负的。所以不能用 `0` 或 `-1` 当"无效状态"标记，三维参照版里我用 `-1e9` 表示不可达。

### 5. `ranges::max` 对数组直接求最大值

`ranges::max(dp[m - 1])` 直接对 `int[3]` 求最大，省去手写循环——这是 ch37（152 题）里 `max({a, b, c})` 的 range 版亲戚。

## 复杂度

| 指标 | 三维 DP | 滚动数组 |
|------|---------|----------|
| 时间 | O(n · m · 3) | O(n · m · 3) |
| 空间 | O(n · m · 3) | O(m · 3) |

`n, m <= 500` 时滚动数组只占 `500 × 3` 个 int，6 KB。

---

## 踩坑点 / 注意点

- ❌ **滚动数组 c 升序更新**。`dp[j][c]` 读到被污染的 `dp[j][c-1]` 新值，对拍 856/2000 出错。降序是必须的，不是风格选择。
- ❌ **用 0 或 -1 表示不可达**。答案本身可以为负，会和真实状态混淆。
- ❌ **忘记"感化本格取 0"还是"取 coins"**。感化是不损失，即加 0，不是加 `coins[i][j]`。
- ❌ **第一列/第一行忘记单独初始化**。它们只有一个来源方向，通用四候选公式会越界或读到脏值。
- ❌ **三维数组直接开在栈上**。`int dp[500][500][3]` 约 3MB，Linux/macOS 主线程默认栈约 8MB（本机 macOS 实测 `ulimit -s` = 8176 KB）勉强够用，但 Windows MSVC 默认只有 1MB、子线程栈通常更小，稍大就爆栈。稳妥做法是 `static`（挪到 BSS 段）或堆分配——这也是滚动数组的隐性收益之一。
