# 不同路径（62. Unique Paths）

## 题意

`m × n` 网格，从左上角走到右下角，每步只能向右或向下。返回不同的路径总数。

```
输入: m = 3, n = 7
输出: 28

输入: m = 3, n = 2
输出: 3
解释: 右→下→下、下→右→下、下→下→右。
```

约束：`1 <= m, n <= 100`，答案保证不超过 `2×10⁹`。

---

## 思路

路径 DP 的入门题：到达 `(i, j)` 只能从上方 `(i-1, j)` 或左方 `(i, j-1)` 来，所以

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

边界：第一行和第一列都只有一条路径（一直向右 / 一直向下），全为 1。

`dp[i][j]` 只依赖上一行同列和本行左侧，可以压成一维滚动数组：`dp[j]` 更新前是 `dp[i-1][j]`，`dp[j-1]` 是本行刚算出的 `dp[i][j-1]`，原地 `dp[j] += dp[j-1]` 即可。

---

## 代码

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        // 保证 n 为较小维度，使 dp 数组更短，减少内存与循环次数
        if (m < n) swap(m, n);
        vector<int> dp(n, 1);
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[j] = dp[j - 1] + dp[j]; // dp[j] 来自上一行同列，dp[j-1] 来自当前行左侧
            }
        }
        return dp[n - 1];
    }
};
```

**注意**：`if (m < n) swap(m, n)` 是个实用的小优化——网格是对称的（`m × n` 和 `n × m` 答案相同），让列数保持较小，滚动数组更短，内层循环也更少。

---

## 关键细节

### 1. 为什么初始化整行 `dp` 为 1 是对的

第一行只能从左边来，路径数全为 1；滚动数组初始化为全 1 正好同时覆盖了"第一行全是 1"和"每一行 `j = 0` 处是 1"（第一列只能从上边来，`dp[0]` 永远不动）。对比 [63 题（带障碍物）](./blog.html?post=leetcode/dp/path/ch42.md) 就不能这么初始化——障碍物的截断效果必须靠主循环逐格传播。

### 2. 组合数学解法（O(1) 空间）

从左上到右下一共要走 `m + n - 2` 步，其中选 `m - 1` 步向下（或 `n - 1` 步向右），答案就是组合数 `C(m + n - 2, m - 1)`。注意计算时要边乘边除防止溢出：

```cpp
long long res = 1;
for (int i = 1; i <= m - 1; i++)
    res = res * (n - 1 + i) / i;  // 每步都能整除
```

DP 的价值在于通用性——加障碍物（63 题）、加权重（64 题）后组合数就用不了了，但 DP 框架原样适用。

## 复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(m × n) | 每个格子访问一次 |
| 空间 | O(min(m, n)) | 滚动数组取较小维度；组合数解法 O(1) |

---

## 踩坑点 / 注意点

- ❌ **内层循环从 `j = 0` 开始**。`dp[0]` 是第一列，恒为 1 不能被更新；从 `j = 0` 开始会读到越界的 `dp[-1]` 或污染第一列。
- ❌ **`swap(m, n)` 后还按原来的维度理解代码**。交换后 `n` 永远是较小维度，`dp` 长度、循环上界都以新 `n` 为准。
