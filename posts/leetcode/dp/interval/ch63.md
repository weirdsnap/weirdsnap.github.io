# 石子游戏 VII（1690. Stone Game VII）

## 题意

一行 `n` 堆石子。轮流移除**最左或最右**的一堆，得分是**移除后剩余区间的总和**（不是被移除那堆的值）。只剩一堆时游戏结束（移除它得 0 分）。Alice 先手，双方都最优，求最终 **Alice − Bob 的分差**。

```
输入: stones = [5,3,1,4,2]
输出: 6
解释: Alice 移除 2，得 5+3+1+4 = 13 分 ... 最终分差 18 - 12 = 6

输入: stones = [7,90,5,1,100,10,10,2]
输出: 122
```

约束：`2 <= n <= 1000`。

---

## 思路：净胜分 + 区间 DP

家族老朋友了（[ch41](./blog.html?post=leetcode/dp/interval/ch41.md) 486 同款两端操作）：

**`dp[i][j]` = 在区间 `stones[i..j]` 上，当前行动玩家的最大净胜分。**

- 移除左端：得 `sum[i+1..j]`，对手接手 `[i+1, j]`，其最优是 `dp[i+1][j]`——取负
- 移除右端：得 `sum[i..j-1] - dp[i][j-1]`

```
dp[i][j] = max( sum[i+1..j] - dp[i+1][j],
                sum[i..j-1] - dp[i][j-1] )
dp[i][i] = 0  （只剩一堆，移除得 0）
```

```cpp
class Solution {
public:
    int stoneGameVII(vector<int>& stones) {
        const int n = stones.size();
        vector<int> prefix(n + 1, 0);
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + stones[i];

        vector<vector<int>> dp(n, vector<int>(n, 0));
        for (int i = n - 2; i >= 0; i--) {
            for (int j = i + 1; j < n; j++) {
                int sumRemoveLeft  = prefix[j + 1] - prefix[i + 1];
                int sumRemoveRight = prefix[j] - prefix[i];
                dp[i][j] = max(
                    sumRemoveLeft  - dp[i + 1][j],
                    sumRemoveRight - dp[i][j - 1]);
            }
        }
        return dp[0][n - 1];
    }
};
```

**特点**：遍历方向还是那套——`i` 降序服务 `dp[i+1][j]`，`j` 升序服务 `dp[i][j-1]`。区间和用前缀和 O(1) 拿。

### 变体一：一维滚动数组

和 486 解法三（[ch41](./blog.html?post=leetcode/dp/interval/ch41.md)）完全相同的压缩逻辑——`dp[j]` 赋值前的旧值正是 `dp[i+1][j]`，`dp[j-1]` 本轮刚更新正是 `dp[i][j-1]`：

```cpp
vector<int> dp(n, 0);
for (int i = n - 2; i >= 0; i--) {
    for (int j = i + 1; j < n; j++) {
        int sumRemoveLeft  = prefix[j + 1] - prefix[i + 1];
        int sumRemoveRight = prefix[j] - prefix[i];
        dp[j] = max(sumRemoveLeft - dp[j],      // 旧值 = dp[i+1][j]
                    sumRemoveRight - dp[j - 1]); // 新值 = dp[i][j-1]
    }
}
return dp[n - 1];
```

### 变体二：len 枚举区间

1563（[ch61](./blog.html?post=leetcode/dp/interval/ch61.md)）风格的按长度枚举，子区间都更短，天然拓扑序，不用管方向：

```cpp
for (int len = 2; len <= n; len++) {
    for (int i = 0; i + len - 1 < n; i++) {
        int j = i + len - 1;
        int sumRemoveLeft  = prefix[j + 1] - prefix[i + 1];
        int sumRemoveRight = prefix[j]     - prefix[i];
        dp[i][j] = max(sumRemoveLeft  - dp[i + 1][j],
                       sumRemoveRight - dp[i][j - 1]);
    }
}
```

三种写法同一转移方程，区别只在遍历拓扑和空间：方向版 O(n²)/O(n²)、滚动版 O(n²)/O(n)、len 版 O(n²)/O(n²)。

## 关键细节

### 1. 得分是"剩余区间的和"，不是被移除的石子

这是本题唯一的题意陷阱。移除 `stones[i]` 得的是 `sum[i+1..j]`——**拿走的越便宜、留下的越多，得分越高**。所以策略直觉和 486 相反：486 想拿大的，这题想扔小的。我第一版就把得分写成了移除石子的值，对拍立刻露馅。

### 2. 终止条件 dp[i][i] = 0

只剩一堆时移除它得"剩余区间（空）的和"= 0。`dp` 零初始化天然覆盖，不用显式写。

### 3. 返回值就是分差

和 1140 不同，这里 `dp[0][n-1]` 直接是题目要的 Alice − Bob 分差，不需要 `(total + diff) / 2` 换算。

| 指标 | 值 |

| 空间 | O(n²)，可压到 O(n) |

验证：方向版 / 一维滚动版 / len 枚举版 / 无记忆化暴力四方对拍 300 组（`n ∈ [2,12]`）完全一致；官方样例 `6` / `122` 均命中。902 条断言全过。

---

## 踩坑点 / 注意点

- ❌ **得分写成移除石子的值**（`prefix[i+1] - prefix[i]`）。题意是剩余区间的和，一字之差，模型全错。
- ❌ **前缀和下标错位**。`[i+1, j]` 的和是 `prefix[j+1] - prefix[i+1]`，不是 `prefix[j] - prefix[i+1]`。
- ❌ **角色互换取负漏掉**。`sum + dp[...]` 变成"一个人一直拿"，家族传统坑第五遍。
