# 石子游戏 IV（1510. Stone Game IV）

## 题意

`n` 块石子，两名玩家轮流拿走**任意平方数**块（1、4、9、...），拿到最后一块的人获胜。Alice 先手，双方都最优，问 Alice 是否必胜。

```
输入: n = 1   输出: true    （拿 1 块直接获胜）
输入: n = 2   输出: false   （只能拿 1，对手拿最后 1 块）
输入: n = 4   输出: true    （拿 4 块直接获胜）
输入: n = 7   输出: false   （1/4 都试过，都送对手进必胜态）
```

约束：`1 <= n <= 10⁵`。

---

## 思路：必胜态 / 必败态的一维 DP

石子游戏家族第五篇，但风味变了：这题**没有分值**，只有输赢。所以净胜分定义（ch41/57/58/59）用不上，换成博弈论更基础的布尔状态：

**`f[i]` = 剩余 `i` 块石头时，当前行动的玩家是否必胜。**

转移一句话：**存在一步让对手落入必败态，则当前必胜**。

```
f[0] = false                       （无石头可取，当前玩家输）
f[i] = OR over k² <= i of  !f[i - k²]
```

```cpp
class Solution {
public:
    bool winnerSquareGame(int n) {
        vector<int> f(n + 1);  // f[0] = 0：必败态
        for (int i = 1; i <= n; ++i) {
            for (int k = 1; k * k <= i; ++k) {  // 枚举可取的平方数
                if (!f[i - k * k]) {            // 对手必败 → 我必胜
                    f[i] = true;
                    break;                      // 找到一步就够
                }
            }
        }
        return f[n];
    }
};
```

**特点**：`break` 提前退出对应 OR 语义——只要找到一步好棋，其余走法不用看。`vector<int>` 而不是 `vector<bool>`：后者是位压缩代理，读写慢还可能踩引用代理的坑，布尔 DP 用 `int`/`char` 更稳。

## 核心理解

### 1. 为什么净胜分在这里不适用

486/1140/1406 里每堆石子有分值，目标是"比对手多拿"，状态是整数差值。本题拿多块没有额外收益——**唯一的目标是拿最后一块**，所以状态退化成布尔，"对手的最优"体现为 `!f[·]`：不是从对手手里扣分，而是把对手推进"怎么动都输"的局面。

### 2. 必胜/必败的定义是自洽的递归

- 终止态：`f[0] = false`（轮到你时没石头，你输）
- 必胜态：**存在**一个走法到达对方的必败态
- 必败态：**所有**走法都到达对方的必胜态（= 不存在走法到达对方必败态）

这套定义就是组合博弈里 P-position / N-position 的直观版，Nim、取石子游戏都是同一个骨架，只是走法集合不同。

### 3. 按"心法"先试探了数学捷径，但没有

必败态序列是 `0, 2, 5, 7, 10, 12, 15, 17, 20, 22, 34, 39, ...`——看不出周期或封闭形式（对比 292 Nim 游戏，取 1~3 块时必败态就是 4 的倍数，`return n % 4 != 0` 秒杀）。试探失败，退回 DP——这正是"先想必胜策略，走不通再上 DP"的标准流程。

## 复杂度

| 指标 | 值 |
|------|----|
| 时间 | O(n√n)：每个 `i` 枚举 `k <= √i`；`n = 10⁵` 约 3×10⁷ 次判断，可过 |
| 空间 | O(n) |

验证：`n = 0..25` 与无记忆化暴力三方对拍一致；`n = 0..5000` DP 与记忆化递归逐值互查一致。5057 条断言全过。

---

## 踩坑点 / 注意点

- ❌ **`f[0]` 当成"先手赢"**。`vector` 零初始化恰好给 `f[0] = false`（必败），是对的——手写时要想清楚：剩余 0 块时**轮到你动**，你无子可取，输。
- ❌ **平方枚举写成 `k <= i / k` 防溢出**。本题 `i <= 10⁵`，`k * k` 最大约 10⁵，int 无压力；但养成习惯——`i` 到 10⁹ 量级时 `k * k` 会爆 int。
- ❌ **忘记 `break`**。不算错，但每个状态都扫完所有平方数，常数差几倍。
- ❌ **试图找数学规律硬猜**。必败态无周期，打表找规律这题走不通（见核心理解 3）。
