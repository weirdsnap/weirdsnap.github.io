> **标签**：动态规划、字符串
# 最大开销子字符串（2606. Find the Substring With Maximum Cost）

## 题意

每个小写字母有一个**开销值**：默认是字母表位置（`a`=1, `b`=2, ...），但可以用 `chars[i]` 和 `vals[i]` 覆盖指定字母的开销（**可以为负**）。给定字符串 `s`，求开销最大的**子串**的开销（子串可以为空，空子串开销为 0）。

```
输入: s = "adaa", chars = "d", vals = [-1000]
输出: 2
解释: 选 "a" 或 "aa"，开销 = 2 。含 'd' 的子串都被 -1000 拖垮。

输入: s = "abc", chars = "abc", vals = [-1,-1,-1]
输出: 0
解释: 所有非空子串开销都是负的，选空子串开销 = 0 。
```

---

## 思路

### 关键观察

1. 字符 → 开销的映射建好后，`s` 就变成一个**整数数组**，问题变成**最大子数组和（LC 53）**。
2. 和 53 唯一的区别：53 要求子数组**非空**（全负时要返回最大那个负数），本题允许**空子串**（全负时返回 0）。

### DP 定义与转移

和 53 完全一样的 Kadane：

```
last = max(last + values[c], values[c])   # 以当前字符结尾的最大开销
result = max(result, last)                # 全局最大，初始为 0（空子串）
```

`result` 初始化为 `0` 而不是 `values[0]`，就是"允许空子串"的全部体现。

---

## 代码

```cpp
class Solution {
public:
    int maximumCostSubstring(string s, string chars, vector<int>& vals) {
        // 使用数组替代vector，避免堆分配开销
        int values[26];
        for (int i = 0; i < 26; i++) {
            values[i] = i + 1;
        }
        for (int i = 0; i < chars.size(); i++) {
            values[chars[i] - 'a'] = vals[i];
        }
        int result = 0;
        int last = 0;  // 直接初始化为0，避免多余的赋值
        int cur;
        for (int i = 0; i < s.size(); i++) {
            // 原地计算，减少临时变量
            last = max(last + values[s[i] - 'a'], values[s[i] - 'a']);
            result = max(result, last);
        }
        return result;
    }
};
```

**注意**：开销表用定长数组 `int values[26]`，先填默认值 `i + 1`，再用 `chars`/`vals` 覆盖——没有出现在 `chars` 里的字母自动保留默认开销。

---

## 关键细节

### 1. 与 LC 53 的唯一差异：初始值

| | LC 53 最大子数组和 | 本题 |
|--|-------------------|------|
| 子串可否为空 | ❌ 至少一个元素 | ✅ 空子串开销 0 |
| `result` 初始值 | `nums[0]`（或 `INT_MIN`） | `0` |
| `last` 初始值 | `nums[0]`，从 i=1 开始 | `0`，从 i=0 开始 |

`last` 初始化为 0 也等价于"前面是空子串"，第一轮循环 `max(0 + v, v) = v` 自然等价于从 `i = 0` 重新开始，不需要特判。

### 2. 为什么不用前缀和

53 的前缀和写法在这里同样适用（`min_pre` 初始 0 天然对应空子串），但本题数据极小（`n ≤ 10^5`，字母表 26），Kadane 一遍过即可。

## 复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n + 26) | 建表 O(26) + Kadane O(n) |
| 空间 | O(1) | 26 槽位定长数组 |

---

## 踩坑点 / 注意点

- ❌ **`result` 初始化为 `INT_MIN` 或第一个值**。53 的写法直接搬过来会在全负开销时返回负数，而本题答案是 0。
- ❌ **忘记填默认开销**。没在 `chars` 里的字母开销是字母表位置（1~26），不是 0。
- ❌ **开销可以为负**。正因为有负开销，"空子串 = 0"这个选项才有意义，Kadane 的"负贡献丢弃"逻辑也才必要。
