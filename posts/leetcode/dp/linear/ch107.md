# 找两个和为目标值且不重叠的子数组（1477. Find Two Non-overlapping Sub-arrays Each With Target Sum）

## 题意

正整数数组 `arr`，整数 `target`。找两个**不重叠**的子数组，各自的和都等于 `target`，要求长度之和最小。找不到返回 -1。

```
输入: arr = [3,2,2,4,3], target = 3     输出: 2   （[3] 和末尾的 [3]）
输入: arr = [7,3,4,7], target = 7       输出: 2   （[7] 和 [7]，或 [3,4]）
输入: arr = [4,3,2,6,2,3,4], target = 6 输出: -1  （和为 6 的子数组存在，但任意两个都重叠）
```

- `1 <= arr.length <= 1e5`，`1 <= arr[i] <= 1000`，`1 <= target <= 1e8`

## 思路

直接枚举两段再检查重叠，O(n²) 打不住。换个角度：枚举**第二段**的右端点 `i`，问题拆成两半——

- 以 `i` 结尾、和为 `target` 的子数组有多短
- 它左边 `[0, l-1]` 里（`l` 是这段的左端点），和为 `target` 的子数组有多短

第二个量可以递推：

dp 定义：`dp[i]`：前 `i+1` 个元素（下标 `[0, i]`）中，和为 `target` 的子数组的最短长度（不存在记为 `INT_MAX`）

`dp[i]` 的来源就两个：
- 继承：`dp[i-1]`，`[0, i-1]` 里的最优照样是 `[0, i]` 里的候选
- 更新：以 `i` 结尾、和为 `target` 的子数组，若存在则拿它的长度来比

"以 `i` 结尾、和为 `target`"用前缀和 + 哈希 O(1) 定位：`preSum[i] - preSum[l-1] == target` 等价于查 `mp[preSum - target]`，哈希表记"前缀和 → 下标"。

于是扫一遍，每个 `i` 处尝试组合 `dp[l-1] + cur`：第一段收在 `l` 左边（不重叠由此保证），第二段是 `[l, i]`。

下面两版代码是同一个思路的两种组织方式：一个把哈希和 DP 交织在一趟循环里，一个拆成先后两遍。

## 解法一：一趟扫描

每个位置依次做三件事：查哈希定位当前子数组、更新 dp、登记新前缀和。省一个数组，循环体里几件事的先后顺序要留心。

```cpp
class Solution {
public:
    int minSumOfLengths(vector<int>& arr, int target) {

        const int n = arr.size();
        // 哈希：记录 前缀和 -> 最早出现位置，O(1) 定位和为 target 的子数组
        unordered_map<int, int> mp;
        mp[0] = -1;  // 前缀和为 0 时，对应下标 -1（处理从头开始的子数组）

        // dp: 前 i 个元素中，和为 target 的最短子数组长度
        vector<int> dp(n, INT_MAX);
        int preSum = 0;
        int ans = INT_MAX;

        for (int i = 0; i < n; i++) {
            preSum += arr[i];
            // 若 preSum - target 曾出现过，则 [mp[...]+1, i] 的和为 target
            if (mp.find(preSum - target) != mp.end()) {
                int l = mp[preSum - target] + 1;
                int cur = i - l + 1;
                // 用左端点之前的 dp 值组合，保证两子数组不重叠
                if (l >= 1 && dp[l - 1] != INT_MAX) {
                    ans = min(ans, dp[l - 1] + cur);
                }
                // 更新当前 dp（当前子数组长度与之前的最小值取更小）
                dp[i] = min(dp[i], cur);
            }
            // 继承前缀最小值
            if (i > 0) {
                dp[i] = min(dp[i], dp[i - 1]);
            }
            // 只在第一次出现时记录前缀和，保证左端点最靠左
            if (mp.find(preSum) == mp.end()) {
                mp[preSum] = i;
            }
        }

        return ans == INT_MAX ? -1 : ans;
    }
};
```

## 解法二：两遍扫描，先预处理 left 数组

把两件事拆开。第一遍只管哈希：算出 `left[i]`，即"以 `i` 为右端点、和为 `target` 的子数组"的左端点，不存在记 -1。第二遍只管 DP：读 `left[i]` 做组合和继承，不再碰哈希表。

```cpp
class Solution {
public:
    int minSumOfLengths(vector<int>& arr, int target) {

        const int n = arr.size();

        // ------- 第一部分：哈希表预处理 -------
        // best[i] 存"以 i 为右端点、和为 target 的子数组"的左端点 l
        // 若不存在，则为 -1
        vector<int> left(n, -1);

        unordered_map<int, int> mp;   // 前缀和 -> 首次出现位置
        mp[0] = -1;
        int preSum = 0;

        for (int i = 0; i < n; i++) {
            preSum += arr[i];
            // preSum - target 若出现过，则 [mp[...]+1, i] 的和为 target
            if (mp.find(preSum - target) != mp.end()) {
                left[i] = mp[preSum - target] + 1;
            }
            // 只在第一次出现时记录，保证左端点最靠左
            if (mp.find(preSum) == mp.end()) {
                mp[preSum] = i;
            }
        }

        // ------- 第二部分：前缀最小值 DP -------
        vector<int> dp(n, INT_MAX);   // dp[i]: [0..i] 内最短 target 子数组长度
        int ans = INT_MAX;

        for (int i = 0; i < n; i++) {
            if (left[i] != -1) {                       // 以 i 结尾存在 target 子数组
                int l = left[i];
                int cur = i - l + 1;                   // 当前子数组长度
                // 组合左边不重叠的子数组
                if (l >= 1 && dp[l - 1] != INT_MAX) {
                    ans = min(ans, dp[l - 1] + cur);
                }
                dp[i] = min(dp[i], cur);               // 更新 dp[i]
            }
            if (i > 0) {
                dp[i] = min(dp[i], dp[i - 1]);         // 继承前缀最小值
            }
        }

        return ans == INT_MAX ? -1 : ans;
    }
};
```

代价是多一个 `left[]` 数组和一趟循环，换来的是每遍循环只干一件事，读代码时不用在脑子里切换"这行是管哈希的还是管 DP 的"。两个职责都没有跨序依赖（DP 只读 `left`，不回写哈希），所以拆开是安全的。

## 关键点

- `mp[0] = -1` 这个哨兵管的是"子数组从下标 0 开始"的情况：此时 `preSum - target == 0`，查出 `l = 0`，不用特判。
- 组合时用的是 `dp[l-1]` 而不是 `dp[i-1]`。第一段必须整个落在第二段左边，"不重叠"就靠这一处下标保证。
- `l >= 1 && dp[l-1] != INT_MAX` 这个判断身兼两职：`l == 0` 时左边没有位置放第一段；`dp[l-1]` 为 `INT_MAX` 时左边还没有合法子数组。漏掉它，`INT_MAX + cur` 还会直接溢出。

## 一个利用正数约束的观察

注释里"只在第一次出现时记录前缀和"，在本题其实不会触发：`arr` 全是正数，`preSum` 严格递增，同一个前缀和值不会出现第二次，每个键本来就只插一次。这个 `if` 是为含 0 或负数的数组准备的防御写法。

同样因为全是正数，这题也能用滑动窗口做：右端点右移、和超了就从左边缩，省掉哈希表，空间降到 O(1)。前缀和 + 哈希的写法通用性更好，值域放开也成立。

## 复杂度

两版相同：

- 时间：O(n)，哈希操作均摊 O(1)（解法二是两趟常数 2 的扫描）
- 空间：O(n)，`mp` 和 `dp` 各一份，解法二多一个 `left[]`
