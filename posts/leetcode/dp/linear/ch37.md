# 乘积最大子数组（152. Maximum Product Subarray）

## 题意

给定整数数组 `nums`，找出**乘积最大的非空连续子数组**，返回乘积。

```
输入: nums = [2,3,-2,4]
输出: 6
解释: 子数组 [2,3] 的乘积最大，为 6 。

输入: nums = [-2,0,-1]
输出: 0
解释: 子数组 [0] 的乘积最大，[-2,-1] 虽然乘积为 2，但不连续。
```

---

## 思路

### 关键观察

这是 LC 53 的乘法版，但有一个本质差异：**加法不会因符号翻转大小关系，乘法会**。当前数是负数时，之前的**最小**乘积（负得最多）乘上它反而变成**最大**（负负得正）。

所以只维护"以 `i-1` 结尾的最大乘积"不够，必须**同时维护最大和最小**两个极值。

### DP 定义与转移

`max_pre` / `min_pre` = 以上一个位置结尾的连续子数组的最大/最小乘积。对 `nums[i]`，三种选择：

```
n_max = max(nums[i], max_pre * nums[i], min_pre * nums[i])
             ↑重新开始    ↑延续最大值      ↑负负得正：最小值翻盘
n_min = min(nums[i], max_pre * nums[i], min_pre * nums[i])
```

遇到 `0` 不需要特判：任何延续都变成 0，下一轮 `max(nums[i], 0, 0)` 自然从 `nums[i]` 重新开始。

---

## 代码

```cpp
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int max_pre = nums[0];
        int min_pre = nums[0];
        int result = nums[0];
        for (int i = 1; i < nums.size(); i++) {
            // 修复: 同时考虑 max_pre 和 min_pre 与当前数的乘积
            int n_max_pre = max(
                {nums[i], max_pre * nums[i], min_pre * nums[i]});
            // 修复: 同时考虑 max_pre 和 min_pre 与当前数的乘积
            int n_min_pre = min(
                {nums[i], max_pre * nums[i], min_pre * nums[i]});
            result = max(result, n_max_pre);
            max_pre = n_max_pre;
            min_pre = n_min_pre;
        }
        return result;
    }
};
```

**注意**：`n_max_pre` 和 `n_min_pre` 都必须用**旧的** `max_pre`/`min_pre` 计算，所以先算完两个新值再赋值更新——顺序反了会自己用自己。

---

## 关键细节

### 1. `std::max({a, b, c})`：initializer_list 重载

代码里 `max({nums[i], max_pre * nums[i], min_pre * nums[i]})` 用的是 C++11 的 `std::max(std::initializer_list<T>)` 重载（`<algorithm>`），可以一次取任意多个值的最大者，`std::min` 同理：

```cpp
max(a, b);           // 双参数版本，返回引用
max({a, b, c, d});   // 列表版本，返回值（不是引用）
```

两个细节：列表**不能为空**（`max({})` 是 UB）；元素类型必须一致，不一致要写 `max({1, 2L, 3})` 会编译错误。

### 2. 为什么 53 不需要维护最小值

53 的转移是 `max(nums[i], dp[i-1] + nums[i])`——加法单调，`dp[i-1]` 越大越好，"负贡献丢弃"就够了。乘法的符号翻转打破了单调性，"最负的"也有翻盘价值，所以要多维护一个 `min_pre`。

### 3. 与 53 的对照

| | 53 最大子数组和 | 152 乘积最大子数组 |
|--|----------------|-------------------|
| 运算 | 加法 | 乘法 |
| 维护状态 | 1 个（最大） | 2 个（最大 + 最小） |
| 重启条件 | 前缀和为负 | 不需要显式判断，由 max/min 自然选择 |
| 特殊元素 | 负数只是减分 | 负数会翻转极值，0 会切段 |

## 踩坑点 / 注意点

- ❌ **只维护最大乘积**。遇到负数时最大值直接错，这是本题唯一的难点。
- ❌ **更新顺序错误**。`n_max_pre` 用到了旧的 `max_pre` 和 `min_pre`，必须先算后赋值。
- ❌ **给 0 写特判**。0 会把延续的乘积清零，下一轮 `max(nums[i], 0, 0)` 自然重启，特判反而容易引入 bug。
- ❌ **`max({})` 空列表**。initializer_list 版本的 `max`/`min` 传空列表是 UB。
