> **标签**：动态规划、递归、记忆化搜索
# 打家劫舍（198. House Robber）

## 题意

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金。相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组 `nums`，计算你**在不触动警报装置的情况下**，今晚能够偷窃到的最高金额。

```
输入: nums = [1,2,3,1]
输出: 4
解释: 偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。
     偷窃到的最高金额 = 1 + 3 = 4 。

输入: nums = [2,7,9,3,1]
输出: 12
解释: 偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。
     偷窃到的最高金额 = 2 + 9 + 1 = 12 。
```

---

## 思路

### 关键观察

对于第 `i` 间房子，有两个选择：
1. **偷**：不能偷第 `i-1` 间，最大金额 = `dp[i-2] + nums[i]`
2. **不偷**：最大金额 = `dp[i-1]`

取两者最大值：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

### 边界条件

- `dp[0] = nums[0]`（只有一间，必偷）
- `dp[1] = max(nums[0], nums[1])`（两间，偷金额大的）

---

## 代码

### 解法一：记忆化搜索（递归 + 备忘录）

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;
        
        vector<int> dp(n + 1, -1);
        
        function<int(int)> f = [&](int k) -> int {
            if (dp[k] != -1) return dp[k];
            
            int result;
            if (k == 1) {
                result = nums[0];
            } else if (k == 2) {
                result = max(nums[0], nums[1]);
            } else {
                result = max(f(k - 1), f(k - 2) + nums[k - 1]);
            }
            
            dp[k] = result;
            return result;
        };
        
        return f(n);
    }
};
```

**注意**：`k` 表示**前 k 间房子**（不是下标），`nums[k-1]` 是第 k 间房子。三个分支互斥：`k==1`、`k==2`、`k>2` 只会进入一个。

### 解法二：递推（自底向上，下标从 1 开始）

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        const int n = nums.size();
        vector<int> dp(n + 1, 0);
        dp[1] = nums[0];
        
        for (int i = 2; i <= n; i++) {
            dp[i] = max(
                nums[i - 1] + dp[i - 2],  // 偷第 i 间
                dp[i - 1]                  // 不偷第 i 间
            );
        }
        
        return dp[n];
    }
};
```

**特点**：`dp[i]` 表示前 `i` 间房子，`dp[0] = 0` 表示 0 间房子金额为 0。下标从 1 开始，和记忆化搜索的 `f(k)` 定义一致。

### 解法三：显式状态 DP（二维，更清晰）

用 `dp[i][0/1]` 明确表示**第 i 间房子偷或不偷**的状态：

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        const int n = nums.size();
        if (n == 0) return 0;
        
        // dp[i][0]: 不偷第 i 间, dp[i][1]: 偷第 i 间
        vector<vector<int>> dp(n, vector<int>(2, 0));
        
        dp[0][0] = 0;           // 第 0 间不偷
        dp[0][1] = nums[0];     // 第 0 间偷
        
        for (int i = 1; i < n; i++) {
            dp[i][0] = max(dp[i-1][0], dp[i-1][1]);  // 不偷 i，i-1 随意
            dp[i][1] = dp[i-1][0] + nums[i];          // 偷 i，i-1 必须不偷
        }
        
        return max(dp[n-1][0], dp[n-1][1]);
    }
};
```

**状态转移**：
- `dp[i][0] = max(dp[i-1][0], dp[i-1][1])`：不偷 `i`，`i-1` 偷不偷都行
- `dp[i][1] = dp[i-1][0] + nums[i]`：偷 `i`，`i-1` 必须不偷

**优点**：状态定义清晰，适合扩展（如 213. 打家劫舍 II 的环形情况）。

### 解法四：空间优化（滚动数组）

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;
        
        int prev2 = 0;  // dp[i-2]
        int prev1 = 0;  // dp[i-1]
        
        for (int i = 0; i < n; i++) {
            int curr = max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = curr;
        }
        
        return prev1;
    }
};
```

---

## 关键细节

### 1. 状态转移方程

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
         ↑不偷第i间    ↑偷第i间
```

- 不偷 `i`：金额和偷到 `i-1` 时一样
- 偷 `i`：不能偷 `i-1`，所以是 `dp[i-2] + nums[i]`

### 2. 空间优化原理

`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，不需要保存整个数组。用两个变量滚动即可。

```
i=0: curr = max(0, 0 + nums[0]) = nums[0]
       prev2 = 0, prev1 = nums[0]

i=1: curr = max(nums[0], 0 + nums[1]) = max(nums[0], nums[1])
       prev2 = nums[0], prev1 = max(nums[0], nums[1])

i=2: curr = max(prev1, prev2 + nums[2])
       ...
```

### 3. 三种解法对比

| | 记忆化搜索 | 递推 | 空间优化 |
|--|-----------|------|---------|
| 时间 | O(n) | O(n) | O(n) |
| 空间 | O(n) | O(n) | **O(1)** |
| 代码量 | 稍多 | 中等 | 最少 |
| 推荐度 | ⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |

## 踩坑点 / 注意点

- ❌ **边界条件处理**。`n == 0` 或 `n == 1` 时要提前返回。
- ❌ **递推时 `i` 从 2 开始**。`dp[0]` 和 `dp[1]` 需要手动初始化。
- ❌ **空间优化变量更新顺序**。先算 `curr`，再更新 `prev2 = prev1`，最后 `prev1 = curr`。
- ❌ **递归深度过大**。能否扛住取决于栈大小和栈帧：实测 macOS 默认栈约 8MB 下，小栈帧递归 5×10⁵ 层仍正常、10⁶ 层段错误；而 `std::function` 递归栈帧更大，10⁵ 量级确实有真实风险。稳妥起见用递推或空间优化版本。
