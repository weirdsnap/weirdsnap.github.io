# 施咒的最大总伤害（3186. Maximum Total Damage With Spell Casting）

## 题意

给你一个整数数组 `power`，表示每个法术造成的伤害值。你可以施放任意多个法术，但有一个限制：**如果施放了伤害为 `x` 的法术，就不能施放伤害为 `x - 2`、`x - 1`、`x + 1`、`x + 2` 的法术**（伤害值相同的法术不受此限制，可以全部施放）。

求能够造成的**最大总伤害**。

```
输入: power = [1,1,3,4]
输出: 6
解释: 施放两个伤害为 1 的法术和一个伤害为 4 的法术。
     总伤害 = 1 + 1 + 4 = 6 。（不能选 3，因为 3 和 1、4 都冲突）

输入: power = [7,1,6,6]
输出: 13
解释: 施放伤害为 1 的法术和两个伤害为 6 的法术。
     总伤害 = 1 + 6 + 6 = 13 。
```

---

## 思路

### 关键观察

1. **相同伤害值的法术要么全选，要么全不选**。限制只和数值有关，和个数无关，所以选了伤害 `x`，就应该把所有 `x` 都选上。
2. 先按伤害值**聚合并排序**，问题转化为：在有序的不同伤害值序列上，选一些数值使两两之差都大于 2，求最大总伤害。
3. 这就是 **打家劫舍（198）的变体**：198 是不能选相邻元素，这里是**不能选差值 ≤ 2 的元素**。

### DP 定义

设聚合排序后有 `m` 个不同的伤害值，`items[i] = (伤害值, 该值的总贡献)`。

`dp[i]` = 前 `i` 个不同伤害值能获得的最大总伤害。

### 状态转移

对第 `i` 个伤害值：

1. **不选**：`dp[i] = dp[i-1]`
2. **选**：找到最后一个与 `i` 不冲突的位置 `j - 1`（即满足 `items[j-1].first + 2 < items[i].first` 的最大下标），`dp[i] = items[i].second + dp[j-1]`

```
dp[i] = max(dp[i-1], dp[j-1] + items[i].second)
         ↑不选 i      ↑选 i，跳到最近的不冲突位置
```

### 如何找 j

有三种方式：

- **双指针**：`j` 单调右移，指向第一个满足 `items[j].first + 2 >= items[i].first` 的位置，`j - 1` 即为所求。`i` 递增时 `j` 不需要回退，均摊 O(m)。
- **二分查找**：键已排序，直接二分最后一个满足 `keys[j] + 2 < keys[i]` 的下标，O(m log m)。
- **只看前 3 个位置**：键是**严格递增的整数**，所以 `keys[i-3] <= keys[i] - 3` 恒成立——`i-3` 及更早的位置一定不冲突，冲突只可能发生在 `i-1` 和 `i-2`。因此 `dp[i]` 实际只依赖最近 3 个状态，可以滚动成 O(1) 空间。

## 代码

### 解法一：双指针

```cpp
class Solution {
public:
    long long maximumTotalDamage(vector<int>& power) {
        // 统计频率并直接计算每个伤害值的总贡献
        map<int, long long> cnt;
        for (int p : power) cnt[p] += p;  // 累加贡献值，避免后续重复计算
        
        int m = cnt.size();
        // 提取排序后的键值对，减少额外数组开销
        vector<pair<int, long long>> items;
        items.reserve(m);
        for (auto& [k, v] : cnt) {
            items.emplace_back(k, v);
        }
        
        // dp[i] 表示前 i 个不同伤害值的最大总伤害
        // dp[i] 依赖 dp[i-1] 和 dp[j-1]，j-1 位置不固定，保留一维数组
        vector<long long> dp(m, 0);
        
        int j = 0;  // 双指针：指向第一个与 i 冲突的位置
        for (int i = 0; i < m; i++) {
            // 移动 j 使 items[j].first 是第一个满足 key + 2 >= items[i].first 的位置
            while (j < i && items[j].first + 2 < items[i].first) {
                j++;
            }
            
            long long take = items[i].second;
            if (j > 0) take += dp[j - 1];  // 加上前一个不冲突位置的最优解
            
            // 不选 i：继承 dp[i-1]；选 i：用 take。取最优
            dp[i] = max(i > 0 ? dp[i - 1] : 0LL, take);
        }
        
        return dp[m - 1];
    }
};
```

**注意**：`j` 指向的是第一个**冲突**的位置，所以真正累加的是 `dp[j - 1]`（最后一个不冲突位置）。`j == 0` 说明前面所有值都和 `i` 冲突，`take` 就是 `items[i].second` 本身。

### 解法二：二分查找

`j - 1` 也可以直接在已排序的键上二分：找最后一个满足 `keys[j] + 2 < keys[i]` 的下标。

```cpp
class Solution {
public:
    long long maximumTotalDamage(vector<int>& power) {
        map<int, long long> cnt;
        for (int p : power) cnt[p] += p;
        
        int m = cnt.size();
        vector<int> keys;
        vector<long long> vals;
        keys.reserve(m);
        vals.reserve(m);
        for (auto& [k, v] : cnt) {
            keys.push_back(k);
            vals.push_back(v);
        }
        
        vector<long long> dp(m, 0);
        dp[0] = vals[0];
        
        for (int i = 1; i < m; i++) {
            // 二分：找最后一个 keys[j] + 2 < keys[i] 的 j
            int lo = 0, hi = i - 1, j = -1;
            while (lo <= hi) {
                int mid = lo + (hi - lo) / 2;
                if (keys[mid] + 2 < keys[i]) {
                    j = mid;        // mid 可行，继续往右找更大的
                    lo = mid + 1;
                } else {
                    hi = mid - 1;
                }
            }
            
            long long take = vals[i] + (j >= 0 ? dp[j] : 0);
            dp[i] = max(dp[i - 1], take);
        }
        
        return dp[m - 1];
    }
};
```

**特点**：思路直观，每个 `i` 独立二分，不依赖指针单调性；代价是多一个 log 因子。

### 解法三：O(1) 滚动（直接在 map 上迭代）

由思路部分，冲突只可能发生在 `i-1`、`i-2`，只需保留**最近 3 个** `dp` 值和 `key`，用循环数组滚动即可：

```cpp
class Solution {
public:
    long long maximumTotalDamage(vector<int>& power) {
        map<int, long long> cnt;
        for (int p : power) cnt[p] += p;
        
        if (cnt.empty()) return 0;
        
        long long dp0 = 0, dp1 = 0, dp2 = 0;  // dp[i-1], dp[i-2], dp[i-3]
        
        // 用数组存最近3个 (key, value) 对，避免迭代器回退
        long long keys[3] = {0, 0, 0};   // 循环数组存最近3个key
        long long vals[3] = {0, 0, 0};   // 循环数组存最近3个value
        int idx = 0;  // 当前位置
        
        int i = 0;
        for (auto& [k, v] : cnt) {
            keys[idx] = k;
            vals[idx] = v;
            
            long long take = v;
            
            // 找前一个不冲突的位置
            if (i >= 1 && keys[(idx + 2) % 3] + 2 >= k) {  // i-1 冲突
                if (i >= 2 && keys[(idx + 1) % 3] + 2 >= k) {  // i-2 冲突
                    if (i >= 3) take += dp2;  // dp[i-3]
                } else {
                    if (i >= 2) take += dp1;  // dp[i-2]
                }
            } else {
                if (i >= 1) take += dp0;  // dp[i-1]
            }
            
            long long cur = max(dp0, take);
            dp2 = dp1; dp1 = dp0; dp0 = cur;
            
            idx = (idx + 1) % 3;
            i++;
        }
        
        return dp0;
    }
};
```

**注意**：写入 `keys[idx]` 的是当前 `i`，所以 `i-1` 在 `(idx + 2) % 3`、`i-2` 在 `(idx + 1) % 3`。嵌套的 `if` 对应三种情况：`i-1` 不冲突用 `dp[i-1]`；`i-1` 冲突但 `i-2` 不冲突用 `dp[i-2]`；都冲突用 `dp[i-3]`。

**特点**：不提取 vector，额外空间 O(1)（不计 `map` 本身）；缺点是循环数组下标绕、边界分支多，容易写错。

## 关键细节

### 1. 为什么先聚合贡献

`cnt[p] += p` 把"频率 × 伤害值"一步算成总贡献。因为相同伤害值的法术必然同进同退，聚合后 DP 只需在 `m` 个**不同**值上进行，`m ≤ n`。

### 2. 与打家劫舍的对应关系

| | 198. 打家劫舍 | 3186. 施咒 |
|--|--------------|-----------|
| 冲突条件 | 下标相邻 | 数值差 ≤ 2 |
| 预处理 | 无 | 聚合 + 排序 |
| 选 i 时回退 | 固定 `dp[i-2]` | 表面不固定 `dp[j-1]`，实际最多回看 3 个 |

198 靠"相邻下标"只回看 2 个；本题靠"差值 ≤ 2 + 整数键"只回看 3 个，本质相同。

## 复杂度

| | 双指针 | 二分查找 | O(1) 滚动 |
|--|--------|---------|-----------|
| 时间 | O(n log n) | O(n log n) | O(n log n) |
| 找 j 部分 | **O(m)** | O(m log m) | **O(m)** |
| 额外空间 | O(m) | O(m) | **O(1)** |
| 代码量 | 中等 | 稍多 | 最多（边界繁琐） |
| 推荐度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐ |

（时间瓶颈都在排序的 O(n log n)；用 `map` 时排序已内建。空间不计 `map` 本身。）

## 踩坑点 / 注意点

- ❌ **溢出**。`n` 最大 `10^5`，伤害值最大 `10^9`，总伤害可达 `10^14`，必须用 `long long`。
- ❌ **忘记聚合就直接 DP**。不去重的话，差值判断和下标处理都会乱，先 `map` 聚合。
- ❌ **`j - 1` 的边界**。双指针 `j == 0`、二分 `j == -1` 都表示前面全部冲突，不能访问 `dp[-1]`，要特判。
- ❌ **双指针条件写反**。`while` 里是不冲突就右移（`+ 2 <`），停下时 `j` 指向第一个**冲突**位置，取的是 `dp[j-1]`。
- ❌ **循环数组下标拿错**。当前 `i` 刚写入 `keys[idx]`，所以 `i-1` 在 `(idx + 2) % 3`。直接用 `idx - 1` 会拿到当前值自己，判断全错。
