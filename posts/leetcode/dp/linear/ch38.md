# 任意子数组和的绝对值的最大值（1749. Maximum Absolute Sum of Any Subarray）

## 题意

给定整数数组 `nums`，找出**绝对值最大**的子数组和，返回这个最大值（即 `max |sum(subarray)|`）。

```
输入: nums = [1,-3,2,3,-4]
输出: 5
解释: 子数组 [2,3] 的和为 5，绝对值最大。

输入: nums = [2,-5,1,-4,3,-2]
输出: 8
解释: 子数组 [-5,1,-4] 的和为 -8，绝对值 8 最大。
```

---

## 思路

### 关键观察

`|和|` 最大，只需要看**和最大**（正方向）与**和最小**（负方向）两个候选：

```
max|sum| = max(最大子数组和, -最小子数组和)
```

所以同时跑**两个方向的 Kadane**：一个维护以 `i` 结尾的最大子数组和，一个维护最小子数组和，答案取两者绝对值的较大者。

### DP 定义与转移

`max_pre` / `min_pre` = 以上一个位置结尾的连续子数组的最大/最小**和**（加法，和 53 完全同构）：

```
n_max = max(nums[i], max_pre + nums[i])
n_min = min(nums[i], min_pre + nums[i])
result = max(result, |n_max|, |n_min|)
```

---

## 代码

```cpp
class Solution {
public:
    int maxAbsoluteSum(vector<int>& nums) {
        int min_pre = nums[0];
        int max_pre = nums[0];
        int result = abs(nums[0]);
        for (int i = 1; i < nums.size(); i++) {
            int cur = nums[i];
            // 维护以当前位置结尾的子数组的最小前缀和
            int n_min_pre = min({
                cur, cur + min_pre
            });
            // 维护以当前位置结尾的子数组的最大前缀和
            int n_max_pre = max({
                cur, cur + max_pre
            });
            // 用最大/最小前缀和的绝对值更新答案
            result = max({
                result, abs(n_max_pre), abs(n_min_pre)
            });
            min_pre = n_min_pre;
            max_pre = n_max_pre;
        }
        return result;
    }
};
```

**注意**：这里的 `max_pre`/`min_pre` 是以 `i` **结尾的子数组和**（Kadane 状态），不是前缀和——每轮只有两个候选（"重新开始"或"延续"），和前缀和写法里维护历史最小值是两种不同结构，别被变量名混淆。更新顺序同样是先算完两个新值再赋值。

---

## 关键细节

### 1. Kadane 家族的对照

| | 53 | 152 | 1749 |
|--|-----|-----|------|
| 目标 | 最大和 | 最大乘积 | 最大\|和\| |
| 维护状态 | 1 个（最大） | 2 个（最大+最小） | 2 个（最大+最小） |
| 为什么两个 | 加法单调，不用 | 负数翻转乘积极值 | 绝对值要看两端 |
| 答案来源 | `max(result, n_max)` | 同左 | `max(result, \|n_max\|, \|n_min\|)` |

1749 和 152 的"双极值"结构相同，但原因不同：152 是负数会翻转乘积的符号，1749 是绝对值让"最负的和"也有竞争力。

### 2. 一次遍历 vs 两次遍历

也可以分别跑一遍正向 Kadane（最大和）和反向语义 Kadane（最小和），两次遍历。本写法把两个状态放同一循环里，一次遍历，逻辑对称紧凑。

## 复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 单次遍历，同时维护两个状态 |
| 空间 | O(1) | 三个滚动变量 |

---

## 踩坑点 / 注意点

- ❌ **只跑一遍最大子数组和**。`[-5,1,-4]` 这种"负得最多"的子数组会被漏掉，答案少一半。
- ❌ **把绝对值加在转移里**。`abs` 只作用于最终的两个候选状态，转移本身还是带符号的加法——提前取绝对值会破坏"负贡献丢弃"的逻辑。
- ❌ **更新顺序错误**。`n_min_pre` 和 `n_max_pre` 都依赖旧的 `min_pre`/`max_pre`，必须先算后赋值。
