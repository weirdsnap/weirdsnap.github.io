# 最大子数组和（53. Maximum Subarray）

## 题意

给定一个整数数组 `nums`，找到一个**连续子数组**（至少包含一个元素），使其和最大，返回这个最大和。

```
输入: nums = [-2,1,-3,4,-1,2,1,-5,4]
输出: 6
解释: 连续子数组 [4,-1,2,1] 的和最大，为 6
```

---

## 思路

### 暴力想

枚举所有子数组，计算和，取最大。O(N³) 或 O(N²)，显然超时。

### 关键观察

假设我们已经知道以位置 `i-1` 结尾的最大子数组和是 `dp[i-1]`。那以 `i` 结尾的最大子数组和呢？

要么从 `i` 重新开始（前面的和是负的，不如不要），要么延续前面的子数组：

```
dp[i] = max(nums[i], dp[i-1] + nums[i])
```

这就是状态转移。`dp[i]` 表示**必须以 i 结尾**的连续子数组的最大和。

### 代码

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        // dp[i] 表示以 i 结尾的连续子数组最大和
        // 直接复用 nums 数组，省空间
        vector<int> dp(nums.begin(), nums.end());
        const int n = nums.size();
        
        // 同时维护全局最大值，避免第二次遍历
        int result = dp[0];
        
        for (int i = 1; i < n; i++) {
            // 状态转移：要么重新开始，要么延续前一个子数组
            dp[i] = max(dp[i], dp[i - 1] + nums[i]);
            // 实时更新全局最大值
            result = max(result, dp[i]);
        }
        
        return result;
    }
};
```

### 空间优化

`dp[i]` 只依赖 `dp[i-1]`，可以滚成 O(1)：

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        // 复用 dp 数组，dp[i] 表示以 i 结尾的子数组最大和
        int cur, last;
        const int n = nums.size();
        last = nums[0];
        
        // 同时维护全局最大值，避免第二次遍历
        int result = last;
        
        for (int i = 1; i < n; i++) {
            // 状态转移：要么重新开始，要么延续前一个子数组
            cur = max(nums[i], last + nums[i]);
            // 实时更新全局最大值
            result = max(result, cur);
            last = cur;
        }
        
        return result;
    }
};
```

### 前缀和转化

换一个视角：子数组 `[j..i]` 的和 = `pre[i] - pre[j-1]`（前缀和之差）。固定右端点 `i`，要让差最大，就要减去 `i` 之前**最小的前缀和**：

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        
        int pre = 0;
        int min_pre = 0;
        int result = INT_MIN;

        for (const auto& num: nums) {
            pre += num;
            result = max(result, pre - min_pre);
            min_pre = min(min_pre, pre);
        }

        return result;
    }
};
```

**注意**：`min_pre` 初始为 0，代表"空前缀"（子数组从头开始的情况）；并且必须先更新 `result` 再更新 `min_pre`，保证子数组非空。`result` 初始化为 `INT_MIN`，兼容全负数数组。

### 线段树解法（分治视角）

学了线段树之后可以用它重做这道题——最大子数组和恰好是"不能简单合并"的信息：左右两段各自的 best 取 max 还不够，答案可能**横跨拼接缝**（`L.suf + R.pre`）。所以 Node 要存四个字段：

```cpp
struct Node {
    int pre;   // 必须含区间左端点的最大子段和
    int suf;   // 必须含区间右端点的最大子段和
    int sum;   // 区间总和
    int best;  // 区间内最大子段和
};

// merge：横跨候选是 L.suf + R.pre
Node merge(const Node& L, const Node& R) {
    return {
        max(L.pre, L.sum + R.pre),           // pre：纯左前缀 或 左全段+右前缀
        max(R.suf, R.sum + L.suf),           // suf：对称
        L.sum + R.sum,
        max({L.best, R.best, L.suf + R.pre}) // best：左、右、横跨三者取最大
    };
}
```

建树后直接读根：`return tree[1].best`。完整代码（deducing this 递归 lambda 建树）见 `cpp_learning/leetcode/lc53_maximum_subarray/segtree.hpp`，500 组随机对拍 Kadane 版完全一致。

**和 2213（[ch52](./blog.html?post=leetcode/segment-tree/ch52.md)）的对照**：两题都是"merge 需要前缀/后缀信息"的形态，但 2213 的前缀段是"长度"（受字符相同约束，延续要判 `preLen == len`），本题的前缀段是"和"（延续无条件，直接把 `sum` 加上去）——同一个骨架，merge 语义不同。

**复杂度**：建树 O(n)，答案 O(1)（读根），空间 O(4n)。单次询问下被 Kadane 的 O(n)/O(1) 完爆——线段树版的价值在于**可扩展性**：如果题目要求"多次修改数组元素后查询最大子段和"（GSS 系列），Kadane 每次都要 O(n) 重扫，线段树每次 update 只需 O(log n)。这是"整体 best 型"线段树的又一个样本。

### 复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(N) | 单次遍历（三种写法相同） |
| 空间 | O(1) | DP 数组版为 O(N)，滚动变量和前缀和为 O(1) |

## 核心理解

`dp[i]` 的定义很关键：**必须以 i 结尾**。这保证了子数组的连续性——如果不要求连续，就变成"最大子序列和"，直接取所有正数相加就行。

`max(nums[i], dp[i-1] + nums[i])` 这个转移也很直观：前面的和如果是负的，`dp[i-1] + nums[i]` 比 `nums[i]` 还小，不如从 `i` 重新开始。

前缀和是同一个问题的另一个视角：DP 里"前面的和是负就丢弃"，等价于前缀和里"减去历史最小前缀和"——`min_pre` 之后的部分正是被保留下来的"正贡献"后缀。两种写法可以互相印证。

---

## 踩坑点

- ❌ `dp` 定义成"前 i 个元素的最大子数组和"，转移时会漏掉"必须连续"的约束
- ❌ 忘记处理全负数的情况，`result` 初始化为 `nums[0]` 而不是 0
- ❌ 空间优化时把 `cur` 和 `result` 初始化为 0，全负数数组会返回 0
- ❌ 前缀和写法先更新 `min_pre` 再算 `result`——顺序反了会得到空子数组的和 0，全负数时出错
- ❌ 线段树版把 `best` 写成 `max(L.best, R.best)`——漏掉横跨拼接缝的 `L.suf + R.pre`
- ✅ `dp[i]` 必须包含 `nums[i]`，这是连续性的保证
