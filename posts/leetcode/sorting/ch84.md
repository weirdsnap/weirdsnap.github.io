# 会议室（252. Meeting Rooms）

## 题意

给定若干会议时间区间 `intervals[i] = [start, end]`，判断一个人能否参加所有会议——即**任意两个区间都不重叠**。端点相接不算重叠（`[5,10]` 和 `[10,15]` 可以都参加）。

```
输入: intervals = [[0,30],[5,10],[15,20]]
输出: false    （[0,30] 与另两个都重叠）

输入: intervals = [[7,10],[2,4]]
输出: true

输入: intervals = [[5,10],[10,15]]
输出: true     （端点相接，合法）
```

---

## 思路：按起点排序，只查相邻

排序后区间的起点单调递增。此时若有任何重叠，**必然存在一对相邻区间重叠**：设 `i < j < k` 且 i、k 重叠（`intervals[k][0] < intervals[i][1]`），则夹在中间的 j 起点 ≥ i 的起点且 ≤ k 的起点 < i 的终点，j 与 i 也重叠。所以只需扫一遍相邻对：`intervals[i][0] < intervals[i-1][1]` 即重叠。

## 解法：排序 + 相邻检查

```cpp
class Solution {
public:
    bool canAttendMeetings(vector<vector<int>>& intervals) {
        if (intervals.empty()) {
            return true;
        }
        sort(intervals.begin(), intervals.end(),
             [](const vector<int>& a, const vector<int>& b) {
                 return a[0] < b[0];
             });
        for (int i = 1; i < intervals.size(); i++) {
            // 当前区间起点 < 前一区间终点 → 重叠
            if (intervals[i][0] < intervals[i - 1][1]) {
                return false;
            }
        }
        return true;
    }
};
```

---

## 核心理解

### 1. 排序把 O(n²) 两两比较降为相邻比较

无序时"任意重叠"必须两两检查；按起点排序后，重叠关系被**传递到相邻对**上——非相邻的重叠必然蕴含相邻的重叠（证明见思路）。这是区间题的标配起手式：**先排序，再看结构性质能不能把全局条件化归为局部条件**。56（合并区间）、435（去重叠）、452（射气球）全是这个套路。

### 2. 重叠判定的不等号方向

"当前起点 < 前一终点"即重叠，用**严格小于**——端点相接合法。两个区间 `[a,b]`、`[c,d]` 的完整相交判据是 `a < d && c < b`，排序后 `c >= a` 恒成立使判据简化成一个比较。想清楚"哪个不等号因为排序而免费"比背模板可靠。

### 3. 排序键只需要起点

终点不参与排序键——相邻重叠检查里用的"前一区间终点"就是 `intervals[i-1][1]` 原值，不要求终点有序。加 `a[1] < b[1]` 做次级排序键不改变正确性（起点相同的两区间本来就必须检查重叠），但属于多余信息。

## 复杂度

| | 时间 | 空间 |
|--|------|------|
| 排序 + 一趟 | O(n log n) | O(log n)（排序栈） |

验证：对拍 O(n²) 两两判重叠的暴力 oracle（完整判据 `a < d && c < b`）。官方样例 + 端点相接/空/单区间手工边界 + **穷举端点 [0,5] 内全部区间、数量 ≤ 3 的全部组合**（2,024 组）+ 500 组随机，**2,529 条断言全过**。

---

## 踩坑点 / 注意点

- ❌ **`<=` 当重叠**。端点相接（`[5,10]` 与 `[10,15]`）按题意合法，用 `<=` 会误判。会议/区间题的"相接算不算重叠"每题都要重新确认题面。
- ❌ **忘排空数组**。空输入直接返回 true；虽然本题空数组在排序+循环下也自然正确，但显式早退让意图清楚，也防后续改代码时踩空指针类问题。
- ❌ **排序后还两两比较**。那就白排了——排序的收益恰在于只需查相邻。
- ⚠️ **`sort` 的 lambda 比较器要严格弱序**：`a[0] < b[0]` 正确；写成 `a[0] <= b[0]` 是 UB（相等时双方互判 true，违反严格弱序），Debug 下 libstdc++ 会直接断言炸掉。
