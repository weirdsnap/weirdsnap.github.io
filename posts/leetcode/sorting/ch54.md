# 三个数的最大乘积（628. Maximum Product of Three Numbers）

## 题意

给定整数数组 `nums`（长度 `>= 3`），从中选**三个数**使乘积最大，返回最大乘积。

```
输入: nums = [1,2,3,4]
输出: 24     （2*3*4）

输入: nums = [-1,-2,-3]
输出: -6    （-1*-2*-3，全负数时只能取"最不负"的三个）
```

约束：`3 <= nums.length <= 10⁴`，`-1000 <= nums[i] <= 1000`。

---

## 思路：候选只有两种

乘积最大的三个数，只可能出自两种组合：

1. **最大的三个数** `max1 * max2 * max3`
2. **最小的两个数 × 最大的数** `min1 * min2 * max1`（两个负数负负得正，再乘最大正数）

直觉证明：排好序后，乘积最大必然尽可能选绝对值大的数。全正/混合时方案 1 保底；存在两个绝对值很大的负数时方案 2 可能反超。没有第三种形态——三个负数乘积为负，永远不如以上两者（除非全负数数组，此时方案 1 恰好就是正确答案）。

### 解法一：排序（O(n log n)）

```cpp
class Solution {
public:
    int maximumProduct(vector<int>& nums) {
        const int n = nums.size();
        sort(nums.begin(), nums.end());
        return max(
            nums[n - 1] * nums[n - 2] * nums[n - 3],  // 最大三个
            nums[0] * nums[1] * nums[n - 1]           // 最小两个 × 最大
        );
    }
};
```

### 解法二：单趟扫描（O(n)）

只需要最大的 3 个和最小的 2 个，排序是浪费——一趟扫描维护五个变量：

```cpp
class Solution {
public:
    int maximumProduct(vector<int>& nums) {
        int max1 = INT_MIN, max2 = INT_MIN, max3 = INT_MIN;
        int min1 = INT_MAX, min2 = INT_MAX;
        for (int num : nums) {
            // 更新前三大（链式下移）
            if (num > max1)      { max3 = max2; max2 = max1; max1 = num; }
            else if (num > max2) { max3 = max2; max2 = num; }
            else if (num > max3) { max3 = num; }
            // 更新前二小
            if (num < min1)      { min2 = min1; min1 = num; }
            else if (num < min2) { min2 = num; }
        }
        return max(max1 * max2 * max3, min1 * min2 * max1);
    }
};
```

---

## 关键细节

### 1. 链式下移的顺序

更新前三大时，`max3 = max2` 必须在 `max2 = ...` **之前**——先把旧值往下挤，再覆盖。写反了 `max2` 的新值会污染 `max3`。这和手动实现插入排序的"挪位置"是同一个模式。

### 2. 为什么不用维护"最小的三个"

三个负数的乘积是负的，只有全负数数组才轮到它——但那时"最大的三个"就是绝对值最小的三个负数，方案 1 已经覆盖。所以五个变量够了。

### 3. 初始化哨兵

`INT_MIN` / `INT_MAX` 做哨兵是安全的：约束 `n >= 3`，扫描结束时五个变量必然都被真实值覆盖。

---

## 复杂度

| 指标 | 排序版 | 单趟扫描 |
|------|--------|---------|
| 时间 | O(n log n) | **O(n)** |
| 空间 | O(log n)（排序栈） | O(1) |
| 代码量 | 3 行 | ~15 行 |

对拍验证：300 组随机（含负数）与暴力枚举三元组完全一致。`n = 10⁴` 时两版都能过，排序版是面试先手答案，扫描版展示优化意识。

---

## 踩坑点 / 注意点

- ❌ **只考虑"最大的三个"**。有负数时 `min1 * min2 * max1` 可能反超，`[-100,-98,-1,2,3,4]` 的答案是 `-100*-98*4 = 39200`，不是 `2*3*4`。
- ❌ **全负数时想特判**。不用特判——全负数时"最大的三个"恰好是绝对值最小的三个，方案 1 自动正确。
- ❌ **链式下移顺序写反**。见关键细节 1。
- ❌ **溢出**。`1000³ = 10⁹` 在 int 范围内（`INT_MAX ≈ 2.1×10⁹`），但如果值域放宽到 `10⁵` 就必须用 `long long`。
