# 孤独像素 I（531. Lonely Pixel I）

## 题意

`n × m` 字符矩阵，只有 `'B'`（黑）和 `'W'`（白）。一个黑色像素是**孤独的**，当且仅当它所在的**行和列都没有其他黑色像素**。求孤独像素的个数。

```
输入: picture = [["W","W","B"],
                 ["W","B","W"],
                 ["B","W","W"]]
输出: 3        （三个 B 各自独占行列）

输入: picture = [["B","B","B"],
                 ["B","B","W"],
                 ["B","B","B"]]
输出: 0
```

约束：`1 <= n, m <= 500`。

---

## 思路：先聚合统计，再逐格判定

对每个 B 格直接扫它的行和列是 O(nm(n+m))。换个顺序：**第一遍**遍历把每行、每列的 B 数预聚合到 `row_cnt` / `col_cnt`；**第二遍**遍历时查表判定——B 格孤独 ⇔ `row_cnt[i] == 1 && col_cnt[j] == 1`（这个 1 就是它自己）。两遍 O(nm)。

## 解法：两遍扫描 + 行列计数

```cpp
class Solution {
public:
    int findLonelyPixel(vector<vector<char>>& picture) {
        const int n = picture.size();
        const int m = picture[0].size();
        // 行列下标连续，数组定址即可，无需哈希表
        vector<int> row_cnt(n, 0);
        vector<int> col_cnt(m, 0);
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (picture[i][j] == 'B') {
                    row_cnt[i]++;
                    col_cnt[j]++;
                }
            }
        }
        int count = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (picture[i][j] == 'B' && row_cnt[i] == 1 && col_cnt[j] == 1) {
                    count++;
                }
            }
        }
        return count;
    }
};
```

---

## 核心理解

### 1. "逐个查询"改"批量预聚合"是通用套路

暴力版对每个 B 格重复扫描行和列，同一行被扫了"该行 B 数"次。当**查询结构固定**（永远是整行/整列）时，把查询结果预先聚合一次、后续 O(1) 查表，几乎总是对的。前缀和、行列计数、直方图都是这个思想的实例。

### 2. `== 1` 天然处理"排除自身"

孤独定义要求"同行同列无**其他** B"。暴力版要小心翼翼跳过 `(i, j)` 自身；计数版不用——`row_cnt[i]` 把当前格也算进去了，所以条件写成 `== 1` 而不是 `== 0`。**计数包含自身时，阈值要 +1**，这个换算别忘了。

### 3. 条件合并与短路

判定 `picture[i][j] == 'B' && row_cnt[i] == 1 && col_cnt[j] == 1` 把"是 B"放最前：绝大多数格子是 W 时直接短路，两次数组访问都省了。条件顺序按**区分度**排，成本最低、筛掉最多的放前面。

---

## 复杂度

| | 时间 | 空间 |
|--|------|------|
| 两遍扫描 | O(nm) | O(n + m) |

验证：对拍一个"每个 B 格直接扫其行列"的暴力 oracle。官方 3 样例 + **穷举 16 格以内全部 2^(n·m) 个 01 网格**（74,954 个）+ 300 组随机网格（≤30×30，三档密度），**75,257 条断言全过**。

---

## 踩坑点 / 注意点

- ❌ **阈值写成 `== 0`**。计数包含当前格，孤独的行/列计数是 1 不是 0；写 0 则永远没有答案。
- ❌ **暴力版忘排自身**：扫行时把 `(i, j)` 自己也数进去，就再找不到孤独像素了。
- ⚠️ **矩阵行列数从哪拿**：`n = picture.size()`、`m = picture[0].size()`，题面保证每行等长且非空；约束一松（空矩阵、锯齿数组）这两个取值都会出事。
