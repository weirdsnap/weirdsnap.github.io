# 找出变位映射（760. Find Anagram Mappings）

## 题意

`nums2` 是 `nums1` 的变位词（**可能含重复值**）。返回下标映射 `mapping`，使得 `mapping[i] = j` 表示 `nums1[i]` 出现在 `nums2[j]`。多个答案时**返回任意一个**。

```
输入: nums1 = [12,28,46,32,50], nums2 = [50,12,32,46,28]
输出: [1,4,3,2,0]

输入: nums1 = [84,46], nums2 = [84,46]
输出: [0,1]
```

约束：`1 <= nums1.length == nums2.length <= 100`，元素 `<= 10⁵`。

---

## 思路：值 → nums2 中的位置（们）

无重复时一个 `unordered_map<int, int>`（值 → 下标）就够了。有重复值时，每个值要维护**一串**可用下标，每被 `nums1` 消费一次就弹出一个。

## 解法一：单值 + 溢出队列（第一版）

```cpp
class Solution {
public:
    vector<int> anagramMappings(vector<int>& nums1, vector<int>& nums2) {
        unordered_map<int, int> pos;           // 每个值只存一个"当前待用"下标
        unordered_map<int, vector<int>> dups;  // 重复值的其余下标
        for (int i = 0; i < nums2.size(); i++) {
            auto it = pos.find(nums2[i]);
            if (it == pos.end()) {
                pos[nums2[i]] = i;               // 首次出现
            } else {
                dups[nums2[i]].push_back(it->second); // 旧下标转入队列
                it->second = i;                        // 保留下标 i
            }
        }
        vector<int> mapping(nums1.size());
        for (int i = 0; i < nums1.size(); i++) {
            auto it = pos.find(nums1[i]);
            mapping[i] = it->second;
            auto d = dups.find(nums1[i]);
            if (d != dups.end() && !d->second.empty()) {
                it->second = d->second.back();  // 从队列回填下一个待用下标
                d->second.pop_back();
            }
        }
        return mapping;
    }
};
```

## 解法二：值 → 下标栈（简化版）

```cpp
class Solution {
public:
    vector<int> anagramMappings(vector<int>& nums1, vector<int>& nums2) {
        unordered_map<int, vector<int>> index;
        for (int i = 0; i < nums2.size(); i++) {
            index[nums2[i]].push_back(i);
        }
        vector<int> mapping(nums1.size());
        for (int i = 0; i < nums1.size(); i++) {
            auto& v = index[nums1[i]];   // 取引用，避免重复哈希查找
            mapping[i] = v.back();
            v.pop_back();
        }
        return mapping;
    }
};
```

---

## 核心理解

### 1. 解法一是无收益的复杂化

"为每个值都分配 vector 太浪费"的动机可以理解，但代价是：双结构、两套状态迁移（转入队列、回填）、两个 map 各查一次。复杂度和解法二完全一样，出错面却翻倍——而且重复值一多，`dups` 就退化得和 `index` 一模一样，省的东西不存在。**标准容器的"笨"写法先跑通， profiling 证明有热点再优化**，这题 n ≤ 100，优化纯属自我感动。

### 2. 答案不唯一，验证要用"合法性"而不是"比对输出"

重复值存在时合法映射有多个（`[1,1]` 的映射可以是 `[0,1]` 也可以是 `[1,0]`）。所以本题的自动化对拍不能 `CHECK(got == want)`，要校验三条性质：下标都在界内、**每个 j 最多被用一次**、`nums2[mapping[i]] == nums1[i]`。这也是写测试的一般原则：**输出不唯一的题，断言性质，不断言具体值**。

### 3. `pop_back` 取用顺序无所谓

栈序（LIFO）取出下标，重复值的映射顺序会反过来——但因为任意合法映射都算对，顺序完全自由。这是"答案不唯一"红利：不用维护 FIFO 队列，`vector::back/pop_back` 的 O(1) 最顺手。

---

## 复杂度

| | 解法一 | 解法二 |
|--|--------|--------|
| 时间 | O(n) 均摊 | O(n) 均摊 |
| 空间 | O(n) | O(n) |

验证：穷举 {0,1,2} 上全部长度 ≤ 8 的 nums1 × 4 种 nums2 排列（原序/逆序/两次 shuffle）× 两版 + 300 组重重复值随机对，全部做**合法性校验**（界内、不重复占用、值相等）。79,324 条断言全过。

---

## 踩坑点 / 注意点

- ❌ **解法一的状态迁移顺序写反**。必须先 `push_back(旧下标)` 转入队列，再 `it->second = i` 保留新下标；反了会把同一个下标既入队又当当前值，重复分配。
- ❌ **`pos.find` 不判 `end()` 就解引用**。本题由"变位词"约束兜底（值必然存在），但换个题就是 UB——防御性判断的成本极低。
- ❌ **`v.back()` 前不确认非空**。解法二靠变位词约束保证每个值的栈恰好够用；约束一松（比如 nums1 有 nums2 没有的字符）立刻崩。
