# 唯一异或三元组（3514. Unique XOR Triplets）

## 题意

给定一个数组 `nums`，求有多少个不同的 `nums[i] ^ nums[j] ^ nums[k]` 值（`i`、`j`、`k` 可以相同）。

```
输入: nums = [1,2,3]
输出: 4

解释: 所有三元组：
      1^1^1 = 1, 1^1^2 = 2, 1^1^3 = 3, 1^2^2 = 1, 1^2^3 = 0, ...
      不同的结果：0, 1, 2, 3，共 4 个
```

---

## 思路

### 关键观察

题目限制 `nums[i] <= 1500`，而 `1500 < 2^11 = 2048`。三个数的异或结果最大不超过 `2047`（11 位全 1）。

这意味着：**结果空间很小（只有 2048 种可能），可以用布尔数组标记存在性**。

### 分步枚举

直接三重循环枚举 `i, j, k` 是 O(n³)，会超时。利用异或的结合律，分两步：

1. **枚举所有 `a ^ b`**：两层循环，标记 `hasAB[x] = true`
2. **枚举所有 `(a ^ b) ^ c`**：对第一步的每个结果，再异或上所有可能的 `c`

```
(a ^ b) ^ c = a ^ b ^ c
```

### 为什么用 vector<bool> 而不是 unordered_set？

- `vector<bool>(2048)`：固定空间，O(1) 访问，缓存友好
- `unordered_set<int>`：动态扩容，哈希开销，缓存不友好

在结果空间很小且确定时，`vector<bool>` 更快。

---

## 代码

```cpp
class Solution {
public:
    int uniqueXorTriplets(vector<int>& nums) {
        // 去重：相同的数异或结果一样，没必要重复枚举
        unordered_set<int> s(nums.begin(), nums.end());
        vector<int> vals(s.begin(), s.end());
        
        // 第一步：枚举所有 a ^ b
        vector<bool> hasAB(2048, false);
        for (int a : vals) {
            for (int b : vals) {
                hasAB[a ^ b] = true;
            }
        }
        
        // 第二步：枚举所有 (a ^ b) ^ c
        vector<bool> hasABC(2048, false);
        for (int x = 0; x < 2048; x++) {
            if (!hasAB[x]) continue;  // 剪枝：不存在的 a^b 跳过
            for (int c : vals) {
                hasABC[x ^ c] = true;
            }
        }
        
        // 统计
        int ans = 0;
        for (bool b : hasABC) {
            if (b) ans++;
        }
        return ans;
    }
};
```

---

## 关键细节

### 1. 去重优化

```cpp
unordered_set<int> s(nums.begin(), nums.end());
```

如果 `nums` 有大量重复元素，去重后枚举量大幅减少。

### 2. 剪枝

```cpp
if (!hasAB[x]) continue;
```

第一步没有标记的 `x`，第二步不需要处理。

### 3. 空间大小为什么是 2048？

`nums[i] <= 1500 < 2^11`，所以：
- `a ^ b` 最多 11 位，范围 `[0, 2047]`
- `(a ^ b) ^ c` 也最多 11 位，范围 `[0, 2047]`

如果题目限制变大（如 `nums[i] <= 10^5`），需要相应扩大数组。

---

## 复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(m² + 2048×m) | m 为去重后的不同元素个数 |
| 空间 | O(2048) | 两个布尔数组 |

最坏情况 `m = n = 1500`：
- 第一步：1500² = 2.25×10⁶
- 第二步：2048 × 1500 ≈ 3×10⁶
- 总计约 5×10⁶，轻松通过

---

## 踩坑点 / 注意点

- ❌ **三重循环枚举 i, j, k**。O(n³) 会超时，必须利用异或结合律分步。
- ❌ **忘记去重**。重复元素会导致重复计算，虽然结果正确但浪费时间。
- ❌ **数组大小设错**。如果 `nums[i]` 可能达到 `10^5`，2048 不够，需要 `1 << 17 = 131072`。
- ❌ **用 `vector<char>` 代替 `vector<bool>`**。`vector<bool>` 是位压缩的，空间更省；但注意它不是标准容器，不支持取地址。
- ❌ **忽略 `i, j, k` 可以相同**。题目允许下标相同，所以 `a ^ a ^ a = a` 也是合法结果。
