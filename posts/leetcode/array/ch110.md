# 有海景的楼（1762. Buildings With an Ocean View）

## 题意

`n` 栋楼一字排开，高度为 `heights[i]`，大海在数组右侧。一栋楼右边（不含自己）所有楼都严格比它矮，它就有海景。返回所有有海景的楼的下标，升序。

```
输入: heights = [4,2,3,1]
输出: [0,2,3]
输入: heights = [4,3,2,1]
输出: [0,1,2,3]
输入: heights = [1,3,2,4]
输出: [3]
```

- `1 <= n <= 10^5`，`1 <= heights[i] <= 10^5`

## 思路

"右边所有楼都比它矮"等价于"它比右边的最大值还高"。从右往左扫一遍，顺手维护右边的最大值 `max_h`，`heights[i] > max_h` 就收下标。

收集到的下标是逆序的，最后排个序即可。

```cpp
class Solution {
public:
    vector<int> findBuildings(vector<int>& heights) {
        const int n = heights.size();
        int max_h = -1;
        vector<int> result;
        for (int i = n - 1; i >= 0; i--) {
            if (heights[i] > max_h) {
                result.push_back(i);
            }
            max_h = max(max_h, heights[i]);
        }
        sort(result.begin(), result.end());
        return result;
    }
};
```

## 关键点

- 判断是严格大于：同高就遮挡，初始 `max_h = -1` 配合高度下界 1，保证最右边的楼必有海景。
- 收集顺序天然是下标逆序，所以最后 `reverse` 一下就是升序，比 `sort` 省一个 log，代码里用 `sort` 也没毛病。
- 这题是单调栈"从右往左维护递减栈"的退化版：只关心"有没有比我大的"，最大值一个变量就够，不用真的开栈。要求"下一个比我大的是谁"（496、503 那种）才需要栈把弹出的元素一个个对上号。

## 复杂度

- 时间：O(n log n)，扫描 O(n)，瓶颈在最后那次 `sort`（换 `reverse` 就是 O(n)）
- 空间：O(1)，不计返回值
