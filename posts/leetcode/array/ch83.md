# 缺失的区间（163. Missing Ranges）

## 题意

升序无重复的 `nums`，所有元素都在 `[lower, upper]` 内。返回该闭区间内**没被 nums 覆盖的所有极大区间**（闭区间形式）。

```
输入: nums = [0,1,3,50,75], lower = 0, upper = 99
输出: [[2,2],[4,49],[51,74],[76,99]]

输入: nums = [-1], lower = -1, upper = -1
输出: []

输入: nums = [], lower = 1, upper = 1
输出: [[1,1]]
```

约束：`0 <= nums.length <= 100`，`-10⁹ <= lower <= upper <= 10⁹`。

---

## 思路：把 lower−1 和 upper+1 当虚拟元素

在 nums 首尾各塞一个虚拟哨兵后，每对相邻元素 `(prev, cur)` 之间的缺失区间就是 `[prev+1, cur-1]`（为空则跳过）。代码上用 `start` 滚动记录"下一段缺失区间的左端点"：遍历每个 `num`，若 `num > start` 则 `[start, num-1]` 是一段缺失；随后 `start = num + 1`。循环结束后再用 `upper` 收一次尾，等价于补上右哨兵。

## 解法：哨兵扫描

```cpp
class Solution {
public:
    vector<vector<int>> findMissingRanges(vector<int>& nums, int lower, int upper) {
        vector<vector<int>> result;
        // long long 防御：num = INT_MAX 时 num+1 溢出 int
        long long start = lower;
        for (int num : nums) {
            if (num > start) {
                result.push_back({(int)start, num - 1});
            }
            // 当前元素充当下一段区间的左哨兵
            start = (long long)num + 1;
        }
        // upper 充当尾部哨兵，统一处理末尾缺失区间
        if (start <= upper) {
            result.push_back({(int)start, upper});
        }
        return result;
    }
};
```

---

## 核心理解

### 1. 哨兵把"三种边界"统一成一种

缺失区间有三种形态：开头（lower 到首元素前）、中间（相邻元素间）、结尾（末元素后到 upper）。不加哨兵要分三段写；把边界当成"虚拟数组元素"后，三种形态变成同一个"相邻元素求间隙"的操作。本题用 `start = lower` 起滚 + 循环后补尾，与显式插入 `lower-1 / upper+1` 是等价的两种写法。**首尾特判多的扫描题，先想想能不能用哨兵消掉。**

### 2. 条件是 `num > start`，不是 `>=`

`num == start` 意味着该元素正好是期望的下一个整数，无缺失；只有严格大于才产生区间 `[start, num-1]`。写成 `>=` 会推出 `[x, x-1]` 这种空区间。闭区间端点的 +1/−1 方向要边写边默念一遍。

### 3. 输出是"区间集合"时，性质校验比逐值对拍更独立

这类题的自动验证不必重写一遍算法对拍，直接断言输出应满足的**定义性质**更可靠：区间升序不相交、相邻区间不能贴在一起（否则应合并）、区间内不含任何 nums 元素、区间与 nums 合并后无缝铺满 `[lower, upper]`。四条性质独立成立 ⇒ 答案唯一正确。

## 踩坑点 / 注意点

- ❌ **忘记空 nums**：此时答案是 `[[lower, upper]]`，哨兵写法天然覆盖，分段写法容易漏。
- ❌ **`num + 1` / `num - 1` 溢出**。本题约束 ±10⁹ 时 int 够用，但若值域到 INT_MIN/INT_MAX（验证里专门测了这个），`int` 直接 UB。涉及端点 ±1 的区间题，`long long` 是廉价保险。
- ❌ **条件方向写反**：`num > start` 推 `[start, num-1]`；写成 `num >= start` 会产出空区间。
- ❌ **收尾漏一刀**：循环只处理"元素之间"，末元素到 upper 的尾部区间必须在循环后单独检查 `start <= upper`。
