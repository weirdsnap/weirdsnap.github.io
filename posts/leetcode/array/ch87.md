# 构造统一奇偶数组 I（3875. Construct Uniform Parity Array I）

## 题意

给定互异的数组 `nums1`，对每个下标 `i` 二选一：`nums2[i] = nums1[i]`，或 `nums2[i] = nums1[i] - nums1[j]`（`j != i`，**无大小限制**，差可以是负数）。问能否构造出**全奇或全偶**的 `nums2`。

```
输入: nums1 = [2,3]
输出: true    （2-3=-1, 保持 3 → [-1,3] 全奇）

输入: nums1 = [4,6]
输出: true    （保持原样，全偶）
```

约束：`n <= 100`，值 `1..100`，互异。

---

## 思路：答案恒为 true

- 若 `nums1` 已经全奇或全偶：直接照抄。
- 若奇偶混杂：任取一个奇数 `o` 和一个偶数 `e`（混杂保证两者都存在），把所有奇数改成 `x - e`（奇−偶=奇），偶数改成 `x - o`（偶−奇=奇），**全体变奇**。差为负也合法，因为没有任何 `>= 1` 之类的约束。

两种情况都行得通，所以无论输入是什么，答案都是 `true`。

## 解法：一行

```cpp
class Solution {
public:
    bool uniformArray(vector<int>& nums1) {
        return true;
    }
};
```

---

## 核心理解

### 1. 脑筋急转弯题的识别信号

操作次数**不受限**、结果值域**不受限**（允许负数）、只问**可行性**不问方案。三个信号齐了，往往存在"恒可达"的构造。这时候别急着写搜索，先问：**什么输入会让它失败？** 本题里找不到任何失败情形，于是答案是常量。

### 2. 证明"恒 true"也要给出构造

"感觉总能行"不是证明。本题的构造非常具体：混杂时挑一对 `(o, e)`，奇数减偶、偶数减奇，全体归奇。**写下显式构造**，既完成证明，也是续作（3876）被否决时的对照基准。

### 3. 和 II 的分界线就一条约束

3876 只多了 `nums1[i] - nums1[j] >= 1`（即只能减去**严格更小**的元素）。这一条把"全体归奇"的构造掐死了：最小的那个元素没有更小的可减，它的奇偶性锁死了整个目标。同一副骨架，一个约束之差，从 O(1) 脑筋急转弯变成需要分析锁死效应的题。

## 踩坑点 / 注意点

- ❌ **把 II 的约束脑补进 I**（或反之）。两题题面长得几乎一样，唯一差别就是 `>= 1` 那条，提交前对一遍题号。
- ⚠️ **"恒 true"也要敢写**。周赛 Q1 出这种题就是考你敢不敢相信自己的构造证明；验证过构造覆盖所有输入形态后，果断返回常量。
