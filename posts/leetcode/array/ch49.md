# 大于等于顺序前缀和的最小缺失整数（2996. Smallest Missing Integer Greater Than Sequential Prefix Sum）

## 题意

给定数组 `nums`。前缀 `nums[0..i]` 是**顺序前缀**当且仅当对每个 `1 <= j <= i` 都有 `nums[j] == nums[j-1] + 1`（仅含 `nums[0]` 的前缀也算）。求**不在数组中**且**大于等于最长顺序前缀之和**的最小整数 `x`。

```
输入: nums = [1,2,3,2,5]
输出: 6
解释: 最长顺序前缀是 [1,2,3]，和为 6。6 不在数组中，答案即 6。

输入: nums = [3,4,5,1,12,14,13]
输出: 15
解释: 最长顺序前缀 [3,4,5] 和为 12。12 在数组中，13、14 也在，15 才是缺失的。
```

约束：`1 <= nums.length <= 50`，`1 <= nums[i] <= 50`。

---

## 思路

两步模拟：先扫描出最长顺序前缀求和，再从 `sum` 开始递增找第一个不在数组中的数。

```cpp
class Solution {
public:
    int missingInteger(vector<int>& nums) {
        int sum = nums[0];
        for (int i = 1; i < nums.size(); i++) {
            if (nums[i] != nums[i - 1] + 1) break;  // 顺序前缀到此为止
            sum += nums[i];
        }

        // 直接在原数组上线性查找，不开哈希表
        while (true) {
            bool found = false;
            for (const int& x : nums) {
                if (x == sum) { found = true; break; }
            }
            if (!found) break;
            sum++;
        }
        return sum;
    }
};
```

---

## 关键细节

### 1. 第二阶段为什么可以不开哈希表

`n ≤ 50`，查找循环最多执行 50 次（`nums[i] ≤ 50`，`sum` 起点最小也是 1，递增 50 次内必然脱出所有可能命中），每次线性扫描 O(n)。总复杂度 O(n²) = 2500 次比较，比 `unordered_set` 的哈希计算 + 内存分配还快。

对比哈希版（语义更直观，约束大时该用它）：

```cpp
unordered_set<int> s(nums.begin(), nums.end());
while (s.count(sum)) sum++;
return sum;
```

两版随机对拍 500 组（`n ∈ [1,50]`，值域 `[1,50]`）结果完全一致。

### 2. 第一阶段终止条件的两种读法

`nums[i] != nums[i-1] + 1` 时 `break`——注意 `nums[0]` 单独成前缀，所以 `sum` 从 `nums[0]` 开始、循环从 `i = 1` 开始，不用特判空数组（约束保证非空）。

### 3. 第二阶段的循环上界

`while (true)` 看起来没边界，实际必然终止：`sum` 每次 +1，而数组只有 50 个元素，最多连续命中 50 次。更紧的界：值域 `[1,50]`，`sum` 一旦超过 50 就不可能再在数组中。

---

## 复杂度

| 指标 | 线性扫描版 | 哈希集合版 |
|------|-----------|-----------|
| 时间 | O(n²)，实测常数极小 | O(n) 均摊 |
| 空间 | O(1) | O(n) |

`n = 50` 时两版差距可以忽略；约束放大到 `10^5` 级别时哈希版才是正确选择。

---

## 踩坑点 / 注意点

- ❌ **把"顺序前缀"理解成"排序后的前缀"**。是**相邻元素恰好 +1** 的前缀，和排序无关，`[3,4,5,1,...]` 的前缀在 `1` 处断开。
- ❌ **忘记 `sum` 本身可能在数组中出现多次命中**。`12, 13, 14` 都在数组中时要连续 +1 三次，用 `if` 只跳一次就错了，必须是 `while`。
- ❌ **第一阶段循环从 `i = 0` 开始**。`nums[0]` 没有前驱，`nums[-1]` 越界；从 `i = 1` 开始，`sum` 初始化为 `nums[0]`。
