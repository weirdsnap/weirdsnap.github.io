# 唯一异或三元组 I（3513. Number of Unique XOR Triplets I）

## 题意

给定长度为 `n` 的数组 `nums`，它是 `[1, 2, ..., n]` 的一个排列。统计所有三元组 `nums[i] ^ nums[j] ^ nums[k]`（`i <= j <= k`，下标可重复）能得到的**不同值的个数**。

```
输入: nums = [1, 2]
输出: 2
解释: 所有三元组的值: 1^1^1=1, 1^1^2=2, 1^2^2=1, 2^2^2=2 → {1, 2}

输入: nums = [1, 2, 3, 4]
输出: 8
```

约束：`1 <= n <= 10⁵`。

---

## 思路

暴力枚举三元组是 O(n³)，`n = 10⁵` 完全没戏。但这道题的答案**只取决于 n，和排列顺序无关**：

- `n = 1`：答案 1
- `n = 2`：答案 2
- `n >= 3`：答案是**大于 n 的最小 2 的幂**

```cpp
class Solution {
public:
    int uniqueXorTriplets(vector<int>& nums) {
        const int n = nums.size();
        if (n == 1) return 1;
        if (n == 2) return 2;
        int m = 1;
        while (m <= n) m <<= 1;  // 大于 n 的最小 2 的幂
        return m;
    }
};
```

`nums` 的具体内容根本不用读——它是 `1..n` 的排列这一条就够了。

---

## 核心理解：为什么 n ≥ 3 时恰好能造出 [0, 2^k - 1] 的全部整数

设 `2^k` 是大于 `n` 的最小 2 的幂，即 `2^(k-1) <= n < 2^k`。结论：**能异或出的值恰好是 `[0, 2^k - 1]`，共 `2^k` 个**。分两半证明。

### 上界：超不出 2^k

三个操作数都 `< 2^k`，二进制最高位不超过第 `k-1` 位。XOR 不产生新的高位，结果必然 `< 2^k`。所以不同值最多 `2^k` 个。

### 下界之 trivial 部分：[0, n] 都能造

- `v ∈ [1, n]`：`v = v ^ 1 ^ 1`（下标允许重复，1 可以用两次）
- `v = 0`：`0 = 1 ^ 2 ^ 3`，这里用到 `n >= 3`

### 下界之关键部分：(n, 2^k - 1] 也能造

这是整道题的精华。令 `h = 2^(k-1)`（`n` 的最高位）。对 `v ∈ (n, 2^k - 1]`：

- `v > n >= h` 且 `v < 2^k`，所以 **`v` 的最高位恰好也是 `h`**
- 令 `r = v ^ h = v - h`，则 `r <= h - 1 <= n - 1`，且 `v > n >= h` 保证 `r >= 1`

于是 `v = h ^ r`，只需把 `r` 拆成两个 `[1, n]` 内数的 XOR：

| 情况 | 构造 | 合法性 |
|------|------|--------|
| `r >= 2` | `v = h ^ 1 ^ (r ^ 1)` | `r ^ 1 != 0`（因 `r != 1`），`r ^ 1 <= r + 1 <= n` |
| `r = 1` | `v = h ^ 2 ^ 3` | `2 ^ 3 = 1`，用到 `n >= 3` |

所有操作数都在 `[1, n]` 内，构造完成。上下界一夹，恰好 `2^k` 个。

### n = 1, 2 为什么特判

`n = 2` 时 `{1^1^1, 1^1^2, 1^2^2, 2^2^2} = {1, 2}`——**0 造不出来**，因为 `1 ^ 2 ^ 3 = 0` 需要 3。`n = 1` 只有 `1^1^1 = 1`。两者都是公式会多算的情形，单独返回。

## 复杂度

| 指标 | 公式版 | 暴力枚举 |
|------|--------|----------|
| 时间 | O(log n) | O(n³) |
| 空间 | O(1) | O(2^k)（集合） |

验证：`n = 1..64` 全量对拍（公式版 vs 暴力枚举集合大小）全部一致；`n = 3..40` 额外逐值检查暴力集合恰好覆盖 `[0, 2^k)` 一个不缺；随机打乱排列 50 组答案不变。1407 条断言全过。

---

## 踩坑点 / 注意点

- ❌ **读题漏掉"下标可重复"**。`i <= j <= k` 允许 `i == j`，`v ^ 1 ^ 1` 这类构造才合法。如果下标必须互不相同，`[0, n]` 的构造就要重写。
- ❌ **忘记特判 `n = 1, 2`**。公式对 `n = 2` 给出 4，但 0 和 3 都造不出来，真实答案是 2。
- ❌ **`while (m <= n) m <<= 1` 写成 `m = m << 1` 忘赋值或写成 `<`**。条件是 `<=`：要找的是**严格大于** n 的 2 的幂，`n = 4` 时答案是 8 不是 4（`[0, 7]` 里 5、6、7 要靠 `h = 4` 拆出来）。
- ❌ **试图真的去枚举或记忆化**。这题是数学题，看出"答案只依赖 n"就结束了。
