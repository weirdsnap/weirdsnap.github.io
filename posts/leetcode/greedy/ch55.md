# 数组中的最大距离（624. Maximum Distance in Arrays）

## 题意

给定 `m` 个**各自升序**的整数数组，从中选取**两个不同数组**各取一个数 `a`、`b`，求 `|a - b|` 的最大值。

```
输入: arrays = [[1,2,3],[4,5],[1,2,3]]
输出: 4
解释: 取第 2 个数组的 5 和第 0 或第 2 个数组的 1，|5 - 1| = 4

输入: arrays = [[-10],[0,100]]
输出: 110
```

约束：数组个数 `m >= 2`，每个数组非空且升序，元素范围 `[-10⁴, 10⁴]`。

---

## 思路：只关心每个数组的首尾

`|a - b|` 要大，必然是一个数组的**最小值**配另一个数组的**最大值**。既然每个数组已升序，每个数组有用信息就只有两个数：`front()` 和 `back()`，中间的元素永远不可能出现在最优解里。

剩下的唯一障碍是"两个数必须来自**不同**数组"：全局最小值和全局最大值可能落在同一个数组里，不能直接 `全局max - 全局min`。

### 贪心：滚动维护"之前数组"的最值

遍历到第 `i` 个数组时，用它的首尾去和**之前所有数组**的滚动最值配对：

```cpp
class Solution {
public:
    int maxDistance(vector<vector<int>>& arrays) {
        int result = 0;
        int last_min = arrays[0].front();
        int last_max = arrays[0].back();
        for (size_t i = 1; i < arrays.size(); ++i) {
            auto& array = arrays[i];              // 引用避免拷贝整个 vector
            int min_num = array.front();
            int max_num = array.back();
            result = max(result, max_num - last_min);
            result = max(result, last_max - min_num);
            last_min = min(last_min, min_num);
            last_max = max(last_max, max_num);
        }
        return result;
    }
};
```

**为什么这是对**的：设最优配对是数组 `i` 的某个端点和数组 `j` 的某个端点，不妨设 `j` 后处理。遍历到 `j` 时，`last_min / last_max` 是 `0..j-1` 的最值，其中包含数组 `i` 的端点。而滚动最值只会比数组 `i` 自己的端点**更极端**（`last_min <= min_i`，`last_max >= max_i`），用它配对算出的候选**不小于**真实最优值；同时滚动最值一定来自 `j` 之前的某个数组，"不同数组"约束天然满足。所以候选一定在某个时刻被算到，且不会算出一个非法的更大值。

**特点**：一趟遍历，O(m) 时间、O(1) 额外空间，连"最值同数组要取次优配对"这个问题都不需要显式处理——滚动最值在配对时还没并入当前数组，冲突天然不存在。

---

## 关键细节

### 1. 配对方向要算两种

`max_num - last_min` 和 `last_max - min_num` 都要试。当前数组可能贡献"大的那一头"（它的 max 配之前的 min），也可能贡献"小的那一头"（它的 min 配之前的 max），少算一个就漏解。

### 2. result 初始化为 0 是安全的

`|a - b| >= 0` 恒成立，且 `m >= 2` 保证至少存在一对合法取数，所以用 0 做初始值不会掩盖真实答案。两个差值中间出现负数也无所谓（比如当前数组整体比之前的小），`max` 会把它过滤掉。

### 3. 不需要 sort

题目已保证每个数组升序，直接 `front() / back()`。没看到这条约束就排序属于浪费——但注意这和其他"自己排序"的题不同，这里排序的前提是题给的。

---

## 复杂度

| 指标 | 贪心 | 暴力枚举数对 |
|------|------|--------------|
| 时间 | O(m) | O((元素总数)²) |
| 空间 | O(1) | O(1) |

对拍验证：500 组随机（2~7 个数组、每个 1~6 个元素、值域 [-1000,1000]、组内排序）与暴力版完全一致（503 条断言全过）。

---

## 踩坑点 / 注意点

- ❌ **全局 min/max 直接相减**。最值可能来自同一个数组（如 `[[-10],[0,100]]` 之外的构造），违反"不同数组"约束。滚动配对法把这个约束消解在遍历顺序里，是最干净的写法。
- ❌ **只算一个方向**。只写 `max_num - last_min` 会漏掉"当前数组贡献小端"的情况，如 `[[5,6],[1,2]]`。
- ❌ **按值传参 `auto array = arrays[i]`**。每个数组拷贝一遍，白送 O(元素总数) 的时间和内存，用 `auto&`。
