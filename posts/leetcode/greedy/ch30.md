# 最大数位乘积（3536. Maximum Product of Two Digits）

## 题意

给定一个正整数 `n`，将其十进制表示中的两个数位相乘，求能得到的**最大乘积**。

```
输入: n = 31
输出: 3
解释: 数位为 3 和 1，最大乘积 = 3 * 1 = 3

输入: n = 22
输出: 4
解释: 两个 2 相乘 = 4

输入: n = 124
输出: 8
解释: 最大两个数位是 4 和 2，乘积 = 8
```

---

## 思路

### 关键观察

要让两个数的乘积最大，应该选**最大的两个数位**。这是贪心思想——局部最优（选最大）导致全局最优（乘积最大）。

### 解法一：数学法（O(1) 空间）

直接遍历数字的每一位，维护最大和次大值：

```cpp
class Solution {
public:
    int maxProduct(int n) {
        int max1 = 0, max2 = 0;  // 最大和次大数位
        
        while (n > 0) {
            int d = n % 10;   // 取末位
            n /= 10;          // 移除末位
            
            if (d >= max1) {  // >= 确保相等时也能更新次大值
                max2 = max1;
                max1 = d;
            } else if (d > max2) {
                max2 = d;
            }
        }
        
        return max1 * max2;
    }
};
```

### 解法二：排序法（代码短，但有额外开销）

```cpp
class Solution {
public:
    int maxProduct(int n) {
        string s = to_string(n);
        sort(s.begin(), s.end());
        return (s[s.size()-1] - '0') * (s[s.size()-2] - '0');
    }
};
```

---

## 关键细节

### 1. 为什么用 `>=` 而不是 `>`？

```cpp
if (d >= max1) {
    max2 = max1;  // 原最大值变成次大值
    max1 = d;     // 更新最大值
}
```

考虑 `n = 99`：
- 第一个 9：`max1 = 9, max2 = 0`
- 第二个 9：如果 `d > max1` 为假（9 > 9 不成立），`max2` 不会更新
- 结果：`9 * 0 = 0` ❌

用 `>=`：第二个 9 满足 `9 >= 9`，`max2 = 9, max1 = 9`，结果 `81` ✅

### 2. 两种解法对比

| | 数学法 | 排序法 |
|--|--------|--------|
| 时间 | O(log n) | O(d log d)，d 为数位个数 |
| 空间 | O(1) | O(d)，创建字符串 |
| 代码量 | 稍多 | 少 |
| 实际性能 | 快（无内存分配） | 慢（to_string + sort）|

**推荐**：数学法。排序法虽然代码短，但 `to_string` 和 `sort` 都有额外开销。

### 3. 边界情况

- `n` 只有两位：直接相乘
- `n` 有重复最大位（如 99, 888）：`>=` 确保次大值正确更新
- `n` 包含 0：不影响，0 不会成为最大或次大值（除非所有位都是 0，但 `n` 是正整数）

---

## 复杂度

| 指标 | 数学法 | 排序法 |
|------|--------|--------|
| 时间 | O(log n) | O(d log d) |
| 空间 | O(1) | O(d) |

`d` 是 `n` 的十进制位数，`d = log₁₀(n) + 1`。

---

## 踩坑点 / 注意点

- ❌ **用 `>` 代替 `>=`**。重复最大位时次大值无法更新。
- ❌ **排序法忘记 `- '0'`**。`s[s.size()-1]` 是字符 `'9'`，不是数字 9。
- ❌ **负数处理**。题目说 `n` 是正整数，无需处理负号。
- ❌ **只考虑不同位置的数位**。题目没说不能选同一个位置的数字两次，但两个不同位置恰好是最大和次大值，自然满足。
