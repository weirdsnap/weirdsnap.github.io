# 反转每对括号间的子串（1190. Reverse Substrings Between Each Pair of Parentheses）

## 题意

字符串 `s` 由小写字母和括号组成，括号可以嵌套。把每对括号里的子串反转（嵌套时从内到外逐层生效），返回不含括号的最终结果。

```
输入: "(abcd)"        输出: "dcba"
输入: "(u(love)i)"    输出: "iloveu"
输入: "(ed(et(oc))el)" 输出: "leetcode"
```

- `1 <= s.length <= 2000`，括号保证配对

## 解法一：栈分层，逐层反转

按嵌套结构模拟：`(` 把当前层压栈、开一个新层收集字符；`)` 把当前层原地反转，拼回上一层末尾。结果自然不含括号。

```cpp
class Solution {
public:
    string reverseParentheses(string s) {
        vector<char> str; // 用于 O(1) reverse
        vector<vector<char>> stk; // 模拟 string 栈，避免频繁字符串拼接
        for (const auto& c: s) {
            if (c == '(') {
                stk.push_back(str);
                str.clear();
            } else if (c == ')') {
                reverse(str.begin(), str.end()); // 原地反转当前层
                auto prev = std::move(stk.back());
                stk.pop_back();
                prev.insert(prev.end(), str.begin(), str.end());
                str = std::move(prev);
            } else {
                str.push_back(c);
            }
        }
        return string(str.begin(), str.end());
    }
};
```

关键点：

- 层缓冲用 `vector<char>` 而不是 `string`，配合 `insert` + `move` 拼回上一层，避免一遍遍的字符串拼接构造。
- 每个 `)` 反转一次当前层，嵌套 k 层的内容会被反转 k 次，所以最坏 O(n²)。n 只有 2000，完全够用。

## 解法二：括号配对 + 跳转，O(n)

先预处理出每个括号的配对下标，然后带方向遍历：遇到括号就瞬移到配对位置并掉头，普通字符直接收下。这等价于"从内到外逐层反转"的最终效果，但每个字符只被访问常数次。

```cpp
class Solution {
public:
    string reverseParentheses(string s) {
        int n = s.size();
        vector<int> match(n);
        stack<int> stk;
        // 记录每个括号的配对位置
        for (int i = 0; i < n; ++i) {
            if (s[i] == '(') {
                stk.push(i);
            } else if (s[i] == ')') {
                int j = stk.top();
                stk.pop();
                match[i] = j;
                match[j] = i;
            }
        }
        string res;
        // 按方向遍历，遇到括号跳到配对位置并反转方向
        for (int i = 0, dir = 1; i < n; i += dir) {
            if (s[i] == '(' || s[i] == ')') {
                i = match[i];
                dir = -dir;
            } else {
                res += s[i];
            }
        }
        return res;
    }
};
```

关键点：

- 直觉：一层反转就是让遍历方向在那对括号之间掉头。嵌套反转叠加起来，等价于每个括号都是一扇"传送门"，进去就镜像到另一端并反向走。
- 栈在这里只负责建 `match` 表，真正的遍历不再用栈。建表是括号匹配的标准套路：`(` 压下标，`)` 弹出即配对。
- `for` 的更新语句是 `i += dir`，循环体里 `i = match[i]` 改的是当前位置，下一次迭代才按新方向迈步，两者别写串。

## 复杂度

| | 时间 | 空间 |
|---|---|---|
| 解法一（栈分层） | O(n²) 最坏，嵌套每层反转一次 | O(n) |
| 解法二（配对跳转） | O(n) | O(n)，`match` 表 |
