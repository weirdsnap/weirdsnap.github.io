# 最多能拿多少本书（2355. Maximum Number of Books You Can Take）

## 题意

书架上第 `i` 层有 `books[i]` 本书。选一段**连续**的层 `[l, r]` 拿书，要求对 `l <= i < r`，从第 `i` 层拿的数量**严格少于**第 `i+1` 层。问最多能拿多少本。

```
输入: books = [8,5,2,7,9]
输出: 19
解释: 从 1~4 层分别拿 1, 2, 7, 9 本（5 层拿 1 本而不是 5 本，因为第 2 层只有 2 本可拿）

输入: books = [7,0,3,4,5]
输出: 12

输入: books = [8,2,3,7,3,4,0,1,4,3]
输出: 13
```

约束：`1 <= n <= 10⁵`，`0 <= books[i] <= 10⁵`。

---

## 思路：以谁结尾 + 断开位置

两个观察把题目拆开：

**观察 1：固定右端点 `i`，最优拿法唯一。** 严格递增的限制下，第 `i` 层最多拿 `books[i]` 本，拿满最划算；往前每层最多拿"右边那层减 1"本，同时不能超过该层存量，也不能小于 0。所以从右往左就是 `books[i], books[i]-1, books[i]-2, ...`，直到某一层**接不上**为止。

**观察 2：接不上的位置可以用单调栈找。** 第 `p` 层接不上第 `i` 层的条件是 `books[p] < books[i] - (i - p)`，移项得 `books[p] - p < books[i] - i`。也就是说，把每层看成 `books[k] - k` 这个值，维护一个**严格递增**的单调栈，栈顶就是最近的断开位置 `p`。段 `[p+1, i]` 是等差数列求和，再加上 `dp[p]`（`p` 之前的最优）就是 `dp[i]`。

`dp[i]` 表示以第 `i` 层结尾的连续段最多拿几本，答案是所有 `dp[i]` 的最大值。

## 解法：单调栈 + 等差求和

```cpp
class Solution {
public:
    long long maximumBooks(vector<int>& books) {
        // 以 i 结尾，最优取法是 books[i], books[i]-1, ...（差 1 最优）。
        // 往前找第一个"接不上"的位置 p：books[p] < books[i]-(i-p)
        //   => books[p]-p < books[i]-i
        // 用单调栈维护 books[k]-k 递增，栈顶就是断开位置 p。
        // 当前段 [p+1,i] 等差求和 + dp[p]。
        const int n = books.size();
        vector<long long> dp(n, 0);
        vector<int> st; // 单调递增栈，存下标，books[k]-k 严格递增

        for (int i = 0; i < n; i++) {
            // 弹掉冗余位置：books[栈顶]-栈顶 >= books[i]-i（这些位置对后面用不上）
            while (!st.empty() && books[st.back()] - st.back() >= books[i] - i) {
                st.pop_back();
            }

            // 断开位置 p = 栈顶（若存在），当前段从 p+1 开始
            int p = st.empty() ? -1 : st.back();

            // 递减序列最多 books[i] 个位置（books[i]=0 时 cnt=0，不能减到 0 以下）
            long long cnt = min((long long)(i - p), (long long)books[i]);
            // 等差数列求和：books[i], books[i]-1, ..., books[i]-cnt+1
            long long sum = cnt * (2LL * books[i] - cnt + 1) / 2;

            dp[i] = (p == -1 ? 0LL : dp[p]) + sum;

            st.push_back(i); // 先弹、再算、后压：当前 i 为未来的位置服务
        }

        long long ans = 0;
        for (long long v : dp) ans = max(ans, v);
        return ans;
    }
};
```

---

## 核心理解

### 1. 为什么是 `books[k] - k` 这个变形

"第 `p` 层接得上第 `i` 层"要求 `books[p] >= books[i] - (i - p)`。左边只和 `p` 有关、右边只和 `i` 有关的移项就是单调栈的经典信号：`books[p] - p >= books[i] - i`。把每个下标压成一个标量之后，"找最近断开点"就变成了"找左边第一个值更小的位置"，这是单调栈的模板活（和 ch24 柱状图找左右边界同构）。

### 2. 弹栈条件是 `>=`，等号不能少

`books[p] - p == books[i] - i` 时，第 `p` 层恰好只能拿"接上所需"的本数，再往前一层就要拿负的。也就是说相等的 `p` 对 `i` 而言已经断开了，必须弹掉，栈里保持**严格**递增。等号漏了，断开位置会找错一位。

### 3. `cnt = min(i - p, books[i])` 的另一层截断

等差递减不能减到负数：从 `books[i]` 出发最多往回拿 `books[i]` 层（拿到 1 为止）。所以段长取"断开距离 `i - p`"和"存量 `books[i]`"的较小值。`books[i] = 0` 时 `cnt = 0`，这一段贡献 0，`dp[i]` 退化为 `dp[p]`，天然处理了 0 层。

### 4. dp 的分段结构

`dp[i] = dp[p] + 段[p+1, i] 的等差和`，整个数组被断开位置切成了若干段，每段内部是"差 1 递减、到底截断"的最优拿法，段与段之间通过 dp 累加。最终答案取 `max(dp)` 而不是 `dp[n-1]`，因为最优段不一定延伸到末尾（末尾一层存量太小反而会拖累）。

| | 时间 | 空间 |

| 单调栈 + 等差求和 | O(n)（每个下标至多入栈出栈一次） | O(n) |

## 踩坑点 / 注意点

- ❌ **弹栈条件漏掉等号**。`books[p] - p == books[i] - i` 时 p 已经接不上 i，必须弹；写成 `>` 会把断开位置找错，段长多算一格。
- ❌ **忘记存量的下界截断**。递减到 0 以下不合法，`cnt` 必须和 `books[i]` 取 min；`books = [7,0,3,4,5]` 这种带 0 的用例就是专门查这个的。
- ❌ **答案取 `dp[n-1]`**。最优段可能在中间结束（例 3 就是前 4 层拿完 13 本最好），必须取全局 max。
- ⚠️ **溢出**。n 和 books[i] 都是 10⁵ 量级，单段和最大约 `10⁵ × 10⁵ = 10¹⁰`，`int` 放不下，求和与 dp 都要 `long long`。
