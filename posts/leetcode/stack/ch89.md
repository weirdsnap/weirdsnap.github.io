# 三元表达式解析器（439. Ternary Expression Parser）

## 题意

给定一个**保证合法**的三元表达式字符串，原子是单字符 `T` / `F` / 数字，形如 `cond?a:b` 可任意嵌套。求它的求值结果（单字符）。

```
输入: "T?2:3"
输出: "2"

输入: "F?1:T?4:5"
输出: "4"

输入: "T?T?F:5:3"
输出: "F"      （右结合：T?(T?F:5):3）
```

---

## 思路：从右往左扫 + 栈

三元表达式**右结合**，最内层的可归约单元永远在最右端。从右往左扫描：

- 普通字符（原子）→ 压栈；
- `:` → 跳过；
- `?` → 栈顶两个就是 then/else 分支的**已折叠结果**（各剩一个字符），`expression[i-1]` 是条件字符。弹出两个、按条件选一个压回，然后 `i--` 跳过条件字符。

扫完栈底（也是栈顶）剩唯一字符即答案。

**弹出顺序**：逆序扫描先遇到 else（靠右）、后遇到 then（靠左），所以先弹出的是 **then** 分支——`a = pop()` 是 then，`b = pop()` 是 else，选 `cond == 'T' ? a : b`。

## 解法：逆序扫描 + 折叠

```cpp
class Solution {
public:
    string parseTernary(string expression) {
        const int n = expression.size();
        vector<char> stack;
        stack.reserve(n);
        for (int i = n - 1; i >= 0; i--) {
            char c = expression[i];
            if (c == '?') {
                // 条件在 '?' 左侧紧邻字符；栈顶两个是 then/else 的折叠结果
                char cond = expression[i - 1];
                char a = stack.back(); stack.pop_back();  // then 分支
                char b = stack.back(); stack.pop_back();  // else 分支
                stack.push_back(cond == 'T' ? a : b);
                i--;  // 跳过条件字符，别让它入栈
            } else if (c != ':') {
                stack.push_back(c);
            }
        }
        return string(1, stack.back());
    }
};
```

---

## 核心理解

### 1. 为什么是从右往左，不是从左往右

左往右遇到 `cond?` 时，then/else 两个子表达式还没解析完（可能自身嵌套），不得不递归或显式维护多层挂起状态。逆序扫时，**任何 `?` 被遇到时它的两个分支早已折叠成单字符**躺在栈顶——嵌套结构被扫描方向自动拆解。这和"后缀表达式从左往右算"是对偶技巧：**结合方向决定扫描方向**，选对了方向，递归变成迭代。

### 2. `i--` 的双重角色

`?` 的条件不是栈里的值，而是**字符串里紧邻的左字符** `expression[i-1]`。取完它必须 `i--` 跳过，否则下一轮循环会把它当原子压栈。这类"一个下标被两处消费"的写法，漏掉补偿步是最常见的 bug。

### 3. 输入保证合法 = 省略全部错误检查

栈底恰好剩一个、弹栈必然非空、`?` 左边必有条件字符，这些都靠题面"expression is valid"兜底。竞赛题给合法性保证时大胆依赖；工程代码里这层保证不存在，每个 `pop` 前都要判空。

## 踩坑点 / 注意点

- ❌ **忘记 `i--`**。条件字符被当原子压栈，结果里混进 T/F。见核心理解 2。
- ❌ **弹出顺序写反**。先 pop 的是 then 分支（它靠左、后入栈），写成 `cond=='T' ? b : a` 就把两个分支选反了。
- ❌ **`:` 忘记跳过**。它既不是操作数也不是操作符，漏掉 `c != ':'` 判断会把冒号压进栈。
- ⚠️ **原子是单字符**这个前提别外推：若数字允许多位（如 `12`），字符级栈就不够用，要换 token 级解析。
