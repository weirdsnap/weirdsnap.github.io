# 寻找排列（484. Find Permutation）

## 题意

给定只含 `'I'`（递增）/ `'D'`（递减）的字符串 `s`，返回 `[1, 2, ..., s.size()+1]` 的一个排列，使相邻元素的大小关系与 `s` 逐位吻合。要求**字典序最小**的那个。

```
输入: s = "I"
输出: [1,2]

输入: s = "DI"
输出: [2,1,3]

输入: s = "DDI"
输出: [3,2,1,4]
```

约束：`1 <= s.length <= 10⁵`。

---

## 思路：递增打底，D 段翻转

从恒等排列 `[1, 2, ..., n]` 出发——它已经满足所有 `'I'`。一段连续 `k` 个 `'D'` 要求 `k+1` 个位置严格递减：把这 `k+1` 个位置上的数字（恰好是 `k+1` 个连续整数）**整段逆序**，递减成立，且段内数字没有和段外交换，字典序最小性不受损。`'I'` 边界两侧天然 `左边段内最大值 < 右边段内最小值`，衔接处自动递增。

实现上用 `'I'`（或末尾哨兵）触发翻转：累计连续 `'D'` 数 `cnt`，遇 `'I'` 时 `reverse` 区间 `[i-cnt, i]`（恰好 `cnt+1` 个数）。

## 解法：单趟扫描 + 段翻转

```cpp
class Solution {
public:
    vector<int> findPermutation(string s) {
        const int n = s.size() + 1;
        vector<int> perm(n, 1);
        int cnt = 0;

        for (int i = 0; i < n; i++) {
            char cur = s[i];

            if (i == n - 1) {
                cur = 'I';       // 哨兵：末端强制结算最后一段 D
            } else {
                perm[i + 1] = i + 2;   // 同步构建 [1..n]
            }

            if (cur == 'D') {
                cnt++;
            } else if (cnt > 0) {
                reverse(perm.begin() + i - cnt, perm.begin() + i + 1);
                cnt = 0;
            }
        }
        return perm;
    }
};
```

## 解法二：栈

同一个思路的另一种实现，也是这道题的"标准答案"长相。不再显式记录 D 段边界再 `reverse`，而是把数字依次压栈，遇 `'I'`（或末尾）把栈弹空：栈顶先出，连续 `'D'` 段压进去的数字正好逆序出来，效果和段翻转一模一样。

```cpp
class Solution {
public:
    vector<int> findPermutation(string s) {
        const int n = s.size() + 1;
        vector<int> perm;
        stack<int> st;

        for (int i = 0; i < n; i++) {
            st.push(i + 1);  // 依次压入下一个数字

            // 遇到 'I' 或到末尾：弹空栈，
            // 栈顶先出的特性正好把连续 'D' 段逆序
            if (i == n - 1 || s[i] == 'I') {
                while (!st.empty()) {
                    perm.push_back(st.top());
                    st.pop();
                }
            }
        }

        return perm;
    }
};
```

和段翻转版对照：段翻转版显式算区间 `[i-cnt, i]`，栈版让 LIFO 顺序替你做这件事；哨兵（`i == n - 1` 时强制结算）在两版里是同一件事。栈版不用关心区间下标，写起来更不容易错，代价是 O(n) 的栈空间。

---

## 核心理解

### 1. 为什么 D 段逆序就是字典序最小

字典序最小要求前缀尽量小。`'I'` 处左边的元素不能动（动了只能换入更大的）；一段 `'D'` 里，位置 `i-cnt` 必须大于其右侧所有位置，能放的最小值就是这段连续数字里的最大值。归纳下去，**整段逆序是每个位置都取到可行最小值的唯一方案**。贪心正确性靠"段间数字不交换"保持：每段翻转只在内部进行。

### 2. 哨兵结算尾部 D 段

循环在 `'I'` 处结算，但 `s` 可以以 `'D'` 结尾（`"DDI"`），尾部段没有 `'I'` 触发。把循环多跑一格、末端强制 `cur = 'I'`，尾部段就和平常段走同一条结算路径，不用单独特判。和 163 的边界哨兵是同一招：**收尾特判多的时候，造一个哨兵事件统一触发**。

### 3. `s[s.size()]` 的合法但脆弱

代码里 `char cur = s[i]` 在 `i == n-1` 时读的是 `s[s.size()]`——C++11 起 `basic_string` 保证该位置返回 `'\0'`，所以合法，且下一行立刻被哨兵覆盖，结果正确。但这个值被"读了又扔掉"，纯属多余；更干净的写法是先判 `i == n - 1` 再决定读不读（[ch67](./blog.html?post=leetcode/sliding-window/ch67.md) 核心理解 3 讨论过这个保证的脆弱性：换成自定义容器或 C 数组就越界了）。

## 复杂度

| | 时间 | 空间 |
|--|------|------|
| 单趟 + 段翻转 | O(n)（每元素至多被 reverse 一次） | O(1)（输出不计） |
| 栈 | O(n)（每元素入栈出栈各一次） | O(n)（栈） |

验证：官方 4 样例 + **穷举 {I,D} 全部长度 ≤ 6 的模式**（126 个）对拍全排列暴力 oracle（枚举 `[1..n]` 全部排列，滤出匹配者取字典序最小），两版实现都跑；再加 300 组长模式（≤500）做**性质校验**（是排列 + 逐位满足 s + 两版输出一致）。**72,257 条断言全过**。

---

## 踩坑点 / 注意点

- ❌ **翻转区间算错**。`k` 个连续 `'D'` 对应 `k+1` 个数字，区间是 `[i-cnt, i]` 闭区间，`reverse` 的迭代器要 `[i-cnt, i+1)` 半开——差一个就翻错。
- ❌ **忘记哨兵结算**。尾部 `'D'` 段没有 `'I'` 触发，漏掉 `[2,1]` 这种输出。
- ❌ **试图逐位贪心放数**。"每位放最小可行数"要做可用数维护，复杂度 O(n²) 起步；看出"翻转连续段"的结构才是 O(n)。
- ⚠️ **初始 `perm(n, 1)` 依赖逐位覆写**。`perm[0] = 1` 是初始值兜底、`perm[i+1] = i+2` 在循环里补齐，哨兵格不写入——初始化与覆写时机耦合较紧，改循环结构时容易踩到。
