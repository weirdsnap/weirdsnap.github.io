# 子树平均值等于节点值的计数（2265. Count Nodes Equal to Average of Subtree）

## 题意

给定二叉树根节点，统计有多少个节点满足：节点值等于其**子树**（含自身）所有值的平均（向下取整）。

```
输入: root = [4,8,5,0,1,null,6]
输出: 5
解释: 值为 4 的节点子树平均 24/6 = 4 ✓；值为 5 的子树平均 11/2 = 5 ✓；
      叶子 0、1、6 各自的平均就是自身 ✓

输入: root = [1]
输出: 1
```

约束：节点数 `[1, 1000]`，`0 <= Node.val <= 1000`。

---

## 思路：后序遍历聚合子树信息

判断一个节点需要它整棵子树的**和**与**节点数**，这两个值都必须先拿到左右子树的结果才能算，天然是后序遍历（左右根）。让每个递归调用返回 `{子树和, 子树节点数}`，当前节点把左右结果一拼，就地判断、就地计数。

## 解法：返回 pair 的后序 DFS

```cpp
class Solution {
public:
    int averageOfSubtree(TreeNode* root) {
        int result = 0;  // 用计数变量替代 vector，仅记录数量
        auto func = [&](this auto&& self, TreeNode* node) -> pair<int, int>{
            if (node == nullptr) {
                return {0, 0};
            }
            int target = node->val;
            auto [l_sum, l_cnt] = self(node->left);
            auto [r_sum, r_cnt] = self(node->right);

            if (target == (l_sum + r_sum + target) / (l_cnt + r_cnt + 1)) {
                ++result;  // 只计数，不存储节点
            }
            return {target + l_sum + r_sum, 1 + l_cnt + r_cnt};
        };
        func(root);
        return result;
    }
};
```

---

## 核心理解

### 1. 返回值设计：需要什么就聚合什么

子树判断需要"和"与"个数"两个量，返回值就是 `pair<int, int>` 两个槽。这是树形 DP 的通用形状：**递归返回值 = 父节点做决策所需的全部信息**。如果改问"子树最大值超过自身的节点"，返回值换成 `{最大值}`；问直径类问题则返回 `{高度}`，外加一个全局变量存答案（和这里的 `result` 一个角色）。

### 2. 整数除法恰好就是题意的"向下取整"

题面要求向下取整，C++ 整数除法是**向零取整**。两者只在负数时有分歧，而本题 `val >= 0`、和也非负，向零取整等于向下取整，`/` 直接用即可。如果节点值允许为负，这里就是个真坑（`-3 / 2 == -1` 而不是 `-2`），得换 `floor` 语义的写法。

### 3. 递归 lambda 的 C++23 写法

`[&](this auto&& self, ...)` 是 C++23 的 deducing this：lambda 把自身当第一个参数显式接收，递归调 `self(...)`，不用再玩 `std::function` 包一层或 `y_combinator` 那两种老花招（[Lambda 递归：三种写法](./blog.html?post=cpp/practices/lambda_01.md)里有完整对比）。配合作者的 `auto [l_sum, l_cnt]` 结构化绑定，整段 DFS 没有任何样板代码。

## 踩坑点 / 注意点

- ❌ **先序就动手**。当前节点的判断依赖左右子树的聚合结果，先序写出来一定错；认"左右根"的顺序。
- ❌ **用全局变量存子树和**。多个递归分支共享一个累加器会互相污染，聚合值必须走返回值通道，全局只放答案计数。
- ⚠️ **负数情形下 `/` 不是向下取整**。本题值域非负所以没事，但凡是"平均值向下取整"的题，先检查值域。
