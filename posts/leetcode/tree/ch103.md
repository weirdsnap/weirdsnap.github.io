# 二叉树层序遍历（102. Binary Tree Level Order Traversal）

## 题意

给定二叉树根节点，逐层返回节点值，每层一个数组，从左到右。

```
输入: root = [3,9,20,null,null,15,7]
输出: [[3],[9,20],[15,7]]

输入: root = []    输出: []
输入: root = [1]   输出: [[1]]
```

- 树中节点数 `[0, 2000]`
- `-1000 <= Node.val <= 1000`

## 思路

BFS 模板题，唯一的考点是**分层**：普通 BFS 只关心遍历顺序，这题还要求知道每一层的边界在哪。手法是每轮循环开始时先取 `q.size()` 快照——队列里此刻的元素恰好就是一整层（上一层处理时把它的孩子全推进来了），固定这个数，处理满 `s` 个再进入下一轮。

## 解法：队列 + 层大小快照

```cpp
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> result;
        if (root == nullptr)     // 提前返回，避免后续空指针访问
            return result;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int s = q.size();
            vector<int> layer;
            layer.reserve(s);    // 预分配当前层容量，避免多次扩容
            while (s-- > 0) {
                auto cur = q.front();
                q.pop();
                layer.push_back(cur->val);
                if (cur->left != nullptr) {
                    q.push(cur->left);
                }
                if (cur->right != nullptr) {
                    q.push(cur->right);
                }
            }
            result.push_back(std::move(layer)); // 移动语义，减少拷贝
        }
        return result;
    }
};
```

## 核心理解

### 1. 为什么必须快照 `q.size()`

这是分层 BFS 和裸 BFS 的唯一区别，也是唯一的易错点。处理当前层时会往队列里推下一层的节点，队列长度一直在变。如果写成 `while (!q.empty())` 一层内不固定处理个数，就会把下一层的节点提前混进当前层，层边界全乱。`int s = q.size()` 在循环开头拍快照，之后只处理 `s` 个，推进来的新节点自然留给下一轮。

这个"先快照层大小"的手法在所有分层 BFS 里通用：单词接龙（127）、腐烂的橘子（994）、按层打印之字形（103）都是同一个模子。

### 2. `reserve` 和 `move` 值不值得写

`layer.reserve(s)` 和 `result.push_back(std::move(layer))` 都是小优化：前者省掉 `layer` 增长过程中的多次扩容，后者把 `layer` 的移动进 `result` 而不是拷贝。节点数 2000 的规模下感知不到差异，但这两个习惯在大数据量场景是真金白银，写着不亏。

### 3. DFS 也能做层序

一个反直觉的替代写法：DFS 时带上深度参数，往 `result[depth]` 里塞值——先序的顺序天然保证同层内从左到右：

```cpp
void dfs(TreeNode* node, int depth, vector<vector<int>>& out) {
    if (!node) return;
    if ((int)out.size() == depth) out.emplace_back();  // 第一次到这一层，开新数组
    out[depth].push_back(node->val);
    dfs(node->left, depth + 1, out);
    dfs(node->right, depth + 1, out);
}
```

结果和 BFS 完全一致。一般还是写 BFS（层序的语义就是队列），但 DFS 版在"层序 + 需要路径/深度信息"的复合题里更灵活。

## 复杂度

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个节点入队出队各一次 |
| 空间 | O(n) | 队列最坏装一整层，满二叉树底层约 n/2 |

官方样例和空树、单节点边界通过，另和 DFS 带层号收集的参照实现对拍了几百棵随机树，结果一致。

## 踩坑点

### ❌ 层内循环写成 `while (!q.empty())`

直接把 BFS 模板搬过来、不固定层大小，是当前层和下一层混在一起的经典错法。症状是输出只有一两大层。记住分层 BFS 的第一行永远是 `int s = q.size();`。
