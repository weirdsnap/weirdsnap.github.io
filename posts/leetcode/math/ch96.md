# 区间内的逗号计数 II（3871. Count Commas in Range II）

## 题意

和 I（[ch95](./blog.html?post=leetcode/math/ch95.md)）完全一样：把 `[1, n]` 的每个整数按千分位格式写出来，统计逗号总数。唯一的变化是**约束从 `10⁵` 放到 `10¹⁵`**。

```
输入: n = 1002
输出: 3

输入: n = 998
输出: 0
```

约束：`1 <= n <= 10¹⁵`。I 里的 `max(0, n - 999)` 不再成立（7 位以上的数有 2 个及以上逗号），必须上通用公式。

---

## 解法一：位数分段公式（I 的通用版）

[ch95](./blog.html?post=leetcode/math/ch95.md) 的解法二原样搬过来就是本题答案：`d` 位数有 `9 × 10^(d-1)` 个，每个贡献 `(d-1)/3` 个逗号；末段不完整，单独算 `n - 10^(d-1) + 1` 个。约束放大后只需全程 `long long`。

```cpp
class Solution {
public:
    long long countCommas(long long n) {
        long long temp = n;
        long long d = 0;
        while (temp > 0) {
            temp = temp / 10;
            d++;
        }
        long long cnt = 0;
        long long p = 10; // 当前段起始值 10^(i-1)
        for (long long i = 2; i < d; i++) {
            temp = (i - 1) / 3;
            // 用整数 p 替代 pow(10, i-1)，避免浮点误差
            cnt += 9 * p * temp;    // 直接累乘，无需强转
            p *= 10; // 累乘得到下一段起点
        }
        long long rem = 0;
        if (d > 3) {
            temp = (d - 1) / 3;
            // p 此时恰好为 10^(d-1)，即 d 位段的起点
            rem = (n - p + 1) * temp;    // 直接计算，无需强转
        }
        return cnt + rem;
    }
};
```

## 解法二：按逗号"层级"累加（更简洁）

换一个计数视角。一个有 `c` 个逗号的数 `m`，意味着 `m >= 1000`、`m >= 10⁶`、…… 共 `c` 个阈值它都迈过了。所以：

```
逗号总数 = 对每一级阈值 x ∈ {10³, 10⁶, 10⁹, ...}，统计"迈过 x 的数有几个"
        = Σ (n - x + 1)
```

```cpp
class Solution {
public:
    long long countCommas(long long n) {
        long long ans = 0;
        for (long long x = 1000; x <= n; x *= 1000) {
            ans += n - x + 1;
        }
        return ans;
    }
};
```

四行结束。这是"按贡献计数"的典型换元：不按"每个数有几个逗号"逐个数，改按"每个逗号位被多少个数用到"分层累加。

---

## 核心理解

### 1. 两版公式的等价关系

位数分段版按"数"分组（每段内逗号数相同），层级版按"逗号"分组（每级阈值贡献一段后缀）。两者是同一个求和的两种拆法：`Σ_m commas(m) = Σ_x #{m : m >= x}`。前者是定义式，后者是交换求和次序后的形式。数位统计题里这个换序经常能省掉分段讨论。

### 2. 溢出边界

`n` 到 `10¹⁵`，答案约 `4 × 10¹⁵`（实测 `f(10¹⁵) = 3998998998999005`），`int` 早就装不下，`long long` 上限约 `9.2 × 10¹⁸` 够用。中间量里最大的是 `9 * p`（`p` 最大 `10¹⁴`），约 `9 × 10¹⁴`，也安全。约束再放大到 `10¹⁸` 就要小心 `9 * p * temp` 了。

### 3. I 和 II 的出题套路

同一模型两个约束：Q1 用 `10⁵` 把逗号数锁成 0/1，送分给看清约束的人；Q2 放到 `10¹⁵` 逼出通用公式。ch95 里写通用版看似杀鸡用牛刀，到这里就变成正解了。周赛同家族题连号出现时，先翻一下相邻题号的约束差。

## 复杂度

| | 时间 | 空间 |
|--|------|------|
| 解法一（位数分段） | O(log n) | O(1) |
| 解法二（层级累加） | O(log n) | O(1) |

验证：两版公式本地互拍，官方 2 样例 + 段位边界（999/1000、10⁶-1/10⁶、10⁹-1/10⁹、10¹⁵）+ 20 万个 `[1, 10¹⁵]` 随机数，全部一致。

---

## 踩坑点 / 注意点

- ❌ **从 I 直接复制 `int` 版**。`n` 和中间量全部要换 `long long`，漏一个就溢出。位数循环变量也要换（`d` 虽小，`p` 和 `n - p + 1` 才是大头，但统一换更省心）。
- ❌ **层级版阈值写成 `x *= 10`**。逗号是每**三位**一个，阈值步长是 1000 不是 10。
- ⚠️ **`x *= 1000` 自身的溢出**。`x` 最大到 `10¹⁵` 就退出循环，安全；若约束到 `10¹⁸`，最后一次 `x *= 1000` 到 `10¹⁹` 会溢出 `long long`——那时循环条件要改成 `x / 1000 <= n / 1000` 之类的防溢出写法。
