# 相似度为 K 的字符串（854. K-Similar Strings）

## 题意

如果字符串 `s1` 可以通过**交换两个字符的位置**若干次变成 `s2`，就称它们是 `k` 相似的（`k` 为交换次数）。给定两个字母异位词 `s1` 和 `s2`（字符多重集相同），返回最小的 `k`。

```
输入: s1 = "ab", s2 = "ba"
输出: 1

输入: s1 = "abc", s2 = "bca"
输出: 2
解释: "abc" -> "bac" -> "bca"，交换 2 次。
```

---

## 思路

### 关键观察

1. 把每个字符串看作**图中的一个状态**，一次交换看作**一条边**，问题转化为**无权图最短路径**——BFS 的标准应用场景。
2. 状态空间是所有排列（最坏 `n!` 级别），裸 BFS 会爆炸，必须**剪枝**。

### 剪枝策略（核心）

每层扩展时，只生成"有意义"的邻居：

1. **只修第一个不匹配位置 `i`**：找到最小的 `i` 使 `cur[i] != s2[i]`，只交换涉及 `i` 的位置。修更靠后的错位的交换可以推迟，不影响最短性。
2. **`j` 必须能修对 `i`**：`cur[j] == s2[i]`，交换后位置 `i` 直接正确。
3. **`j` 不能破坏已正确的位置**：`cur[j] != s2[j]`，否则交换会把一个对的位置变错，白白倒退。

三条剪枝都不损失最优性：任何最优交换序列都可以重排成"每次固定最左错位"的形式。

## 代码

### 解法一：剪枝 BFS

```cpp
class Solution {
public:
    int kSimilarity(string s1, string s2) {
        if (s1 == s2) return 0;
        
        queue<pair<string, int>> q;  // {当前字符串, 步数}
        unordered_set<string> vis;
        
        q.push({s1, 0});
        vis.insert(s1);
        
        while (!q.empty()) {
            auto [cur, step] = q.front(); q.pop();
            
            // 找到第一个不匹配的位置 i
            int i = 0;
            while (i < cur.size() && cur[i] == s2[i]) i++;
            
            // 遍历候选位置 j
            for (int j = i + 1; j < cur.size(); j++) {
                // 不是i需要换过来的 或 已经是正确的 跳过
                if (cur[j] != s2[i] || cur[j] == s2[j]) {
                    continue;
                }
                
                // 尝试交换 cur[i] 和 cur[j]
                swap(cur[i], cur[j]);
                
                // 如果等于 s2，返回 step + 1
                if (cur == s2) {
                    return step + 1;
                }
                // 如果没访问过，加入队列
                if (vis.count(cur) == 0) {
                    vis.insert(cur);
                    q.push({cur, step + 1});
                }
                
                // 记得回溯！
                swap(cur[i], cur[j]);
            }
        }
        
        return -1; // 不会执行到这里
    }
};
```

**注意**：`cur` 在循环内反复交换再换回（回溯），避免每次生成新字符串的拷贝开销；只有确认入队时才把副本推进队列。

### 解法二：A\* 搜索

BFS 对所有方向一视同仁。A\* 给每个状态加一个**启发函数** `h`（估计还剩几步），优先扩展 `f = g + h` 最小的状态，让搜索朝着目标方向走：

```cpp
class Solution {
public:
    int kSimilarity(string s1, string s2) {
        // 优先队列：按 f = g + h 排序，f 小的优先
        priority_queue<
            pair<int, string>,
            vector<pair<int, string>>,
            greater<pair<int, string>>
        > pq;
        // dist[state] = 到达该状态的最小实际步数 g
        unordered_map<string, int> dist; 

        // 初始化：起点入队，f = 0 + h(s1)
        dist[s1] = 0;
        pq.push({h(s1, s2), s1});

        // A* 主循环
        while (!pq.empty()) {
            auto top = pq.top();
            pq.pop();
            int f = top.first;   // f = g + h，用于排序
            string s = top.second;
            int g = dist[s];     // 实际已走步数
            
            // 找到目标，返回实际步数
            if (s == s2) return g;
            
            // 找第一个不匹配位置 i
            int i = 0;
            while (i < s.size() && s[i] == s2[i]) i++;
            
            // 枚举邻居：所有合法交换
            for (int j = i + 1; j < s.size(); j++) {
                // 跳过：不是需要的字符，或 j 位置已正确
                if (s[j] != s2[i] || s[j] == s2[j]) continue;
                
                // 生成新状态
                string next_s = s;
                swap(next_s[i], next_s[j]);
                
                int new_g = g + 1;
                // 未访问过，或发现更短路径
                if (!dist.count(next_s) || new_g < dist[next_s]) {
                    dist[next_s] = new_g;
                    int new_f = new_g + h(next_s, s2);
                    pq.push({new_f, next_s});
                }
            }
        }

        return -1; // 不会执行到这里
    }
    
    // 启发函数：不匹配位置数 / 2 上取整
    // 每次交换最多修复 2 个位置，所以这是下界估计
    int h(string& s, string& target) {
        int diff = 0;
        for (int i = 0; i < s.size(); i++)
            if (s[i] != target[i]) diff++;
        return (diff + 1) / 2;
    }
};
```

**注意**：邻居生成沿用解法一的三条剪枝。`dist` 记录每个状态的最优 `g`，同一状态可能多次入队（旧条目是"过期"的），但 `h` 满足一致性时，第一次弹出 `s2` 就是答案，过期条目不影响正确性。

### 解法三：IDA\*（迭代加深）

A\* 用优先队列存所有待扩展状态，内存随状态数膨胀。IDA\* 把 A\* 的 `f = g + h` 剪枝和 DFS 的迭代加深结合：**设一个界限 `bound`，DFS 中 `f > bound` 就剪枝回溯；一轮没找到就把 `bound` 增大为"超出界限的最小 f"，再搜一轮**。内存只占递归栈， O(深度)。

```cpp
class Solution {
public:
    string target;
    int n;
    const int INF = 1e9;
    
    int kSimilarity(string s1, string s2) {
        target = s2;
        n = s1.size();
        
        // 迭代加深主循环
        int bound = h(s1);  // 初始界限 = 启发估计
        
        while (true) {
            int t = dfs(s1, 0, bound, 0);
            if (t == -1) return bound;  // 找到解
            if (t == INF) return -1;    // 无解（本题不会发生）
            bound = t;                   // 增大界限，继续搜索
        }
    }
    
    // 返回：-1 表示找到解，其他值表示下一轮的最小 bound
    int dfs(string& s, int g, int bound, int pos) {
        int f = g + h(s);
        
        // 剪枝：超出当前界限
        if (f > bound) return f;
        
        // 找到目标
        if (s == target) return -1;
        
        int minNext = INF;
        
        // 找第一个不匹配位置
        int i = pos;
        while (i < n && s[i] == target[i]) i++;
        
        // 枚举交换
        for (int j = i + 1; j < n; j++) {
            if (s[j] != target[i] || s[j] == target[j]) continue;
            
            // 双向匹配优化：一次搞定两个位置
            if (s[i] == target[j]) {
                swap(s[i], s[j]);
                int t = dfs(s, g + 1, bound, i + 1);
                swap(s[i], s[j]);
                
                if (t == -1) return -1;  // 找到解，直接返回
                minNext = min(minNext, t);
                break;  // 最优交换已尝试，跳过其他
            }
        }
        
        // 再试单向匹配（如果没有双向匹配）
        if (minNext == INF) {
            for (int j = i + 1; j < n; j++) {
                if (s[j] != target[i] || s[j] == target[j]) continue;
                
                swap(s[i], s[j]);
                int t = dfs(s, g + 1, bound, i + 1);
                swap(s[i], s[j]);
                
                if (t == -1) return -1;
                minNext = min(minNext, t);
            }
        }
        
        return minNext;
    }
    
    // 启发函数：同 A*
    int h(string& s) {
        int diff = 0;
        for (int i = 0; i < n; i++)
            if (s[i] != target[i]) diff++;
        return (diff + 1) / 2;
    }
};
```

**注意**：`dfs` 的返回值语义——`-1` 找到解，`INF` 本轮毫无进展，其他值是下一轮该用的 `bound`。双向匹配（`s[i] == target[j]`，一换修两个位置）优先尝试且 `break`：这种交换一步让 `h` 恰好减 1、`f` 不变，总是在最优路径的候选上，先试它不会漏解。

## 关键细节

### 1. 为什么 BFS 而不是 DFS

求**最少**交换次数，等价于无权图最短路。BFS 按层扩展，第一次到达 `s2` 的步数就是答案；DFS 找到的不保证最短，还得遍历全部状态取最小。

### 2. 为什么"只修第一个错位"不丢最优解

设最优交换序列第一次交换涉及位置 `p < i`（`i` 是最左错位）——但 `p < i` 的位置都已匹配，交换它必然引入新错位，之后还得修回来，步数只多不少。因此存在一种最优解，每一步都只修最左错位。

### 3. `vis` 的标记时机

**入队时**就标记（`vis.insert` 紧跟 `q.push`），而不是出队时。否则同一状态可能被多个父状态重复入队，队列指数膨胀。

### 4. A\* 的启发函数为什么合法

`h(s) = ⌈不匹配位置数 / 2⌉`：一次交换最多修复 2 个位置，所以剩余步数**不会少于** `h`。这满足两个性质：

- **可采纳性**（admissible）：`h` 永远不高估真实剩余代价，保证 A\* 找到的是最优解
- **一致性**（consistent）：相邻状态间 `h` 的差不超过 1（一次交换最多让不匹配数减 2，`h` 最多减 1），保证每个状态第一次弹出时 `g` 已是最优，`dist` 的松弛只是防御性写法

`h` 越接近真实剩余步数，剪掉的无效扩展越多；`h ≡ 0` 时 A\* 退化为 Dijkstra（本题即 BFS）。

### 5. IDA\*：用时间换空间

BFS 和 A\* 都要把待扩展状态存进队列，内存随状态数 O(S · n) 膨胀。IDA\* 不存任何队列，只靠递归栈：

- **界限递增**：每轮 DFS 只允许 `f = g + h ≤ bound`，超界就返回当前的 `f` 作为下轮候选
- **`bound` 取"超界最小 f"**：保证界限每次恰好抬到下一个可能出现解的层级，解深度不减，最优性不受影响
- **代价是重复搜索**：每轮从头再搜，浅层状态被反复访问。但 `h` 足够精确时，`bound` 初始值就很接近答案，轮数很少

BFS 的"层"靠队列实现，IDA\* 的"层"靠 `bound` 实现——同一层序思想，两种空间取舍。

## 复杂度

| | 剪枝 BFS | A\* | IDA\* |
|--|----------|-----|-------|
| 时间 | O(S · n²) | O(S' · n² log S') | O(轮数 × 每轮扩展数)，浅层重复搜索 |
| 空间 | O(S · n)（队列） | O(S · n)（优先队列 + dist） | **O(k · n)**（仅递归栈，k 为答案） |
| 特点 | 实现最简单 | 启发式引导扩展方向 | 内存最小，可搜深解 |
| 推荐度 | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐（状态爆炸时的思路） |

S 为实际访问的状态数（剪枝后远小于 n!）；`n ≤ 20` 且字符仅 6 种，三种写法都能通过。本题规模下 BFS 已够用，A\*/IDA\* 的价值在于展示"启发函数引导搜索"和"迭代加深省内存"的通用思路——状态空间更大（如 773 滑动谜题的困难版本）时才是它们的主场。

## 踩坑点 / 注意点

- ❌ **交换后忘记换回**。`cur` 是复用的，漏掉第二次 `swap` 会让后续所有 `j` 在错误的状态上扩展。
- ❌ **出队时才标记 `vis`**。必须入队即标记，否则状态重复入队。
- ❌ **不剪枝直接全交换**。任意两位置交换的邻居数是 O(n²)，状态数 n!，必超时。
- ❌ **用 DFS/BFS 不分**。求最少步数必须 BFS；DFS 第一次到达不代表最短。
- ❌ **启发函数高估**。`h` 若高估真实剩余代价（比如直接用不匹配数不除 2），A\*/IDA\* 不再保证最优。
- ❌ **IDA\* 的 `bound` 更新成固定 +1**。必须取"超界状态的最小 f"，否则可能跳过含解的层级，或在同一层级上空转。
- ✅ 提前特判 `s1 == s2` 返回 0。
