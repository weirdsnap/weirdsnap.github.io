# 至多包含两个不同字符的最长子串（159. Longest Substring with At Most Two Distinct Characters）

## 题意

给定字符串 `s`，返回**至多包含两个不同字符**的最长子串长度。

```
输入: s = "eceba"
输出: 3
解释: "ece"，含 e、c 两个不同字符。

输入: s = "ccaabbb"
输出: 5
解释: "aabbb"。
```

约束：`0 <= s.length <= 10⁴`，`s` 由英文字母组成。

---

## 思路：滑动窗口，右扩左缩

维护窗口 `[i, j]`，右端 `j` 扩张并计数，当窗口里出现**第三种**字符时，从左端收缩直到某个字符计数归零。每个位置最多进出窗口一次，均摊 O(n)。

## 解法一：计数 map + 手动 init（提交版）

```cpp
class Solution {
public:
    int lengthOfLongestSubstringTwoDistinct(string s) {
        if (s.size() <= 2) {
            return s.size();
        }

        int i = 0;
        int j = 1;
        int result = 2;

        unordered_map<char, int> cnt;
        cnt[s[i]]++;
        while (j < s.size() && s[j] == s[i]) {   // 跳过开头的连续同字符
            cnt[s[j]]++;
            j++;
        }
        if (j < s.size()) {
            cnt[s[j]]++;                          // 第二个不同字符入窗
            result = max(result, j - i + 1);
        } else {
            return s.size();                      // 全同字符，提前返回
        }

        while (j < s.size()) {
            ++j;
            cnt[s[j]]++;
            if (cnt[s[j]] == 1) {          // 第三种字符进入窗口
                while (true) {
                    cnt[s[i]]--;           // 每次只减一个
                    if (cnt[s[i]] == 0) {  // 减到 0，这个字符移出了
                        i++;
                        break;
                    }
                    i++;
                }
            }
            result = max(result, j - i + 1);
        }
        return result;
    }
};
```

## 解法二：标准滑动窗口模板

init 阶段其实是多余的——从空窗口开始自然生长，模板几行就覆盖所有边界：

```cpp
class Solution {
public:
    int lengthOfLongestSubstringTwoDistinct(string s) {
        unordered_map<char, int> cnt;
        int i = 0, result = 0;
        for (int j = 0; j < s.size(); j++) {
            cnt[s[j]]++;
            while (cnt.size() > 2) {        // 种类数超标才收缩
                if (--cnt[s[i]] == 0) cnt.erase(s[i]);
                i++;
            }
            result = max(result, j - i + 1);
        }
        return result;
    }
};
```

---

## 核心理解

### 1. 收缩条件的两种等价写法

- 解法一：`cnt[s[j]] == 1` 说明 `s[j]` 是**新**字符（此前窗口里两种字符已满，新字符即第三种），触发收缩
- 解法二：直接看 `cnt.size() > 2`（种类数超标）

前者省了 `erase`（计数减到 0 不删键，`size()` 失真，所以不能混用），后者靠 `erase` 让 `size()` 保持语义。**选了哪种计数方式，就要配对应的判据**。

### 2. "至多 K 种"滑窗家族

同一个骨架，换个收缩条件就是一个题：

| 题 | 窗口约束 | 收缩条件 | 文章 |
|----|----------|----------|------|
| 159 | 种类数 ≤ 2 | `cnt.size() > 2` | 本篇 |
| 3090 | 每字符频次 ≤ 2 | `cnt[c] > 2` | [ch51](./blog.html?post=leetcode/sliding-window/ch51.md) |
| 2958 | 每元素频次 ≤ K | `cnt[x] > k` | [ch53](./blog.html?post=leetcode/sliding-window/ch53.md) |

### 3. 解法一藏着一个越界读（实测无害，但属脆弱写法）

解法一的 `while` 循环里先 `++j` 再 `cnt[s[j]]`：当 `j` 步进到 `s.size()` 时，读的是 `s[s.size()]`。C++11 起标准保证这个访问合法、返回 `'\0'`（见 [ch08](./blog.html?post=leetcode/string/ch08.md)），于是 map 里被塞进一个 `'\0'` 键，触发一次多余的收缩。

之所以**碰巧不出错**：这次多余收缩只会把 `i` 往大推，而 `result` 取的是 `max`，窗口只会变窄不会虚增；且此后循环立即结束，污染不会扩散。穷举 {a,b,c} 上全部 265,720 个长度 ≤ 11 的串 + 随机长串对拍，与模板版结果完全一致。

但依赖"多收缩一次恰好无害"太脆——改动任何一处（比如换成先更新 result 再收缩）就可能出错。模板版用 `for` 管理 `j`，结构上就不存在这个口子。

## 复杂度

| | 解法一 | 解法二（模板） |
|--|--------|----------------|
| 时间 | O(n) 均摊 | O(n) 均摊 |
| 空间 | O(种类数) ≤ O(3) | 同左 |

验证：穷举 {a,b,c} 全部长度 ≤ 11 的串（265,720 个）+ 300 组字母表 26 的随机长串 + 单字符/全同字符边界，两版逐一对拍。266,075 条断言全过。

---

## 踩坑点 / 注意点

- ❌ **`++j` 后未判界直接 `s[j]`**。见核心理解 3：本题碰巧无害，但写法本身越界（靠 C++11 的 `'\0'` 保证兜底），模板版从结构上避免。
- ❌ **混用两种收缩判据**。用 `cnt.size()` 就必须在计数归零时 `erase`，否则 `size()` 虚高、窗口永远卡在收缩状态；用"新字符"判据则不需要 `erase`。
- ❌ **init 阶段漏掉全同字符的提前返回**。手写 init 时 `while` 会把 `j` 一路推到末尾，此时直接返回 `s.size()` 才是对的；模板版无此问题。
- ❌ **`s.size() <= 2` 的短路**。长度 0/1/2 时答案就是自身长度，不进主逻辑。
