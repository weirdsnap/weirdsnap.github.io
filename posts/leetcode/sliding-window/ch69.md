# 至多包含 K 个不同字符的最长子串（340. Longest Substring with At Most K Distinct Characters）

## 题意

给定字符串 `s` 和整数 `k`，返回**至多包含 `k` 个不同字符**的最长子串长度。

```
输入: s = "eceba", k = 2
输出: 3
解释: "ece"，含 e、c 两个不同字符。

输入: s = "aa", k = 1
输出: 2
```

约束：`1 <= s.length <= 10⁴`，`0 <= k <= 50`。

---

## 思路：滑动窗口模板（159 的直接泛化）

右端 `j` 扩张并计数，种类数超过 `k` 就从左端收缩，直到某个字符计数归零、从 map 里删掉。每个位置最多进出窗口一次，均摊 O(n)。

```cpp
class Solution {
public:
    int lengthOfLongestSubstringKDistinct(string s, int k) {
        const int n = s.size();
        int i = 0;
        int j = 0;
        int result = 0;
        unordered_map<char, int> cnt;  // 哈希表均摊 O(1)，替代 map 的 O(log n)
        while (j < n) {
            cnt[s[j]]++;                    // 新字符进窗
            while (cnt.size() > k) {        // 种类数超标才收缩
                cnt[s[i]]--;
                if (cnt[s[i]] == 0) {
                    cnt.erase(s[i]);        // 归零删键，size() 才保真
                }
                i++;
            }
            result = max(result, j - i + 1);
            j++;
        }
        return result;
    }
};
```

这就是 159（[ch67](./blog.html?post=leetcode/sliding-window/ch67.md)）解法二的 K 泛化——当时手写 init 阶段和 `++j` 越界读的两个坑，这个模板结构天然都没有。

---

## 核心理解

### 1. 家族关系：159 是 k=2 的特例

| 题 | 窗口约束 | 收缩条件 | 文章 |
|----|----------|----------|------|
| 159 | 种类数 ≤ 2 | `cnt.size() > 2` | [ch67](./blog.html?post=leetcode/sliding-window/ch67.md) |
| **340** | **种类数 ≤ k** | `cnt.size() > k` | 本篇 |
| 3090 | 每字符频次 ≤ 2 | `cnt[c] > 2` | [ch51](./blog.html?post=leetcode/sliding-window/ch51.md) |
| 2958 | 每元素频次 ≤ K | `cnt[x] > k` | [ch53](./blog.html?post=leetcode/sliding-window/ch53.md) |

同一个"右扩左缩"骨架，只是约束从固定 2 泛化成参数 k。做过 340 之后 159 就没有单独写的必要了——`k = 2` 调用即可。

### 2. `cnt.size()` 判据必须配 `erase`

计数减到 0 不删键的话，`size()` 虚高，窗口会卡在收缩状态出不来。这和 ch67 里"新字符进入"判据（不删键也能用）是两条不能混用的路线，本篇选了 `size()` 路线就必须 `erase`。

### 3. `k = 0` 不用特判

任何字符进窗都让 `cnt.size() > 0` 成立，窗口立刻收缩回空，`j - i + 1 = 0`，`result` 保持 0——边界被模板自然覆盖。空串同理，循环都不进。

---

## 复杂度

| 指标 | 值 |
|------|----|
| 时间 | O(n) 均摊（每个位置进出窗口各一次） |
| 空间 | O(min(k, 字母表)) |

验证：穷举 {a,b,c} 上全部长度 ≤ 11 的串 × k∈[0,4] + 200 组字母表 26 的随机长串（含 k=0 与 k>种类数），与 O(n²) 暴力逐一对拍。1,328,805 条断言全过。

---

## 踩坑点 / 注意点

- ❌ **收缩时忘记 `erase` 归零键**。`cnt.size()` 失真，窗口再也扩不出去，答案恒为 1 左右的小值。
- ❌ **特判 `k = 0` 反而写错**。模板本身就覆盖，画蛇添足的特判容易引入新 bug。
- ❌ **`unordered_map` 换成 `map` 来"保序"**。本题不需要顺序，`map` 单次操作 O(log σ) 还更慢；需要顺序的场景（如 3517 [ch33](./blog.html?post=leetcode/string/ch33.md)）才轮到它。
