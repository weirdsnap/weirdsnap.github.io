# 最大连续 1 的个数 II（487. Max Consecutive Ones II）

## 题意

二进制数组 `nums`，允许**最多翻转一个 0 为 1**，求最长连续 1 的长度。

```
输入: nums = [1,0,1,1,0]
输出: 4
解释: 翻转第一个 0 → [1,1,1,1,0]，最长 4；翻转第二个 0 也一样。

输入: nums = [1,0,1,1,0,1]
输出: 4
```

约束：`1 <= nums.length <= 10⁴`，`nums[i] ∈ {0, 1}`。

---

## 思路一：滑动窗口模板

"允许翻转一个 0"翻译成窗口语言就是**窗口内 0 的个数 ≤ 1**——最长型，直接套[模板](./blog.html?post=leetcode/sliding-window/template.md)：

```cpp
class Solution {
public:
    int findMaxConsecutiveOnes(vector<int>& nums) {
        int i = 0, zeros = 0, result = 0;
        for (int j = 0; j < nums.size(); j++) {
            if (nums[j] == 0) zeros++;
            while (zeros > 1) {            // 收缩判据：0 超标
                if (nums[i] == 0) zeros--;
                i++;
            }
            result = max(result, j - i + 1);
        }
        return result;
    }
};
```

## 思路二：段追踪，O(1) 空间（提交版）

只记两个数：`last`（上一段连续 1 长度）、`cur`（当前段）。遇到 0 时，**翻转上一个 0** 能把 `last` 和 `cur` 接起来：

```cpp
class Solution {
public:
    int findMaxConsecutiveOnes(vector<int>& nums) {
        int last = 0, cur = 0, result = 0;
        for (int i = 0; i < nums.size(); i++) {
            if (nums[i] == 1) {
                cur++;
            } else {
                // 翻转上一个 0：last + 1 + cur
                result = max(result, last + cur + 1);
                last = cur;
                cur = 0;
            }
        }
        result = max(result, last + cur + 1);   // 尾段没有下一个 0 触发，补上
        return min((int)nums.size(), result);   // 全 1 时 +1 是虚的，钳住
    }
};
```

---

## 核心理解

### 1. `last + cur + 1` 翻转的是"上一个 0"

遇到第 `t` 个 0 时，`cur` 是它**左边**的 1 段，`last` 是再左边的 1 段。能让两段接起来的翻转对象是它们**中间那个 0**——也就是上一个 0，不是当前这个。所以更新时机天然滞后一个 0，结尾必须补一次更新（尾段右边没有 0 来触发）。

### 2. `min(n, result)` 不是防御，是真会错

全 1 数组没有任何 0 可翻，`last + cur + 1 = n + 1` 里的 `+1` 是虚的。不钳住就会返回 `n + 1`——`nums = [1]` 返回 2 这种低级错误，穷举对拍第一个抓的就是它。

### 3. 两版的关系：段追踪是滑窗的"约束特化"

滑窗维护"0 的个数 ≤ 1"，段追踪利用约束的特殊性（0 就是段分界线）把窗口状态压缩成两个整数。约束越特殊，能省的空间越多——但滑窗版换个约束（比如允许翻 k 个 0，即 1004 题）只需改判据里的 `1` 为 `k`，段追踪版就得推广成记 k 段，立刻不划算。

---

## 复杂度

| | 滑窗版 | 段追踪版 |
|--|--------|----------|
| 时间 | O(n) 均摊 | O(n) |
| 空间 | O(1)（zeros 计数） | O(1) |
| 泛化到翻 k 个 | 改一个数 | 要记 k 段，不推荐 |

验证：穷举全部长度 ≤ 12 的二进制数组（8,190 个）+ 全 0/全 1/单元素边界 + 300 组随机长数组，两版逐一对拍。8,496 条断言全过。

---

## 踩坑点 / 注意点

- ❌ **忘记 `min(n, ...)` 钳位**。全 1 输入返回 n+1，见核心理解 2。
- ❌ **循环外漏掉尾段更新**。`last + cur + 1` 的候选只在遇到 0 时产生，数组以 1 结尾时最后一次候选要靠循环外那一次。
- ❌ **`last = cur; cur = 0;` 顺序写反**。先清 `cur` 再赋给 `last`，上一段信息直接丢失。
