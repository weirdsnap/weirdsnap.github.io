# 找出临界点之间的最小和最大距离（2058. Find the Minimum and Maximum Number of Nodes Between Critical Points）

## 题意

链表中**临界点**指严格大于两侧邻居（局部极大）或严格小于两侧邻居（局部极小）的节点（首尾节点没有两个邻居，不可能是临界点）。返回 `[相邻临界点的最小距离, 首末临界点的距离]`；临界点不足两个时返回 `[-1, -1]`。

```
输入: head = [3,1]
输出: [-1,-1]

输入: head = [5,3,1,2,5,1,2]
输出: [1,3]
解释: 临界点是下标 2(1，极小)、4(5，极大)、5(1，极小)；
      min = min(4-2, 5-4) = 1，max = 5 - 2 = 3。
```

约束：节点数 `2 <= n <= 10⁵`，`1 <= Node.val <= 10⁵`。

---

## 思路：一趟遍历，三指针同步右移

`last / cur / next` 三个指针同步前进，`cur` 是当前考察的节点。遇到临界点就更新三个量：第一个临界点下标 `first`（只记一次）、上一个临界点下标 `last_node`、相邻最小距离 `min_distance`。

```cpp
class Solution {
public:
    vector<int> nodesBetweenCriticalPoints(ListNode* head) {
        ListNode* last = head;
        ListNode* cur = head->next;
        ListNode* next = cur->next;
        int first_node = -1;   // 第一个临界点下标
        int last_node = -1;    // 上一个临界点下标
        int index = 1;
        int min_distance = -1;
        while (next != nullptr) {
            bool is_node =
                (last->val < cur->val && next->val < cur->val) ||
                (last->val > cur->val && next->val > cur->val);
            if (is_node) {
                if (first_node == -1) {
                    first_node = index;
                } else {
                    int distance = index - last_node;
                    min_distance = min_distance == -1
                                       ? distance
                                       : min(min_distance, distance);
                }
                last_node = index;
            }
            index++;
            last = cur;
            cur = next;
            next = next->next;
        }
        // 最大距离 = 末临界点 - 首临界点；只有一个临界点时 first == last
        int max_distance = (first_node != -1 && first_node != last_node)
                               ? last_node - first_node
                               : -1;
        return {min_distance, max_distance};
    }
};
```

---

## 核心理解

### 1. min 只需记"上一个"临界点，不需要存全部

临界点的下标天然递增被发现，**最小距离一定出现在相邻临界点之间**——跨临界点的距离只会更长。所以维护 `last_node` 滚动计算即可，不用开数组存所有临界点。

### 2. max 不用在循环里维护

首末临界点的距离就是最大值（下标序列的极差），循环结束后 `last_node - first_node` 一句话算出。哨兵处理合并成一个判断：`first_node == last_node` 时说明只见过一个临界点（或零个，此时 `first_node == -1`），返回 -1。

### 3. "严格"不等是考点

等值平台（如 `[2,2,2]`）两侧不满足严格大于/小于，整段都不是临界点。样例 3 `[1,3,2,2,3,2,2,2,7]` 的临界点是下标 1(3) 和下标 4(3)，输出 `[3,3]`——数错的人多半是把平台边缘算进去了。

## 踩坑点 / 注意点

- ❌ **三指针移动顺序写错**。必须 `last = cur; cur = next; next = next->next;` 依次接力；先动 `next` 会把 `cur` 更新丢掉。
- ❌ **首尾节点被当成临界点**。它们没有两个邻居，`while (next != nullptr)` 的循环条件天然把末位排除，首节点则从 `index = 1` 起步避开——改成从 0 起步就会错。
- ❌ **哨兵 `-1` 参与 `min` 运算**。`min_distance` 第一次赋值要走 `min_distance == -1 ? distance : min(...)` 的分支，直接 `min(-1, distance)` 永远是 -1。
