# 查找缺失元素（3731. Find Missing Elements）

## 题意

数组 `nums` 元素**互不相同**，原本包含某个连续范围内的**所有**整数，但有一些丢失了。范围的**最小值和最大值仍然在数组中**。返回范围内所有缺失的整数，按升序排列；没有缺失就返回空数组。

```
输入: nums = [1,4,2,5]
输出: [3]
解释: 范围是 [1,5]，完整应为 [1,2,3,4,5]，只有 3 缺失。

输入: nums = [7,8,6,9]
输出: []
解释: 范围 [6,9] 内元素齐全。

输入: nums = [5,1]
输出: [2,3,4]
```

约束：`2 <= nums.length <= 100`，`1 <= nums[i] <= 100`。

---

## 思路

三步走：找出 `min` 和 `max` → 把数组装进集合 → 扫描 `[min, max)` 区间，不在集合里的就是缺失元素。按从小到大扫描，结果天然有序，不需要再排序。

---

## 解法一：哈希集合

```cpp
class Solution {
public:
    vector<int> findMissingElements(vector<int>& nums) {
        unordered_set<int> my_set;
        int min_num = INT_MAX;
        int max_num = INT_MIN;
        for (const auto& num: nums) {
            my_set.insert(num);
            max_num = max(max_num, num);
            min_num = min(min_num, num);
        }
        vector<int> result;
        for (int i = min_num; i < max_num; i++) {
            if (my_set.find(i) == my_set.end()) {
                result.push_back(i);
            }
        }
        return result;
    }
};
```

**注意**：扫描从 `min_num` 开始而不是 `min_num + 1` 也正确——`min_num` 一定在集合里（题意保证最小值仍在数组中），不会被误加进结果。

## 解法二：定长数组替代哈希表

约束 `1 <= nums[i] <= 100`，值域固定且很小，可以用 `bool` 数组替代 `unordered_set`，查询从哈希（常数但有开销）变成直接索引：

```cpp
class Solution {
public:
    vector<int> findMissingElements(vector<int>& nums) {
        bool present[101] = {false};
        int min_num = INT_MAX;
        int max_num = INT_MIN;
        for (const auto& num: nums) {
            present[num] = true;
            max_num = max(max_num, num);
            min_num = min(min_num, num);
        }
        vector<int> result;
        for (int i = min_num; i < max_num; i++) {
            if (!present[i]) {
                result.push_back(i);
            }
        }
        return result;
    }
};
```

**注意**：这和老生常谈的"26 字母频率数组替代 map"是同一个思路——**值域已知且小时，数组索引永远比哈希快**。这里值域是 1~100，开 101 个槽位即可。

---

## 关键细节

### 1. 为什么不需要排序

结果要求升序。扫描区间 `[min, max)` 本身就是从小到大进行的，缺失元素按发现顺序自然有序。

### 2. 为什么区间端点不可能"缺失"

题意保证最小值和最大值仍在数组中，所以扫描区间开闭无所谓（`[min, max)` 或 `[min+1, max-1]` 结果一样）。如果题目没有这个保证，就要先想清楚端点算不算。

### 3. `INT_MAX` / `INT_MIN` 哨兵初始化

求最小值用 `INT_MAX` 起手、求最大值用 `INT_MIN` 起手，第一个元素必然刷新它们。`nums` 至少 2 个元素，不存在哨兵残留的情况。

---

## 复杂度

| | 解法一（哈希表） | 解法二（数组） |
|--|------------------|----------------|
| 时间 | O(n + range) | O(n + range) |
| 空间 | O(n) | O(101) = O(1) |

`range = max - min ≤ 99`，两版都是常数级别的额外扫描。

---

## 踩坑点 / 注意点

- ❌ **对结果再排一次序**。扫描顺序天然升序，`sort` 是多余动作。
- ❌ **用 `sort(nums)` 后找相邻差 > 1 的gap**。也能做，但把 O(n) 问题做成了 O(n log n)，还要处理边界，属于舍近求远。
