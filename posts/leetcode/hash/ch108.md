# 和为 K 的子数组（560. Subarray Sum Equals K）

## 题意

整数数组 `nums`（**可以有负数和 0**），整数 `k`。统计和为 `k` 的连续子数组的个数。

```
输入: nums = [1,1,1], k = 2   输出: 2
输入: nums = [1,2,3], k = 3   输出: 2   （[1,2] 和 [3]）
```

- `1 <= nums.length <= 2 * 10^4`，`-1000 <= nums[i] <= 1000`，`-1e7 <= k <= 1e7`

## 思路

枚举所有子数组是 O(n²)。子数组和可以写成前缀和之差：`sum(l..r) = pre[r] - pre[l-1]`。固定右端点 `r`，问题就变成：前面有多少个位置的前缀和恰好等于 `pre[r] - k`？

这是个"边扫边查历史"的形状，哈希表记"前缀和 → 出现次数"，每到一个位置先查表累加答案，再把自己的前缀和登记进去。

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        // 记录每个前缀和出现的次数（无需存储索引列表）
        unordered_map<int, int> m;
        int sum = 0;
        m[0] = 1; // 前缀和为 0 出现一次，表示空子数组
        int result = 0;
        for (int i = 0; i < nums.size(); i++) {
            int num = nums[i];
            sum += num;
            // 若 sum - k 已出现，则存在若干子数组和为 k
            if (m.find(sum - k) != m.end()) {
                result += m[sum - k];
            }
            m[sum]++;
        }
        return result;
    }
};
```

## 关键点

- `m` 记的是**次数**，不是下标。有了负数和 0，前缀和不再单调，同一个值可以出现多次，出现几次就贡献几个合法左端点，全部要累加进答案。
- `m[0] = 1` 这个哨兵对应"从下标 0 开始、和就是 k"的子数组，即 `pre[r] == k` 时 `sum - k == 0` 能查到一个"空前缀"。
- 顺序是**先查后记**：先 `result += m[sum - k]`，再 `m[sum]++`。反过来的话，`k == 0` 时会把刚写进去的自己查出来，凭空数出长度为零的空子数组。

## 和 1477 对照着看

[1477](./blog.html?post=leetcode/dp/linear/ch107.md) 用的是同一套前缀和 + 哈希，两处差别都来自值域：

- 1477 的数组全是正数，前缀和严格递增，每个值只出现一次，所以记"下标"就够，"只在首次出现时记录"的防御写法实际不会触发；这题值域放开，必须记次数。
- 滑动窗口在这题**失效**：有负数，右移左端点后窗口和不再单调变化，"和超了就缩左边"的贪心依据没了。1477 那种正数数组才能滑窗。

## 复杂度

- 时间：O(n)，一次扫描，哈希操作均摊 O(1)
- 空间：O(n)，前缀和最坏每个值都不同
