> **标签**：哈希表、矩阵、多指针
# 所有行中的最小公共元素（1198. Smallest Common Element in All Rows）

## 题意

`m × n` 矩阵，每行严格递增，元素值限制在 `1 ~ 10000`。找出在所有行里都出现的最小值，不存在返回 `-1`。

```
输入: mat = [[1,2,3,4,5],
             [2,4,5,8,10],
             [3,5,7,9,11],
             [1,3,5,7,9]]
输出: 5

输入: mat = [[1,2,3],
             [4,5,6]]
输出: -1
```

约束：`1 <= m, n <= 500`，`1 <= mat[i][j] <= 10000`，每行严格递增。

---

## 思路

两条不同的路子：

- 解法一：不看行序，把每个值出现在几行里数出来，出现在 `m` 行的值再取最小。
- 解法二：利用每行有序，每行摆一个指针往前推，每轮先取各指针所指元素的最大值。

## 解法一：统计每个值的出现行数

```cpp
class Solution {
public:
    int smallestCommonElement(vector<vector<int>>& mat) {
        int m = mat.size();
        // 数组替代map：下标即元素值，因本题有范围限制，map的方案更通用
        int cnt[10001] = {0};
        // 统计后从 1 到 10000 找第一个 count == 行数的

        for (auto& row : mat) {
            for (int x : row) {
                cnt[x]++;
            }
        }

        for (int i = 1; i <= 10000; i++) {
            if (cnt[i] == m) {
                return i;
            }
        }
        return -1;
    }
};
```

每行严格递增，同一个值在一行里最多出现一次，所以 `cnt[x]` 恰好就是"x 出现在多少行里"，`cnt[x] == m` 即出现在所有行。再从 1 往上扫，第一个命中的就是最小值。

值域只有 1e4，后面那 10000 步的空扫描可以忽略。把容器换成 `unordered_map` 是同一套逻辑，值域没有上界时就得用它：

```cpp
int smallestCommonElement(vector<vector<int>>& mat) {
    int m = mat.size();
    unordered_map<int, int> cnt;
    for (auto& row : mat)
        for (int x : row) cnt[x]++;
    int best = INT_MAX;
    for (auto& [v, c] : cnt)
        if (c == m) best = min(best, v);
    return best == INT_MAX ? -1 : best;
}
```

## 解法二：每行一个指针同步推进

```cpp
class Solution {
public:
    int smallestCommonElement(vector<vector<int>>& mat) {
        int m = mat.size();
        int n = mat[0].size();
        vector<int> ptr(m, 0);  // 每行的列指针

        while (true) {
            // 1. 找当前各指针所指元素的最大值
            int mx = mat[0][ptr[0]];
            for (int i = 1; i < m; i++) {
                mx = max(mx, mat[i][ptr[i]]);
            }

            // 2. 检查是否所有行都指向同一个值
            bool allSame = true;
            for (int i = 0; i < m; i++) {
                if (mat[i][ptr[i]] != mx) {
                    allSame = false;
                    break;
                }
            }
            if (allSame) return mx;

            // 3. 把小于 mx 的行指针向后推（严格递增，推到 >= mx）
            for (int i = 0; i < m; i++) {
                while (ptr[i] < n && mat[i][ptr[i]] < mx) {
                    ptr[i]++;
                }
                if (ptr[i] == n) return -1;  // 某行越界，无公共元素
            }
        }
    }
};
```

每轮做三件事：

1. 取各指针当前所指元素的最大值 `mx`。**比 `mx` 小的值不可能出现在所有行里**（它在某一行已经被越过），答案的下界被抬到 `mx`。
2. 所有指针指的值都等于 `mx` 时，`mx` 就是答案：它同时满足"在下界上"和"每行都有"。
3. 否则把指着的值小于 `mx` 的行往后推，直到值不小于 `mx`（行内严格递增，一个 `while` 推到位）。任何一行推完越界，说明这行剩下的值全都小于 `mx`，够不到下界，返回 `-1`。

---

## 核心理解

### 1. 数组是哈希的值域特化

解法一的 key 是值，value 是它出现过的行。`unordered_map<int,int>` 是完整形态，值域任意大都能跑；本题值域已知而且只有 1e4，换成长度 10001 的数组，把哈希寻址变成下标寻址，省掉哈希常数，代码也更短。元素范围大到开不出数组时（比如到 1e9），就得换回 map。

### 2. `cnt[x] == m` 依赖"行内不重复"

如果一行里同一个值出现两次，它就被计两次，一个只在个别行出现的值也能凑到 `m`：

```
mat = [[2,2,2],[1,3],[1,3]]   期望 -1，但 cnt[2] == 3 == m，会误判成 2
```

本题每行严格递增，不会发生这种情况。行内可能重复时，要按行去重，同一个值在一行里只计一次：

```cpp
unordered_map<int, int> cnt, last;   // last[x]：x 上次被计数的行号
for (int i = 0; i < m; i++)
    for (int x : mat[i]) {
        auto it = last.find(x);
        if (it == last.end() || it->second != i) {
            cnt[x]++;
            last[x] = i;
        }
    }
```

### 3. 解法二的轮数被值域卡住

继续下一轮的前提是"存在某行的当前值大于 `mx`"，所以下一轮的 `mx` 严格变大，轮数不会超过值域（本题最多 10000 轮，实际远小于它）。指针那边，每个指针最多走完自己那一行，总推进量不超过 `m·n`。

---

## 复杂度

| | 解法一（数组） | 解法一（map） | 解法二（多指针） |
|--|------|------|------|
| 时间 | O(mn + 10000) | O(mn) | O(mn + m·V) |
| 空间 | O(10000) | O(D) | O(m) |

`V` 是值域上界，`D` 是矩阵里不同值的个数；解法二每一轮要扫一遍 `m` 个指针。

---

## 踩坑点 / 注意点

- ⚠️ **数组大小 10001 是写死的**：本题元素不超过 10000 所以够用，把它当模板搬到值域更大的题上要先换容器，否则直接越界。
- ⚠️ **解法二的 `n` 是所有行共用的边界**：题面保证 `m × n` 等长，所以这里没问题；搬到行长不一的题上，`ptr[i] < n` 和 `ptr[i] == n` 都要改成这一行自己的 `mat[i].size()`。
- ⚠️ **解法二里 `mat[i][ptr[i]]` 的安全靠"推进后立刻查越界"**：那个 `if (ptr[i] == n) return -1;` 挪走或删掉，下一轮的比较就会读到行外。
